### 模型基元

- 节点：铰接点/球节，具有三维坐标状态和方形标记。
- 刚性线：长度恒定的上/下叉臂、转向节、拉杆和轮辋结构。
- 可形变线：弹簧/减振器，以三维螺旋线表示，圈距随行程变化。

### 几何拓扑与求解

- 下叉臂包含前后车架枢轴和 LBJ，并绕枢轴轴线单自由度旋转。
- 上叉臂同构并包含 UBJ。
- 转向节是由 LBJ、UBJ、轮心和转向臂点组成的刚体。
- 主销轴为 LBJ→UBJ，并体现 KPI 与 Caster。
- 齿条位移经内拉杆和定长拉杆驱动转向节。
- 每帧数值求解，不使用预烘焙动画。
- 输入：轮跳 `b ∈ [-80, 80] mm`、齿条位移 `r ∈ [-60, 60] mm`。
- 使用定长约束求解上臂角和转向角，再更新转向节、轮心和车轮平面。

### 功能

- 轮跳滑杆与正弦自动激励。
- 转向与轮跳叠加，可观察 bump steer。
- 绘制全行程主销残影、UBJ/LBJ/轮心/接地点轨迹和主销落地点。
- 实时输出外倾、前束、KPI、Caster、轮距变化、scrub、弹簧长度和行程。
- 提供透视线框视图、轨道旋转/缩放/平移和等轴/前/俯/侧视预设。
- 提供复位和路径、轨迹、节点、标签、网格开关。

### UI

- 深色中性工业 CAE 风格。
- 使用 1px 直角边框和等宽数据字体。
- 不使用 emoji、圆角、阴影和装饰渐变。
- 布局为顶部状态栏、左侧控制/数据面板和主视口。

## 验收标准

- 轮跳时外倾角连续变化。
- 左右转向输入产生方向对称的响应。
- 轮跳与转向叠加不发散。
- 所有刚性杆件的渲染长度保持恒定。
- 弹簧长度读数与渲染几何一致。

## 自动化验收建议

- 扫描完整轮跳与齿条输入网格。
- 每帧记录刚性杆长度误差、残差、外倾和前束。
- 对称输入比较符号与幅值。
- 将最大约束误差、非有限数值和求解失败写入结构化报告。
