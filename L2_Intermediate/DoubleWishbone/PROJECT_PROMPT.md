# 任务背景

请在单一 `index.html` 中实现一个基于「节点 + 刚性线 + 可形变线」的汽车双叉臂（Double Wishbone）前悬挂运动学演示页面。忽略工作区内其他文件；渲染/UI 库自选（建议轻量，可经 CDN），**运动学求解必须自研**，不得依赖现成物理引擎。

# 需求范围

## 模拟模型规范

**基元定义：**
- 节点（Node）：铰接点/球节，以方形标记渲染，含三维坐标状态。
- 刚性线（Rigid Link）：长度恒定的约束杆件（上/下叉臂、转向节、转向拉杆、轮辋结构）。
- 可形变线（Deformable Line）：长度随状态变化的元素（螺旋弹簧/减振器，以三维螺旋线渲染，圈距随行程压缩/伸张）。

**几何拓扑（毫米级参数表，X=横向外侧，Y=垂向，Z=纵向前方）：**
- 下叉臂：2 个车架枢轴（前/后）+ 1 个下球节 LBJ，绕枢轴轴线单自由度旋转。
- 上叉臂：同构，含上球节 UBJ。
- 转向节（Upright）：刚体，由 LBJ、UBJ、轮心、转向臂点构成；主销轴 = LBJ→UBJ。
- 转向系统：齿条横向平移 → 内拉杆节点 → 刚性拉杆 → 转向臂节点，约束转向节绕主销旋转。
- 主销参数须体现：主销内倾（KPI）、主销后倾（Caster）。

**运动学求解（每帧数值解，禁止预烘焙动画）：**
- 输入：车轮跳动量 `b ∈ [-80, +80] mm`、齿条位移 `r ∈ [-60, +60] mm`。
- 求解链：下臂转角 →（等距约束 |UBJ−LBJ|=const 数值求解）上臂转角 → 主销轴 →（拉杆定长约束数值求解）转向角 δ → 转向节刚体变换 → 轮心/车轮平面。
- 求解算法自选（二分/迭代/解析均可），但必须每帧实时求解。

## 功能需求

- **F1 悬挂跳动模拟**：手动滑杆 + 正弦自动激励。
- **F2 转向联动**：齿条位移经拉杆驱动车轮绕主销偏转，与跳动叠加（bump steer 可观察）。
- **F3 主销运动路径**：全行程扫描，绘制主销轴残影簇、UBJ/LBJ/轮心/接地点轨迹、主销延长线落地点。
- **F4 实时参数输出**：外倾角、前束角、KPI、Caster、轮距变化、主销偏距（scrub）、弹簧长度、行程。
- **F5 三维线框视图**：透视投影，鼠标轨道旋转/缩放/平移，等轴/前视/俯视/侧视预设。
- **F6 复位与显示层开关**：路径、轨迹、节点、标签、网格。

## UI 规范

- 工业 CAE 软件风格：深色中性配色、1px 直角边框、等宽字体数据、全大写标签。
- 禁止 emoji、圆角、阴影、渐变装饰。
- 布局 = 顶部状态栏 + 左侧控制/数据面板 + 主视口。

## 验收标准

- 跳动时外倾角连续变化。
- 转向时左/右打轮前束对称响应。
- 跳动与转向叠加不发散。
- 全部约束杆件渲染长度恒定。
- 弹簧长度读数与渲染一致。
