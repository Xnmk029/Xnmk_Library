操作说明

目标：移动鼠标让准星对准小球并点击射击。小球带有物理碰撞，命中瞬间会轻微偏移（模拟真实命中反馈）。

鼠标：移动 = 移动准星；左键 = 射击；滚轮 或 [ ] = 调整有效灵敏度。

右键 按住 = 显示武器晃动模拟（扫射练习）。

模式：

  • 网格：静止小球快速出现，练习甩枪与固定瞄准的衔接。
  • 急停：小球随机出现并在停留、瞬移间切换，练习短促急停定位。
  • 追踪：小球在场地内平滑漂移，练习持续跟枪。
  • 小微动：小球极小且在高频抖动，练习极细微控。
  • 静观：小球静止，只练纯粹的点击精度与节奏。

游戏适配：选择不同游戏会自动套用其主流 FOV 与灵敏度换算基准，帮助你在接近真实游戏手感下训练。
