# 小丑牌：网页卡牌游戏与动效复刻 Benchmark

## 分类元数据

- **测试领域**: Web 游戏与交互逻辑
- **难度等级**: `L2`（中级）
- **核心技术栈**: HTML5 / WebGL / CSS Animations
- **核心考核点**: Godot 到 CSS 的转译、卡牌游戏状态机、动效反馈（Juice）

### 核心要求

- 包含发牌、选牌、出牌、弃牌、计分、回合目标、商店/强化和新一轮流程。

- 手牌排序、选中、悬停、计分和结算状态应清晰。

- 卡牌位移、缩放、倾斜、弹性和粒子反馈应平滑一致。

- 状态机必须防止重复结算、非法出牌和动画期间的竞态。

- 提供重新开始和基础设置。

- 使用原创或合法可再分发的图形、字体和音效。

- 固定牌组和随机种子。
