# FPSlab：多游戏适应 FPS 瞄准训练 Benchmark



## Classification Metadata (分类元数据)

- **Test Domain (测试方向)**: Web Games & Interactive Logic
- **Difficulty Level (难度等级)**: `L2 (Intermediate)`
- **Primary Tech Stack (核心技术栈)**: HTML5 Canvas / Pointer Lock API / Audio Synth
- **Core Evaluation Focus (核心考核点)**: Target spawning algorithm, sensitivity converter, crosshair builder

测试模型在单文件 Web HTML5 下构建 3D/2D 练枪环境、目标生成、准星自定义与灵敏度转换系统的能力。
