# FPSlab：多游戏适应 FPS 瞄准训练 Benchmark

## 分类元数据

- **测试领域**: Web 游戏与交互逻辑
- **难度等级**: `L2`（中级）
- **核心技术栈**: HTML5 Canvas / Pointer Lock API / Audio Synth
- **核心考核点**: 目标生成算法、灵敏度换算器、准星构建器

## 任务定位

测试模型在单文件 Web HTML5 下构建 3D/2D 练枪环境、目标生成、准星自定义与灵敏度转换系统的能力。
