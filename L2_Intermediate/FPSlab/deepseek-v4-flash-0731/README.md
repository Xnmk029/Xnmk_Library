# FPSlab · 多游戏适应 FPS 小球练枪（单文件）

`FPSlab.html` — 双击直接用浏览器打开（file:// 零依赖，无 CDN、无外部资源）。

## 核心功能

| 模块 | 说明 |
|---|---|
| 🎯 训练大厅 | 6 种练枪模式：甩枪定点 / 动态跟枪 / 反应速射 / 蜘蛛微调 / 重力弹跳 / 自定义靶场 |
| 🎮 游戏适应 | CS2 / Valorant / Overwatch2 / Apex / R6 / CoD / PUBG 一键适配：套用该游戏的真实 yaw 灵敏度、FOV 与准星风格 |
| ⚖️ 灵敏度换算 | 以 **cm/360°** 为不变量跨游戏换算，输出等效灵敏度 / cm360 / counts360 / eDPI |
| ✛ 准星工坊 | 5 种样式 + 颜色/长度/粗细/间隙/透明度/描边/中心点，实时预览，练枪时自动应用 |
| 📊 战绩看板 | localStorage 持久化，历史表格 + 得分/命中率趋势图，结算弹窗含段位评级与击中散布图 |
| 🔊 音频合成 | WebAudio 全合成音效（射击/命中/爆头/脱靶/连击音高爬升），无音频文件 |

## 技术要点

- **伪3D 引擎**：透视投影 + PointerLock 视角，球形目标带径向渐变着色、距离雾效、命中粒子
- **手感真实映射**：鼠标移动按 `yaw×sens`（弧度/count）直接驱动视角，物理手感与所选游戏一致；FOV 按游戏实际值投影
- **目标生成算法**：每模式独立生成器（网格补位 / Lissajous 跟枪 / 随机闪现寿命 / 蜘蛛中心+外圈 / 重力弹跳物理 / 沙盒参数化）
- **单文件约束**：CSS + JS 全部内联，HTML5 Canvas 渲染，`<script src>` 为 0

## 灵敏度常数（已社区核验）

| 游戏 | yaw | 默认FOV(16:9水平) |
|---|---|---|
| CS2 | 0.022 | 106.26° |
| Valorant | 0.07 | 103° |
| Overwatch 2 | 0.0066 | 103° |
| Apex | 0.022 | 102.4°（70°垂直） |
| R6 Siege | 0.00572 | 112.7°（75°垂直） |
| CoD MW/WZ | 0.0066 | 112.3°（80°垂直） |
| PUBG | 0.022 | 112.3°（80°垂直） |

换算公式：`目标灵敏度 = 源灵敏度 × 源yaw ÷ 目标yaw`；`cm/360 = 360 ÷ (yaw × 灵敏度 × DPI) × 2.54`
