## 自动化验收建议

- Stage 1：验证实例化渲染（约万级草叶、个位数 Draw Call）；低帧率（≈12fps）风动画各草叶相位错开；角色经过草叶被推开（多角色）；非透视相机下面片变扁补偿生效；云影在地面缓慢移动。
- 场景：HDRI、程序化树木、土路、迷雾、地形起伏与草地渲染风格一致。
- Stage 2：主菜单为 Stage 1 场景 + 箱子沿道路自滚循环动画；≥3 个经典布局关卡；推动、重置、胜利判定全部可验证；Low-poly 小鲸鱼推箱动画正常。
- UI 红线检查：无 emoji、无蓝紫渐变、无毛玻璃元素。
