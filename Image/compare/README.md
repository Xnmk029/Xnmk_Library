# 图像对照页

打开 [index.html](index.html)，或使用现有本地服务访问 `/Image/compare/`。页面采用「分析欧普像素动效风格」任务中 `motion-kit-v03 / compare` 的鸢紫与浅柠配色、像素分界线、阶梯拖柄和稳定阅读区。原参考位于 `I:/remotion/projects/channel-style-lab/motion-kit-v03/renders/stills/10-compare.png`。

- 划线对比：拖动像素分界，或点自动扫视。分界线获得焦点后可用左右键微调。
- 并排：完整显示两张图片，便于比较不同构图。
- A/B 闪切：每 0.8 秒切换，空格暂停或恢复。
- 滚轮 / 滑条同步缩放，拖动画面同步平移；双击或点击适应画面恢复。
- 选择左右模型、交换 A/B、原图快捷选择、场景帧切换；缩略图快速切换右侧结果。
- 原始图按比例完整显示，不自动配准或拉伸。不同宽高比有提示，图片不受界面调色影响。
- 历史渡船漫画 v1 与 F1 v2 分组；缺失场景帧显示空位，不偷偷换为其他帧或模型。
- 三道新编辑题作为草案试题加入。临时导入 A/B 仅在本页面有效，不上传外部服务。
- 当前选择写入 URL 片段，可复制链接；本地地址仅适用于能访问此工作区的设备。

目录是静态清单，仅收录实际存在的原始结果。新增模型输出后运行 `python Image/compare/build_catalog.py` 再刷新页面。不会扫描 `.env`、密钥、工具 outputs 或工作区外的文件；不会自动生成图片。图片保持在原项目目录，移动整个 Image 文件夹时应保留相对结构。

模型标签来自原有元数据或目录名，不构成独立的模型身份验证。内置 Image Gen 明确标记模型 ID 未公开；历史目录有元数据但没有实际图像时不显示空模型。提示词记录不一致时提示查阅原调用记录，正式评分需另行完成。

后续修正：暂停后更换模型保留暂停；空格与顶部按钮共用播放状态；桌面舞台适应可用高度；窄屏选择器改为分行。预览服务改为独立后台进程，标准输出写入本地日志。

默认沉浸式入口：`http://127.0.0.1:8769/compare/?v=4`。Tab 呼出控制台，? 快捷键，H 元素重要性分析。详细映射见 [交互热图](INTERACTION-HEATMAP.md)。

## 欧普像素底纹与圈画

入口 `http://127.0.0.1:8769/compare/?v=5`。Y 显隐浅底纹；底纹只绘制在背景/留白，图片保持原色。控制台也使用低对比像素条纹。

D 画笔、E 椭圆、G 方框、N 箭头；Q 退出圈画；Z 撤销、Shift+Z 重做。工具栏可选颜色和三档笔宽，清空本组也可撤销。进入圈画时暂停动效，避免标记过程画面移动；退出后按 Space 可恢复。

标记独立于源图，按题目、帧、模式和图片组合分组，在当前页面内保留，刷新后消失。坐标锚定落笔一侧的图像，随缩放、平移与窗口尺寸调整；并排模式限定在对应半屏。圈画期间滚轮暂停缩放，退出后可正常缩放。不会写入或覆盖任何生成图片。

题目侧栏：指针靠近左侧 14px 边缘或悬停“题目”标签展开；移开后约 0.32 秒收起。支持搜索、当前题高亮、点击切题并收起；输入搜索时保持展开，Esc/外部点击可收起。拖动与圈画过程中不自动唤起。入口：http://127.0.0.1:8769/compare/?v=7


## 集成精灵图审查
选择 SpriteLoop 自动以当前 A/B 模型进行同步切片播放，默认 6 列 × 4 行、6 FPS。原独立播放器保留。
- W：直接打开审查面板；Esc 关闭。
- S：完整图集 / 切片播放；Space 同步暂停或播放。
- 逗号、句号：上一帧、下一帧；上下方向键切换动作行。Shift + 方向键仍用于平移。
- 原有遮罩、并排、闪切、模型水印、右键选模型、缩放与圈画可用于切片；圈画会暂停动画，标记按动作行与帧隔离。
- 面板支持自定义网格、FPS、透明棋盘与纯色底、洋葱皮、Alpha、包围盒、安全边距、图集点选、逐帧缩略图和各行动画预览。
- 无法整除的网格明确报错，不拉伸或偷偷调整。导出 JSON 包含两侧来源、SHA-256、各帧统计与备注。备注和播放设置仅本次页面有效；分享链接保留题目和模型选择。
UI 使用现有四配色变量、硬边线条、浅像素底纹与阶梯揭幕；主视窗沿用原欧普干涉动效，尊重减少动态效果设置。


F2 打开当前题面，Alt + ↑ 打开提示词；文档面板支持全文复制、源文档和当前帧参考图入口。A/B 实际调用标签读取各自元数据中保存的 prompt，缺失时明确提示，不使用标准提示词代填。Esc 返回。

Alt + F 切换全屏（保留 F），在控制台及题面面板内也可使用。
