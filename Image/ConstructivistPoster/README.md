# DeepSeek V4 构成主义宣传海报 Benchmark

## 分类元数据

- **分区**: `Image/`（图像生成与编辑，根目录独立分区）
- **测试领域**: 图像生成 · 文生图（T2I）
- **核心技术栈**: Text-to-Image / 平面海报
- **核心考核点**: 拟人角色、构成主义几何、三色丝网质感、构图张力

## 任务定位

测试模型在 **严格风格约束**（构成主义、三色、丝网）下完成品牌拟人海报的能力。

## 提示词

> 📋 **完整提示词以 [`PROJECT_PROMPT.md`](./PROJECT_PROMPT.md) 为唯一标准**，本页不再内嵌副本。
> 评测时请直接使用提示词原文，**不要修改任何技术约束**。

要点：DeepSeek V4 动漫女性拟人；锐利几何切割；宝蓝/黑/米白三色；丝网颗粒磨损；不对称张力；扁平高对比。

## 验收标准 · 五项评分

建议每项 0–10 分。

| # | 评分项 | 考察内容 | 高分锚点 | 低分锚点 |
| :---: | :--- | :--- | :--- | :--- |
| 1 | **文字与品牌清晰度** | DeepSeek / V4 等字形（若出现）与主体轮廓锐度 | 主标题可读；边缘利落 | 字糊、主体发粉发脏 |
| 2 | **物体/角色合理度** | 动漫女性拟人完整性与形体可读 | 可识别女性动漫形象 | 残肢、五官崩坏 |
| 3 | **提示词遵循度** | 构成主义海报：三角/圆/粗对角线、扁平高对比、非写实摄影 | 几何切割与工业力量感明确 | 实拍/厚涂写实或无构成 |
| 4 | **细节标识与材质准确性** | 三色限定（宝蓝/深黑/米白）、丝网颗粒与磨损 | 三色体系 + 颗粒磨损成立 | 杂色过多、光滑数码渐变 |
| 5 | **整体构图** | 不对称平衡、对角线主导、复古海报张力 | 有冲击力与层级 | 居中发闷、堆叠无主次 |
