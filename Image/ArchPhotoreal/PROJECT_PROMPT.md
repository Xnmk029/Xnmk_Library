# 任务背景

对建模软件截图进行 **真实化渲染（图生图）**。必须在原图基础上工作，不得重做建筑体量。

# 输入

使用本目录 `assets/source.png` 作为唯一源图（黄砖建筑、红色块状背景、深色道路与木栏杆露台）。

# 需求范围

图片中为建模软件中的一张截图，主要任务：进行图片的真实化渲染，其中：

1、严格保留图中原始建筑结构，不得对比例及建筑形态进行任何修改，所有渲染工作必须在原图基础上进行。
2、将前景的道路替换为真实感的材质与样式，保留其走向
3、后景中的红色部分需要替换为中国中南地方的中低高度丘陵山林地势山坡作为背景，需要具有真实的植被树林
4、需要精确识别出图片中的透明玻璃材质部分，为其生成真实的玻璃高光反射与透明效果
5、对当前建模软件中原始建筑结构的表面材质进行类型读取与优化更改，使其表现更加真实，减少材质贴图的循环性。
6、以上修改完成后，要检查画面整体的完成性，让主题建筑物的材质、光影、细节能融入背景、前景当中，整张图片能类似真实拍摄样式


# 交付与限制要求

- 交付 1 张最终成片（PNG / JPG / WEBP），可直接打开。
- 不得以纯文字描述代替图像。
- 建议长边 ≥ 1600 px。
