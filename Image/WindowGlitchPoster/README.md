# DeepSeek V4 窗口叠层与故障拼贴 Benchmark

## 分类元数据

- **分区**: `Image/`（图像生成与编辑，根目录独立分区）
- **测试领域**: 图像生成 · 文生图（T2I）
- **核心技术栈**: Text-to-Image / 平面插画
- **核心考核点**: 全身动态、窗口叠层、天空视窗、Glitch、蓝白主色

## 任务定位

测试模型执行 **复合构图约束**（窗格切割 + 天空透明视窗 + 故障特效 + 动态全身）的能力。

## 提示词

> 📋 **完整提示词以 [`PROJECT_PROMPT.md`](./PROJECT_PROMPT.md) 为唯一标准**，本页不再内嵌副本。
> 评测时请直接使用提示词原文，**不要修改任何技术约束**。

要点：全身动态速写；矩形窗格重叠；框内蓝天积雨云；Glitch 扫描线/色偏；克莱因蓝 + 白；简洁诗意。

## 验收标准 · 五项评分

建议每项 0–10 分。

| # | 评分项 | 考察内容 | 高分锚点 | 低分锚点 |
| :---: | :--- | :--- | :--- | :--- |
| 1 | **文字与界面清晰度** | deepseek / 窗体标题（若有）与角色线稿清晰度 | 关键字与轮廓清楚 | 窗体字糊、角色糊团 |
| 2 | **物体/角色合理度** | 全身像、非常规正面站桩的动态与肢体 | 动态明确，全身入画 | 半身、T-pose、肢体错位 |
| 3 | **提示词遵循度** | 窗口重叠/数字拼贴；轮廓矩形切割；天空透明视窗 | 窗格天空成为设计语言 | 无窗格/无天空视窗 |
| 4 | **细节标识与特效准确性** | Glitch 黑条/扫描线/色偏；主色克莱因蓝+白 | 故障特效可识别且主色正确 | 无 Glitch 或乱彩盖过主体 |
| 5 | **整体构图** | 现代平面律动、背景简洁、宁静诗意 | 留白与律动平衡 | 过载杂乱、失去诗意 |
