# 原神六位角色同屏

任务 ID：`GenshinEnsemble`。版本：1.0。2026-10-10 新增的世界知识文生图题，尚未生成测试成果。

固定六位角色覆盖不同的外观体系，并锁定首次作为可玩角色登场时的默认外观。题面不提供发色、服装颜色等答案线索，测试角色识别、多人属性绑定与游戏角色知识。

输入仅为 PROJECT_PROMPT.md，不提供角色参考图。Agent 全程不得搜索、检索或从素材库获取外观信息，也不得将评审依据追加给生成模型。记录实际提示词、模型、档位、尺寸和工具使用情况。

知识项逐人检查身份、默认外观、发型、服装、配饰与体型，再检查数量、重复、顺序及串用特征。画面项独立检查肢体、遮挡、互动、统一画风与构图。若某角色画得漂亮但身份错误，知识项仍记错误。评审依据与生成输入分开保存；没有工具轨迹时不声称已验证禁止搜索。
