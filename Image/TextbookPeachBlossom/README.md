# 桃花源记语文课本展开页 Benchmark

## 分类元数据

- **分区**: `Image/`（图像生成与编辑，根目录独立分区）
- **测试领域**: 图像生成 · 文生图（T2I）
- **核心技术栈**: Text-to-Image / 场景与文字
- **核心考核点**: 课本物体真实感、篇目文字、教材版式气质

## 任务定位

测试模型生成 **展开语文课本** 并承载指定篇目（《桃花源记》）的能力，重点考核文字可读与「课本」物体属性。

## 提示词

> 📋 **完整提示词以 [`PROJECT_PROMPT.md`](./PROJECT_PROMPT.md) 为唯一标准**，本页不再内嵌副本。
> 评测时请直接使用提示词原文，**不要修改任何技术约束**。

要点：语文课本展开；内容为桃花源记（提示词含「长篇古诗」表述，见评分注）。

## 验收标准 · 五项评分

建议每项 0–10 分。

| # | 评分项 | 考察内容 | 高分锚点 | 低分锚点 |
| :---: | :--- | :--- | :--- | :--- |
| 1 | **文字清晰度** | 标题与正文是否可读 | 标题与至少部分正文可认读 | 假字、全文不可读 |
| 2 | **物体合理度** | 展开课本的书脊、页边、纸张、摊开角度 | 像真实打开的课本 | 不像书、单页海报、崩坏 |
| 3 | **提示词遵循度** | 场景为语文课本展开；主题为桃花源记 | 可识别课本 + 该篇目 | 无关封面、仅风景无书 |
| 4 | **细节标识与内容准确性** | 篇名/作者线索；文言课文气质 | 篇名正确，正文气质贴近 | 篇名错误、现代文乱入 |
| 5 | **是否有插图与插图合理性** | 课文是否配有插图；插图与《桃花源记》内容/情境是否匹配、位置与比例是否像教材 | 有贴合文意的插图（如桃林、渔人、村落等），编排自然 | 无插图；插图跑题/乱入；或插图破坏版式不可读 |

> **体裁说明**：提示词写「长篇古诗」与《桃花源记》实际体裁（散文）不完全一致。评分以 **「桃花源记课文 + 课本展开」** 为准；模型写成散文 **不因体裁扣分**，完全跑题除外。
