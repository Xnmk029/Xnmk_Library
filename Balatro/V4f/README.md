# 小丑牌 · Balatro Web（学习项目）

一个尽可能还原 Balatro（小丑牌）玩法与动效的网页版实现，纯前端、零依赖，双击 `index.html` 即可游玩（推荐用现代 Chrome/Edge 打开）。

## 快速开始

```
git clone <repo> && cd 小丑牌/V4f
# 直接打开 index.html（file:// 即可运行，无需服务器）
```

或起一个本地静态服务器：

```bash
npx serve .        # 或任意静态服务器
```

## 玩法还原

- **完整一局流程**：牌组/注额选择 → 小盲注 → 大盲注 → Boss 盲注 → 商店 → 下一注 → 第 8 注通关 + 无尽模式
- **扑克牌型**：全部 13 种（高牌 → 同花五条），含通配牌（wild）、石头牌（stone）、4 Finger、Shortcut、Smeared 等特殊判定
- **150 张小丑牌**：数值/稀有度/价格/成长逻辑均按原版数据实现（通配、重触发、成长型、经济型、赌狗型……）
- **消耗品**：22 张塔罗牌、12 张星球牌、18 张幻灵牌（含灵魂牌、黑洞等隐藏牌）
- **盲注与 Boss**：盲注数值按原版公式缩放；24 个 Boss 盲注全部实现（削弱花色/人头牌、限制出牌张数、弃牌惩罚、禁止重复牌型等）
- **商店系统**：重掷（费用递增）、补充包（小丑/塔罗/天体/幻灵/标准，普通/巨型/超级）、优惠券（32 张，含升级链）
- **经济系统**：利息（$5 → $1，上限可升级）、盲注奖励、标签（Tag）跳过奖励、租赁费/永恒/易碎机制
- **牌组与注额**：15 个牌组（红/蓝/黄/绿/黑/魔法/星云/幽灵/废弃/方格/黄道/彩绘/浮雕/等离子/混乱）+ 8 级注额

## 动效还原

- 发牌弹入手牌区、选牌弹跳上浮
- 出牌飞向中央、手牌标签砸入（弹性缩放）
- 筹码/倍率数字滚动 + 逐牌计分弹跳 + 浮出文字（+X 筹码 / +X 倍率 / X2）
- Joker 触发抖动动画、XMult 大号金色弹出
- 得分滚动加速、击败盲注横幅砸入
- 开包扇形展开逐张翻面、商店商品滑入
- 玻璃牌破碎、Boss 盲注动画芯片（21 帧原版素材）
- 全部卡牌/小丑牌/塔罗/星球/Boss 图标均为**原版游戏素材**

## 音效

WebAudio 实时合成（无需音频文件）：发牌、选牌、计分 tick、金币、Joker 触发、开包、玻璃破碎等 20+ 种音效。

## 项目结构

```
├── index.html          # 入口
├── css/style.css       # 全部样式与动效
├── js/
│   ├── data.js         # 自动生成：全部卡牌数据 + 官方中文本地化
│   ├── poker.js        # 手牌判定引擎（通配/顺子/同花 + 盲注缩放）
│   ├── sfx.js          # WebAudio 音效合成
│   ├── cards.js        # 卡牌渲染（精灵图 + 描述文本标记解析）
│   ├── game.js         # 游戏状态机（回合/计分/商店/经济/Boss）
│   ├── ui.js           # 界面 + 动效编排
│   └── main.js         # 启动与缩放适配
├── assets/             # 原版精灵图（cards/jokers/tarots/blinds/boosters/vouchers...）
├── ref/                # Balatro 反编译源码（学习参考）
├── tools/              # 数据构建与自动化测试脚本
└── tests/              # 单元测试（node tests/poker.test.js）
```

## 数据来源

本项目的全部数值与文本来自 **Balatro 反编译源码**（GladdonT/balatro-source-code）与**官方中文本地化**，精灵图来自社区种子分析工具（OptimusPi/BalatroSeedOracle）提取的原版资源，通过 `tools/build-data.js` 自动构建为 `js/data.js`。仅供学习交流使用。

## 测试

```bash
node tests/poker.test.js     # 手牌判定单元测试（49 项）
node tools/e2e-test.js       # 浏览器端到端测试（需本机 Chrome，20 项）
```

## 操作说明

- 点击手牌选择（最多 5 张），「出牌」或「弃牌」
- **右键点击小丑牌可售出**；点击消耗品使用（塔罗牌需再点击手牌选目标）
- 跳过小/大盲注可获得标签奖励
- Boss 盲注有特殊规则，注意看描述
