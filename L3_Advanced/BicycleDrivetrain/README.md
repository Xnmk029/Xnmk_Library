你是一名高级 WebGL/Three.js 开发者、创意技术专家和机械传动工程师。请创建一个完整可运行的单文件 HTML 应用：低多边形动态自行车传动展示台。

### 程序化建模

- 低多边形程序化生成曲柄、牙盘、链条（连续闭合环）、5–7 片飞轮、后拨和透明亚克力支架。
- 链条为连续环，随牙盘与飞轮同步运动；飞轮各齿片尺寸与间距可见。
- 后拨含导轮并位于链条路径上；整体安装于透明亚克力展示支架。

### 功能与交互

- 支持电机启停、升挡、降挡和当前挡位显示（如 "Gear: 3/7"）。
- 换挡时后拨导轮水平移动，链条路径平滑插值（lerp）并保持传动同步。
- 挡位变化后飞轮挡位、后拨位置、链条路径与 HUD 显示一致，不得错位或跳变。

### 视觉与环境

- 明亮可读的动漫赛璐璐风格（cel shading、轮廓线、色块、适度像素化/海报化）。
- 避免整体过暗、阴影吞噬结构、bloom 遮挡轮廓或像素化过度。
- 透明亚克力支架（半透明材质、清晰边缘高光）与有尺度感但不过度杂乱的工作台/展示环境。

### UI 与规格

- 提供电机启停按钮、升挡/降挡按钮和当前挡位 HUD。
- 实时显示传动规格（牙盘齿数、飞轮齿数与当前齿比等）。
- 提供重置与相机预设等基础功能；OrbitControls 可用。

## 输出要求

- 交付可复制运行的单个 HTML 代码块。
- Three.js 与 OrbitControls 通过可靠 CDN 引入。
- 不得输出伪代码、局部片段、TODO 或要求用户补齐核心功能。

## 自动化验收建议

- 换挡后验证飞轮挡位、后拨位置、链线路径与 HUD 一致。
- 电机启停与升/降挡往返一致性校验。
- 收集 FPS、draw calls、三角形和内存指标。
