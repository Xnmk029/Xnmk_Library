# 方界

一个无需构建步骤的 HTML 体素开放世界游戏。地形按种子动态生成，玩家修改过的方块、背包、快捷栏、位置与世界时间会保存到浏览器 `localStorage`。

## 运行

直接双击 `启动游戏.cmd`，脚本会在后台启动服务器并打开浏览器。

也可以手动在当前目录启动静态服务器：

```powershell
py -m http.server 4173
```

然后访问 `http://localhost:4173/`。

## 操作

- `W A S D`：移动
- `Space`：跳跃
- `Shift`：奔跑
- 鼠标：环顾
- 鼠标左键：破坏方块
- 鼠标右键：放置方块
- 滚轮或 `1-9`：切换快捷栏
- `E`：打开背包与合成
- `Esc`：暂停并释放鼠标

触屏设备会显示移动摇杆、跳跃、破坏和放置按钮。

## 游戏选项

在背包面板的“选项”页可以开启：

- **永为白日**：将世界时间固定在正午。
- **创造模式**：无限方块、免疫伤害、无限体力并启用飞行。桌面端按 `Space` 上升、`Shift` 下降；触屏端使用上升和下降按钮。

## 贴图

游戏通过 `assets/texture-config.json` 选择贴图来源。默认使用内置原创 Canvas 像素贴图；需要启用 CCTQ 图集时，将图片放到 `assets/cctq-atlas.png`，并把配置中的 `cctqAtlas` 改为 `"./cctq-atlas.png"`。图集会按 4 x 4 网格裁切为十六种方块材质。

预期图集顺序：

1. 草地顶面、草地侧面、泥土、岩石
2. 沙子、树皮、木板、树叶
3. 水、玻璃、红砖、煤矿石
4. 铁矿石、雪、圆石、工作台

## 自动验证保护

`npm run verify` 会使用专用的低负载验证模式，不申请系统指针锁。脚本禁止并发运行，默认运行上限为 90 秒，并会在成功、失败、超时或收到终止信号时关闭本次验证创建的 Edge 进程。正常启动游戏不受该模式影响。
