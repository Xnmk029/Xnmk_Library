# MCZPI · 我的世界（网页版）

一个尽可能还原 Minecraft 的浏览器体素游戏，**无限世界**、无缝地形、纯本地运行（零网络依赖、零构建）。

## 运行方式

**方式一（推荐，双击即玩）**：直接用浏览器打开 `index.html`（Chrome / Edge / Firefox 均可，无需服务器）。

**方式二（本地服务器）**：
```bash
cd mczpi
python -m http.server 8777
# 打开 http://localhost:8777
```

## 操作

| 按键 | 功能 |
|---|---|
| 鼠标 | 视角（点击画面锁定鼠标） |
| 左键 / 右键 / 中键 | 破坏 / 放置 / 取色 |
| WASD + 空格 | 移动 / 跳跃（水中按住上浮） |
| Shift / Ctrl | 潜行 / 疾跑 |
| 滚轮 或 1-9 | 选择热键栏方块 |
| F | 切换飞行（空格上升 / Shift 下降） |
| F3 | 调试信息（坐标/群系/种子/FPS） |
| M | 静音 |
| Esc | 暂停菜单（继续 / 保存并退出 / 重置世界） |

## 特性

- **无限世界**：16×16 区块流式生成/卸载，世界高度 96 格，随机种子或自定种子
- **程序化地形**：分形噪声大陆 + 丘陵 + 山脉，海洋 / 沙滩 / 沙漠 / 雪原 / 森林 / 平原群系
- **地下世界**：3D 噪声洞穴、煤矿、铁矿、基岩
- **橡树**：随机生成树干 + 经典球冠树叶
- **MC 式渲染**：程序化 16×16 像素纹理图集、面剔除、平滑光照（AO）、天光遮蔽、按面明暗
- **昼夜循环**：20 分钟一天，日出日落渐变、星月、云层漂移、雾效
- **物理**：重力 / 碰撞 / 跳跃 / 自动上台阶 / 游泳 / 疾跑 FOV 变化
- **音效**：程序化 WebAudio（破坏/放置/脚步/入水/UI 点击）
- **存档**：自动保存到 localStorage（种子 + 位置 + 时间），标题页可继续游戏

## 目录结构

```
mczpi/
├── index.html
├── css/style.css
├── js/
│   ├── vendor/three.min.js   # 本地 three.js r128（离线可用）
│   ├── noise.js              # 种子化 Simplex 噪声 / fbm / 哈希
│   ├── textures.js           # 程序化 MC 风格纹理 + 图集
│   ├── blocks.js             # 方块注册表
│   ├── world.js              # 无限地形生成 + 区块网格化 + 流式加载
│   ├── player.js             # 物理 / 碰撞 / 飞行 / 游泳
│   ├── sky.js                # 昼夜 / 日月 / 星云 / 光照
│   ├── audio.js              # 程序化音效
│   ├── particles.js          # 破坏粒子
│   ├── ui.js                 # 标题 / 热键栏 / F3 / 暂停
│   └── main.js               # 主循环 / 输入 / 存档
```

## 调试参数（URL 后追加，供验证用）

- `?seed=12345` 指定种子
- `?demo=1` 自动飞行巡航（无需操作，适合演示）
- `?tp=x,y,z` 传送，`?look=yaw,pitch` 固定视角，`?time=18.2` 指定时间
- `?nofog=1` 关闭雾
