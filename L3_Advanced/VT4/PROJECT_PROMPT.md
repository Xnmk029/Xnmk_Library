**1. 运行环境与交互架构**

- **技术基准**：基于 Web 与 HTML 运行环境，采用 **WebGPU** 作为底层图形渲染管线。交付为单页完整应用，纯代码程序化构建几何体、骨架与着色器逻辑，严禁引用外部三维模型资产（如 `.gltf`、`.obj` 等）。

- **UI 分栏与页面隔离**：抛弃单一视口，应用需构建现代化、专业级的模块化 UI 界面。将核心功能严格划分为独立的分栏标签页（如：**[全车装配检视]**、**[改型与内构考证]**、**[专业渲染工作室]**），确保各功能模块的参数面板与交互逻辑相互隔离，互不干扰。

**2. 核心任务：VT-4 主战坦克家族图片对照级建模**

- **外贸主力全结构复现**：AI 需自主检索并提取 VT-4（MBT-3000）主战坦克的大量公开影像资料与外贸防务展手册特征，以图片对照级的高几何精度，程序化构建其完整实体（包含 125mm 滑膛炮身管、复合装甲炮塔、六对负重轮底盘及双销履带）。

- **分舱内构与机械装置**：

- **动力舱（后部）**：程序化构建 1300 马力水冷涡轮增压柴油机、综合液力传动箱、冷却风扇组与排气管路。

- **战斗舱（中部）**：再现吊篮转台、盘式自动装弹机运转机械（输弹机、弹盘）、炮尾炮闩与驻退复进机构。

- **驾驶舱（前部）**：精确还原方向盘驾驶台、综合数字显示面板及舱口潜望镜组。

- **乘员组建模与战位布局**：生成具有基础骨架比例的三人乘员组模型（车长、炮长、驾驶员），配备现代化坦克乘员头盔与装具，并精准定位至车内各自工作战位。

**3. 军武考证辨析（外贸改型与选配套件演变）**
在[改型与内构考证]页面，提供改型切换与动态对比功能，基于不同国家的选配套件要求，精准重构外观差异并支持改动区域的高亮指示：

- **VT-4 (标准防务展版)**：基准 FY-4 反应装甲（ERA）布局，标准车长周视镜与基础型遥控武器站（RWS）。

- **VT-4 A1 (高端主动防御升级版)**：增设炮塔四周的毫米波雷达阵列与主动防御系统（APS）拦截弹发射器；升级重型遥控武器站；炮塔顶部增设车载无人机发射管与激光告警接收器（LWR）；顶部装甲加厚以防御攻顶弹药。

- **VT-4 P (巴基斯坦定制版)**：还原巴方特定要求的炮塔侧面 FY-4/FY-2 ERA 混合排布倾角与缝隙细节，调整首上附加装甲外形，重构特定样式的裙板、前挡泥板及尾部散热格栅布局。

- **透视解构交互**：提供一键外壳剖切或半透明透视切换（X-Ray），直观检视车内机械走线、弹药布局与乘员姿态。

**4. WebGPU 专业级渲染工作室与场景营造**
在[专业渲染工作室]页面，提供持平商业离线渲染器的工作流与视觉表现：

- **双模式渲染架构**：

- **低精度实时预览**：保持 60+ FPS 低延迟渲染，用于视口快速拖拽与光位调试。

- **高精度累积渲染**：视口静止时触发基于路径追踪或帧缓冲累积（Accumulation Buffer）的多采样抗锯齿与多重间接光积分运算，收敛输出具备真实全局光照（GI）、微表面柔和阴影与精确接触遮蔽（AO）的极高画质。

- **专业级相机与镜头控制**：支持在“轨道环视”与“自由飞行（Free Cam）”间切换；提供详尽的物理相机参数调节面板，包含焦距（Focal Length/FOV）、光圈（Aperture/景深模糊程度 DOF）、曝光度（Exposure）与色调映射（Tone Mapping）曲线控制。

- **多环境预设与物理特效**：

- 内置多种高精度 HDRI 环境光预设（如：正午沙场、阴天兵营、影棚打光），并支持一键切换。

- 纯代码生成带起伏凹凸、履带碾压痕迹的真实沙砾地面。

- 引入 GPU 驱动的程序化粒子系统，模拟空气中悬浮的扬尘与履带边缘轻微卷起的沙土特效。

- **大画幅输出**：提供“渲染导出”功能，支持以超高分辨率（如 4K/8K）截取当前累积渲染完成的画面，并无损导出全屏大画幅图像。
