# VT-4 / MBT-3000 主战坦克家族 · WebGPU 数字孪生工作站

纯程序化构建的 VT-4 外贸主战坦克图片对照级三维模型 + WebGPU 专业渲染管线。
**零外部资产**：所有几何体、骨架、材质、环境光与粒子均由代码生成。

## 运行

- 直接双击 `index.html`（Chrome / Edge 113+，需支持 WebGPU 并已启用硬件加速）；
- 或运行 `run.bat` 启动本地静态服务后访问 `http://localhost:8080`。

## 功能地图

### 全车装配检视
- 整车爆炸视图（按分系统向量分离）
- 125mm 滑膛炮俯仰联动（防盾/炮闩/驻退机随动）
- 分系统隔离显示：车体 / 炮塔武器 / 行动装置 / 内构 / 乘员
- 悬停部件识别 + 点击锁定分系统信息
- 六组外景视角预设

### 改型与内构考证
- **VT-4**（基准）：FY-4 楔形 ERA、标准周视镜、基础 RWS
- **VT-4 A1**：毫米波雷达阵 ×4、APS 拦截弹发射器、重型 RWS、无人机发射管、LWR、加厚顶甲
- **VT-4 P**：炮塔侧 FY-4/FY-2 混合 ERA、首上附加装甲重构、分段裙板、尾部格栅重构
- 改动区域橙色脉冲高亮 + 差异清单点击聚焦
- X-Ray 外壳随机透视（累积收敛为真实半透明）/ 三轴剖切平面
- 六组舱室内构机位（驾驶舱 / 战斗舱 / 动力舱 / 装弹机 / 车长 / 炮长）

### 专业渲染工作室
- 双模式：60FPS 实时预览 / 静止触发累积渲染（AA+DOF+软阴影+SSAO 逐帧收敛）
- 物理相机：焦距(18–200mm)、光圈(f/1.4–16 景深)、对焦距离、曝光 EV、ACES/AgX/Reinhard/Linear
- 轨道环视 / 自由飞行 (WASD+R/F+Shift)
- 四套程序化 HDRI 环境（正午沙场 / 阴天兵营 / 影棚 / 黄昏）
- 程序化沙砾地面（起伏地形 + 履带压槽 + 碎石散布）+ 扬尘粒子
- 大画幅导出：最高 8K × 512spp 累积渲染 → 无损 PNG

## 渲染管线

```
阴影深度(2048²) → G-Buffer(albedo+mat / worldN+part / depth)
→ 光照 (Cook-Torrance GGX + IBL + 逐帧随机 SSAO + 旋转泊松软阴影)
→ 累积缓冲 (rgba16f, 亚像素抖动 AA + 光圈盘 DOF + X-Ray 随机透明)
→ 扬尘粒子(累积内时间积分) → 色调映射+暗角+颗粒 → FXAA → Canvas
```
