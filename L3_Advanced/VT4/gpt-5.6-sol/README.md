# VT-4 装配与考证工作室

一个**完全本地、自包含、纯程序化几何**的单页 WebGPU 应用。包内不含 `.gltf`、`.glb`、`.obj`、外部纹理、在线字体或 CDN 依赖；浏览器运行时不会主动请求互联网资源。

> 版本：1.0.0  
> 构建日期：2026-09-04  
> 推荐浏览器：最新版 Chrome 或 Microsoft Edge（需启用硬件加速与 WebGPU）

## 一键运行

WebGPU 需要 `localhost` 或 HTTPS 安全上下文，因此不要直接双击 `index.html`。

### Windows

双击：

```text
start_windows.bat
```

脚本会优先使用 Windows 自带 PowerShell 启动包内的零依赖静态服务器；仅在 PowerShell 不可用时回退到 Python。无需另行安装 npm、Node.js 或任何前端依赖。

### macOS

双击：

```text
start_macos.command
```

首次运行若被系统拦截，可在终端中执行：

```bash
chmod +x start_macos.command start_unix.sh
./start_macos.command
```

### Linux

```bash
chmod +x start_unix.sh
./start_unix.sh
```

### 手动启动

```bash
python3 serve.py
```

默认打开 `http://127.0.0.1:8765/`。可指定端口或禁止自动打开浏览器：

```bash
python3 serve.py --port 9000 --no-open
```

## 功能概览

### 01｜全车装配检视

- 程序化车体、楔形炮塔、125 mm 级滑膛炮、六对负重轮、主动轮/诱导轮、托带轮与逐节履带。
- 炮塔方位、主炮俯仰、装配爆炸视图与系统分层显示。
- 鼠标点击部件后显示系统归属、适用改型、说明和考证置信等级。
- 可按驾驶舱、战斗舱、动力舱快速聚焦镜头。

### 02｜改型与内构考证

- **VT-4 标准防务展版**：基准 ERA、周视镜与基础遥控武器站。
- **VT-4A1**：四向雷达面板、APS 拦截器、重型 RWS、无人机协同发射筒、LWR 与顶部附加防护的照片近似表达。
- **VT-4P / Haider 照片近似版**：混合尺寸 ERA、首上模块、分段裙板、挡泥板和尾部格栅差异。
- 完整、X-Ray 半透明与左舷剖开三种解构模式。
- 内部包括动力包、综合传动、风扇/排气、盘式自动装弹机、输弹机构、炮尾/驻退复进、驾驶台、数字显示器、潜望镜及三名乘员。

### 03｜专业渲染工作室

- 原生 WebGPU PBR 近似着色、PCF 阴影、环境光、接触遮蔽近似、景深、曝光、对比度和 ACES/Reinhard/Linear 色调映射。
- 实时预览与静止触发的时域帧缓冲累积两种工作模式。
- 轨道相机与自由飞行相机；35–120 mm 等效焦距、光圈与对焦距离控制。
- 沙场、阴天兵营、影棚三套**纯程序化环境光场**。
- 4096 个 WebGPU Compute 驱动的悬浮尘埃与履带边缘扬尘粒子。
- 4K / 8K 分块累积、GPU 纹理读回与无损 PNG 导出。

## 性能说明

- 标准构型初始视图约为 **628 个可见实例 / 42 个绘制批次**；VT-4A1 X-Ray 约为 655 个实例。
- 通过几何复用、GPU Instancing、动态分辨率和静止累积减少实时开销。
- “60+ FPS”是中高端独立显卡在常见 1080p 视口下的设计目标，不是对所有设备的硬性保证。软件 WebGPU、集成显卡、4K 浏览器视口或高粒子密度会明显降低帧率。
- 高精累积只有在镜头和参数静止后才持续增加样本；交互会立即清空累积缓冲，避免重影。

## 4K / 8K 导出

导出器不会依赖浏览器是否保留 WebGPU 交换链画面，而是：

1. 按最大 2048 × 2048 分块建立离轴投影；
2. 每块执行 8–16 次抖动累积；
3. 渲染到专用 GPU Capture Texture；
4. 按 WebGPU 256 字节行对齐规则读回像素；
5. 在内存画布中拼接并编码 PNG。

8K PNG 的内存占用较高，建议关闭其他大型网页或应用，并预留至少约 1 GB 可用内存。导出期间不要关闭页面。

## 考证边界

本项目不是 NORINCO、巴基斯坦 Heavy Industries Taxila 或任何军方机构发布的数字样机，也不是维修训练仿真器。

- **公开影像高置信**：总体轮廓、三人制布局、125 mm 级主炮、六对负重轮、常见观瞄/RWS/ERA 等外部可见特征。
- **同系结构推定**：内部舱段相对位置、吊篮、自动装弹机与动力舱的功能性布局。
- **教学性概念化**：精确动力包外壳、管线、传动附件、乘员姿态、A1 APS 内部机理、无人机筒内部机构及 VT-4P 模块缝隙尺寸。
- 公开资料对动力功率存在 1200 hp 与 1300 hp 两种常见表述；应用按需求标注为“1300 hp 级”，并在部件说明中显示该差异。
- “VT-4P”在本应用中是便于界面区分的标签；巴基斯坦本地生产/展示车辆通常也以 **Haider** 名称出现。细节按公开照片近似，不宣称具备厂家图纸精度。

## 常见问题

### 页面提示 `navigator.gpu 不存在`

1. 更新 Chrome / Edge；
2. 在浏览器设置中开启“使用图形加速”；
3. 重新启动浏览器；
4. Linux 用户可参考 `SOURCES.md` 中 Chrome 官方 WebGPU 排障链接，必要时启用 Vulkan 与 unsafe WebGPU 实验开关。

### 页面黑屏但 UI 正常

打开 `chrome://gpu`，确认 WebGPU 不是 Disabled；更新显卡驱动并关闭可能强制软件渲染的远程桌面方案。

### 8K 导出失败

先尝试 4K；关闭其他占用显存/内存的页面；降低尘埃强度；等待累积过程完成后再进行其他操作。
