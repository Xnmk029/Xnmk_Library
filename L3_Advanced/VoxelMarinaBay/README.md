# VoxelMarinaBay：体素新加坡滨海湾与市中心

## 分类元数据

- **测试领域**: 3D 图形、物理仿真与 Shaders
- **难度等级**: `L3`（高级）
- **核心技术栈**: Three.js / Voxel / Procedural City
- **核心考核点**: 体素城市尺度还原、地标天际线辨识、上帝视角+第一人称、光影与动态环境
- **并列题**: [`VoxelLujiazui`](../VoxelLujiazui)（上海陆家嘴）、[`VoxelVictoriaHarbour`](../VoxelVictoriaHarbour)（香港维多利亚港）

## 任务定位

测试模型用体素语言搭建可探索的新加坡滨海湾数字沙盘，并同时给出宏观天际线与街巷尺度体验。
本题与陆家嘴、维港两题为并列同构题：同一考核维度、不同城市实体，便于横向比较模型对不同
城市肌理与地标体系的还原能力。

### 任务要点速览

- 精细体素：滨海湾水域与岸线、新加坡河口、路网与街区、莱佛士坊/CBD 塔楼群。
- 地标可辨识：滨海湾金沙（三塔基座 + SkyPark 悬臂）、艺术科学博物馆、鱼尾狮公园、UOB Plaza、One Raffles Place、Guoco Tower。
- 交通与桥梁：Marina Boulevard、Collyer Quay、Helix Bridge / Sheares Bridge 等，且必须有车流动态。
- 双模式：上帝视角环绕缩放 + 第一人称街道/滨水漫游，可切换且有操作说明。
- 电影感光影、材质区分（玻璃幕墙/混凝土/水面/沥青/热带绿化/木栈道）、至少一项动态环境效果。
- 单 HTML 优先；禁止抄袭工作区外项目、禁止贴图或视频冒充交互沙盘。

## 输出要求

- 单 HTML 可运行（CDN 引擎允许），双击即可打开。
- 模式切换与操作说明可发现。
- 无 TODO/占位；主体不依赖外部 glb 等模型下载。

## 自动化验收建议

- 静态：含可辨识的滨海湾金沙三塔与 SkyPark 轮廓、鱼尾狮公园岸线、CBD 塔楼簇；水域与岸线存在。
- 交互：至少上帝视角相机 + 第一人称移动两条路径；说明可读。
- 动态：存在帧循环驱动的环境效果（水面、车流、灯光或昼夜之一）。
- 性能：常规桌面首帧可接受；禁止静态截图式假交付。
