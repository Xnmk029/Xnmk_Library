# 任务背景

请构建一个可在浏览器中直接运行的三维项目：以 Low-poly 风格程序化营造一座**中国传统木构四角攒尖亭**，并在同一场景中呈现其**朝代形制演变**，同时提供**分层解构与构件观察**能力。本项目的核心目标是考核对传统大木作营造法则（材分制／斗口制、梁架层次、斗栱铺作、榫卯承托）的结构化理解，以及将其转译为纯代码程序化几何与可交互三维系统的综合能力。

# 需求范围

## 1. 运行环境

* 基于 Web 的单页可执行 3D 项目，技术栈自由，纯代码生成，不使用外部三维模型资产。

## 2. 核心任务

* **营造与结构全真**：以 Low-poly 风格构建一座结构严谨、完全符合传统木构营造法则的四角攒尖亭，真实体现梁架、斗栱与榫卯承托体系。
* **朝代形制演变**：在场景中呈现四角亭在不同历史时期的演变历程，体现各朝代在构件尺度、斗栱比例与屋面形态等结构特征上的演化差异。
* **交互解构与观察**：提供可自由探索的三维视角，支持对整座建筑的层级结构进行分层拆解与构件观察。

# 交付与限制要求

* **单页交付**：交付可直接运行的单页 Web 项目（单 HTML 文件或零构建静态工程均可），双击／打开即用，所需库仅通过可靠公共 CDN 引入。
* **零外部三维资产**：全部几何必须由代码程序化生成，不得引用任何 `.glb` / `.gltf` / `.fbx` / `.obj` / `.dae` 等外部模型文件。
* **承托链条闭合**：自台基、柱础、檐柱、额枋、斗栱、梁架、椽望至瓦作宝顶，各层级须形成连续且合逻辑的受力承托关系，构件不得悬浮、错位或互相穿模。
* **形制差异可核验**：朝代演变必须体现为可读的结构参数差异（构件尺度、斗栱比例、屋面举折／举架等），而非仅更换配色或替换标签文字。
* **代码完整闭合**：不得包含 TODO、占位实现或要求用户补齐核心算法的说明；运行时控制台无报错。
* 完成后用中文简要说明营造参数体系、层级装配架构与朝代演变的实现方式。
