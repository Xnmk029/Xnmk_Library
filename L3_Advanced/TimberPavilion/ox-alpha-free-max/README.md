# 四角攒尖亭 · 木作流变

Low-poly 程序化营造的**中国传统木构四角攒尖亭**，在同一场景中并置呈现**唐 → 宋 → 明 → 清**四代形制演变，并提供**分层解构、构件观察与承托受力链演示**。

- 交付形态：单 HTML 文件（`index.html`），双击即用
- 唯一外部依赖：Three.js r128（jsdelivr / unpkg / cdnjs 三路公共 CDN 自动回退）
- 零外部三维资产：全部几何（台基、柱础、柱、额枋、斗栱、梁架、椽望、瓦垄、垂脊、宝顶）均由代码程序化生成

---

## 一、运行方式

1. 直接双击 `index.html`（`file://` 协议即可运行，需联网加载 Three.js CDN）。
2. 操作：
   - 左键拖动旋转视角；右键（或 Shift + 拖动）平移；滚轮 / 双指缩放
   - 点击左侧朝代按钮（或快捷键 `1–4`）聚焦单朝代，`0` 返回全景对照
   - 拖动「分层解构」滑杆（或按 `E`）：九层结构逐层竖向拆解
   - 悬停构件显示名称与受力作用；点击构件在右侧面板查看细节
   - 可开关：层级标注、承托受力链（荷载脉冲自宝顶向下流动）、自动环视、投影

## 二、营造参数体系（形制差异的可核验来源）

每个朝代是一组结构参数，而非贴图或配色变化。核心参数及其转译：

| 参数 | 含义 | 唐 | 宋 | 明 | 清 |
|---|---|---|---|---|---|
| `u` 模数 | 宋·材分（材高/15）/ 清·斗口 | 0.075 | 0.066 | 0.052 | 0.048 |
| `jumps` 出跳数 | 斗栱踩数 | 3 跳 | 2 跳 | 1 跳 | 1 跳（无昂） |
| `ang` 下昂 | 斜置杠杆构件 | 有（雄健） | 有 | 有（趋装饰） | **无（耍头平出）** |
| `rise` 举高比率 | 屋顶举高 / 檐口平距 | 42% | 50% | 62% | 70% |
| `k` 曲线指数 | 屋面凹曲程度（举折→举架） | 1.55 | 1.75 | 2.00 | 2.25 |
| `colR/colH` | 柱径∶柱高 | ≈1∶7.3 | ≈1∶8.4 | ≈1∶9.0 | ≈1∶9.9 |
| `ceJiao` 侧脚 | 柱顶内倾量 | 55‰ | 65‰ | 32‰ | 18‰ |
| `puPai` 普拍方 | 柱头圈梁（宋始盛） | 无（阑额出头） | 有 | 有 | 有 |
| `pingKe` 平身科 | 补间斗栱攒数 | 0（人字栱） | 1 | 2 | 2 |
| `fei/upLift` | 飞椽出挑 / 翼角起翘 | 深/缓 | 中 | 短/高 | 最短/最高 |

右侧信息面板实时列出所选朝代的上述派生值（斗栱高∶柱高、出檐距离等），并给出「较前代 ±%」的量化对比。

## 三、层级装配架构（承托链条闭合）

九个图层自下而上装配，每层的支承标高由其下构件实测顶面推出（`computeLayout()` 为唯一数据源），保证不悬浮、不错位：

```
⑨ 宝顶        宝珠/须弥座/宝顶座 —— 压固于雷公柱柱顶
⑥⑤ 梁架       雷公柱 ← 太平墩 ← 井字梁(刻半搭交) ← 平身科里跳升顶
              老/仔角梁：角科斜昂 → 雷公柱柱身（榫端止于柱面）
④ 斗栱铺作    坐斗 → 华栱/横栱逐跳出跳（升承上跳）→ 令栱+昂/耍头
              撩檐枋环形搁置于令栱外端升与昂尖之上
③②① 柱网     檐柱（卷杀收分＋侧脚内倾）→ 柱础（鼓磴/覆盆）→ 台基（多层＋阶条石＋踏步）
④' 额枋层     大额枋（唐式出头）／普拍方（宋起）／小额枋+由额垫板（明清）
⑥' 椽望       檐椽下搁撩檐枋顶、上向雷公柱收束；飞椽叠其背放缓出翘；封檐板围合
⑦ 瓦作        板瓦/筒瓦垄随椽放射交替，滴水收檐口；四条垂脊沿角部下垂至嫁兽
```

受力路径可视化：开启「承托受力链」后，金色脉冲粒子沿
**宝顶 → 雷公柱 → 井字梁交点 → 角科 → 柱头 → 柱脚 → 柱础 → 台基 → 地面**
的四支路径循环流动，直观呈现荷载传递闭环。

## 四、朝代演变的实现方式

1. **同一生成器、不同参数**：四座亭由同一个程序化装配函数以四组朝代参数实例化，并列置于场景中，地面箭头标注相邻两代间的演变要点。
2. **差异落在几何上**：
   - 斗栱：模数缩小 + 出跳减少 + 下昂消失 → 斗栱占柱高比例由唐 ~20% 降至清 ~8%
   - 屋面：`y = y檐 + H·t^k` 的幂函数剖面，H 与 k 共同把唐「举折平缓」连续过渡到清「举架陡峻」
   - 出檐 = 柱外斗栱出跳 + 撩檐枋悬距，唐深远、清收敛
   - 柱身径高比、侧脚角度、普拍方有无、阑额出头、人字栱/平身科数量、台基层数等均为可读的结构差异
3. **聚焦比对**：选择某朝代时其余三亭幽灵化（透明 + 停用投影），相机推近，右侧规格表给出与前一代的百分比增减，便于逐项核验。

## 五、技术要点

- Three.js r128 UMD 版，多 CDN 顺序回退加载，失败时给出明确提示
- 自研轨道相机（旋转 / 平移 / 缩放 / 双指捏合 / 阻尼 / 自动环视），零额外依赖
- 全部构件为 Box/Cylinder/Icosahedron 低分段体素 + flat shading；瓦垄、望板、垂脊经自写合并器合成单网格（顶点色），控制绘制调用
- Canvas 动态生成中文标注 Sprite；射线拾取 + 材质克隆实现逐构件高亮与详情
- 全部功能完整闭合：无未完成桩件、无占位实现；正常加载运行时控制台无报错
