# 四角攒尖亭 · 实现说明

## 一、营造参数体系（材分制／斗口制的比值演绎）

全部几何由 `STYLE` 朝代参数表驱动（answer.html 内 CORE 段），核心字段：

| 字段 | 含义 | 唐 | 宋 | 明 | 清 |
|---|---|---|---|---|---|
| colH / colD | 柱高／柱径 (m) | 3.40 / 0.52 | 3.50 / 0.42 | 3.60 / 0.38 | 3.70 / 0.34 |
| span | 面阔＝进深（柱中距） | 4.20 | 4.30 | 4.35 | 4.40 |
| nPing | 每面补间铺作攒数 | 1 | 2 | 3 | 4 |
| dgH | 斗栱全高（栌斗底→令栱散斗上皮） | 1.52 | 1.26 | 0.94 | 0.70 |
| eaveOut / flyOut | 檐出／飞椽伸出 | 1.80 / .55 | 1.60 / .48 | 1.35 / .42 | 1.20 / .38 |
| raise | 举高／进深 | 0.245 | 0.275 | 0.310 | 0.350 |
| jvZhao | 屋面算法 | 举折 | 举折 | 举架 | 举架 |
| shouFen / ceJiao / shengQi | 收分率 / 侧脚 / 生起 | 大→小 单调 |
| waLu / tileC | 瓦垄数／瓦色 | 7 青灰 → 10 黄琉璃 |

五项可核验比值由 `metrics(P)` 从参数即时计算并在左栏表格中以趋势条呈现：
斗栱高/柱高 0.447→0.189（大→小）、补间攒数 1→4（疏→密）、檐出/柱高
0.529→0.324（深远→收浅）、举高/进深 0.245→0.350（平缓→陡峻）、柱高/柱径
6.54→10.88（粗壮→修长），四期单调、方向与史实一致（node 断言 A1a–A1e 实测通过）。

`deriveDims()` 是唯一的高度链数据源：台基顶 0 → 柱础顶 zuT → 柱顶 colT（含生起）
→ 普拍枋底 = colT → 铺作底 keBase → keBase + dgH = 铺作顶（单攒积木恰为
2.35u 分层累计）→ 撩檐枋 → liaoTop 锚定屋面剖面曲线 → 脊高 apAbs。
斗栱单攒内部以 u = dgH/2.35 归一，故任何朝代令栱散斗上皮恒等于 dgH 名义值。

## 二、屋面几何：举折／举架的两种真实算法

`profPts()/profYAt()` 将屋面竖剖面生成为分段折线（每段斜率表即"逐缝递减"
的举折或"五举→九举递增"的举架；末段缓延供飞椽趋平）。共享求值器
`surfPt(方位 A, 法线距 ξ, 抬升 lift)` 用 squareRad 做方形平面收缩，
**椽、望板、瓦垄、垂脊、瓦面壳全部取自同一曲面公式，仅层间受控 lift**
（椽底=datum，飞椽叠其上，望板压椽背，瓦垄贴板），因此构件间无悬浮、无穿模；
四条戗脊线与坡面天然同源。

## 三、层级装配架构（7 层 · 重力序）

L0 台基·柱础（含踏步、两层古镜础）→ L1 檐柱（收分圆锥段＋侧脚倾斜+
管脚榫/馒头榫）→ L2 额枋·普拍枋（燕尾榫双阶楔＋卯口贴片＋箍头榫卡口＋
刻半十字搭交环）→ L3 斗栱铺作（角位共用大斗＝两翼角位柱头科正向出跳＋
转角科 45° 斜出＋宝瓶；各面平身科 nPing 攒；撩檐枋四面刻半搭交成环）→
L4 梁架（抹角梁骑压撩檐枋背—搭掌榫台阶；交金瓜柱托金檩十字交点；
老角梁前端经宝瓶压角科、尾入金檩结点；仔角梁续伸起翘；四由戗向心抵
雷公柱腰部并穿销锁定；雷公柱垂莲收尾上承宝顶）→ L5 椽望（檐椽/飞椽/
翼角翘飞椽扇形辐射＋环形满铺望板＋大小连檐）→ L6 瓦作（连续瓦面壳＋
顺坡筒瓦垄＋四垂脊渐收＋须弥座宝珠宝顶）。

爆炸拆解按 LAYERS[].off 竖直分层抬升，滑块连续可逆；卯口贴片与榫头随各自
所属层分离后互补呈现。七类榫卯（燕尾榫、馒头榫、箍头榫、搭掌榫、
十字搭交榫、管脚榫、穿销）全部为真实几何体而非贴图文字。

## 四、朝代演变的实现方式

- **同一套程序化管线，仅换参数**：切换朝代＝换 STYLE 一行参数重建，
  尺度（柱径/斗栱高/檐出）、比例（攒数、举折曲线段斜率序列）、形态
  （翼角翘升量=shengQi、侧脚角=ceJiao、瓦垄密度、清式黄琉璃材质
  metalness 提升）同步变化——差异是结构性的，不是配色与标签。
- **并置对比模式**：一键生成唐宋明清四座 0.46 缩放模型同场排布，
  相机一次取景（用户主动触发）；任何朝代重建均不动相机与拆解状态。

## 五、工程与交互

- 合批：檐椽/飞椽/翘飞/望板/筒瓦垄五大宗族 InstancedMesh（约 500–1000
  实例），其余构件按类别共享少量 MeshStandardMaterial（flatShading 低模）。
- 拾取：Raycaster 直射 registry 扁平列表；InstancedMesh 经 instanceId 映射
  recMap 输出"构件名 · 第 N 根"；命中后 BoxHelper 高亮＋emissive 提亮＋
  右侧信息卡给出名称/术语/功能说明。
- 观察工具：轨道相机、层级显隐（隔离）、仅看榫卯、名称标注（锚点挂层级组，
  爆炸时自动跟随）、线框、可滑动剖切（全局 clipping plane）、自动旋转。
- 自测：CORE 段以标记抽取后在 Node+three@0.160.0 无头运行，
  35 项断言（趋势单调×5、四朝全量构建、承托链 bbox 实测、榫卯 7 类、
  合批计数、NaN 扫描等）全部通过。

## 六、已知简化（诚实声明）

- 低模语境下铺作内部按"分层积木"堆叠表达（华栱与泥道栱正交关系以造型示意），
  未做真 CSG 开槽；卯口以深色互补贴片呈现。
- 金檩为方环刻半搭交简化（未含檩椀），椽尾直接搁檩背；天花及其以上构造省略。
- 生起在四角亭中因无次间平柱，表现为全柱统一抬高基准＋翼角翘飞增量起翘。
- 浏览器内真实运行画面未能在本环境截图验证（无头环境无 WebGL），
  已用 Node 无头几何断言＋全文语法检查替代，详见 log.md。
