# 攒尖亭：四角亭木构营造与朝代演变

## 分类元数据

- **测试领域**: 3D 图形、物理仿真与 Shaders
- **难度等级**: `L3`（高级）
- **核心技术栈**: Web 3D（程序化几何 / Low-poly flat shading，技术栈自由）
- **核心考核点**: 传统大木作营造法则的结构化建模（材分制／斗口制、铺作、梁架、榫卯）、参数化朝代形制演变、分层解构交互与构件语义标注

## 任务定位

测试模型能否把**领域知识（中国古代建筑营造法则）**转译为**严谨的程序化三维结构**：不仅要"看起来像亭子"，还要求自台基至宝顶的承托链条连续可信，斗栱铺作、梁架与榫卯关系正确，并能以参数化方式表达唐—清各代在构件尺度、斗栱比例与屋面形态上的演化趋势，最后通过分层拆解与构件拾取暴露内部结构。

## 自动化验收建议

- **构架完整性**：自下而上须齐备 ① 台基与柱础 ② 四根檐柱（含侧脚等做法）③ 阑额／额枋与普拍枋／平板枋 ④ 斗栱铺作（**柱头科、平身科／补间、转角科三类齐备**，栌斗／坐斗、华栱／翘、昂、令栱、散斗、耍头可分辨）⑤ 梁架（抹角梁或簇角梁、雷公柱、老角梁＋仔角梁／由戗）⑥ 椽望（檐椽、飞椽、翼角翘飞椽、望板、连檐）⑦ 瓦作、垂脊与宝顶。检查各层坐落关系连续，无悬浮、无穿模。
- **榫卯体系**：至少 5 类可辨榫卯（如燕尾榫、馒头榫、箍头榫、搭掌榫、十字搭交榫），榫头与卯口形状互补且在拆解／剖切状态下可见，而非以贴图或文字代替。
- **朝代形制差异**：至少 4 个历史时期，且以下比值须给出可读数值并符合史实趋势——斗栱高／柱高（唐宋大 → 明清小）、补间铺作／平身科攒数（疏朗 → 密集）、檐出／柱高（深远 → 收浅）、举高／进深（平缓 → 陡峻）、柱高／柱径（粗壮 → 修长）；应提供并置对比或切换对比手段。
- **交互解构**：自由轨道视角（旋转／缩放／平移）；分层拆解覆盖 ≥6 个层级，支持连续控制且可逆归位；单构件拾取高亮并给出名称、术语与功能说明；具备隔离、线框或剖切等辅助观察方式。
- **工程质量**：控制台无 error；常规桌面分辨率下交互帧率稳定（构件数量较多时应使用实例化或合并几何等合批手段）；朝代切换后相机与拆解状态不发生异常重置或几何残留。
