## 实现说明

### 静态展示

- **全程序化建模**：164 个 mesh，全部由代码生成，未加载任何外部 3D 模型。
  自建三个低多边形几何构造器：
  - `taperedBox(w,h,d,{top,bottom,topOff,bottomOff,chamfer})` — 支持上下端面缩放/偏移/切角的锥台，用于套筒、机匣、握把等带拔模斜度的零件；
  - `polyCyl(rt,rb,h,sides,axis)` — 低边数棱柱（6~10 边），用于枪管、准星光纤、销钉；
  - `polySphere` — 用于标注锚点。
- **分解部件**（5 个，均为真实机械分离方向）：深色金属套筒（锁定在后，含抛壳口、防滑纹、枪机面）、亮银色裸露枪管（含弹膛块、闭锁凸榫）、聚合物下机匣（含导轨、海狸尾、防滑纹握把、扳机护圈、击锤）、前部 Match 配重/补偿器（带排气槽）、分离弹匣（带观察孔、托弹板、黄铜弹）。
- **光纤准星**：前准星亮绿 `0x39ff6a`、后准星红 `0xff2b34`，均为自发光材质并做缓慢呼吸脉动；套筒后拉/复位全程保持可见。
- **PS1 复古质感**：
  - 自定义顶点着色器做**屏幕空间顶点吸附 + 抖动**（PS1 标志性顶点抖动）；
  - 内部渲染降采样 + `NearestFilter`，产生粗像素帧缓冲；
  - 后处理 4×4 Bayer **有序抖动**（色彩分层）、CRT 扫描线、桶形畸变、边缘色散、暗角；
  - `MeshLambertMaterial` + `flatShading`（157/157 受光 mesh，已验证）；
  - 程序化 canvas 噪点纹理（64px，`NearestFilter`）模拟 90 年代像素贴图；
  - `BasicShadowMap` — 硬边块状阴影，符合 PS1 无柔和阴影的特征。
- **背景/视角**：中性浅灰 `0xb4b4b4`；默认近正交（18° 长焦）+ 可选真正交；三点式影棚布光。

### 机械动画

7.2s 无缝循环，分阶段沿真实轴线运动（非放射式爆炸）：

1. 弹匣沿 **Y 轴垂直**滑入/退出握把；
2. 套筒沿 **-X 沿机匣导轨**后拉（越过裸露枪管）后复位；
3. 套筒让位后枪管 **+Y 抬起**并带连杆下摆倾角；
4. 补偿器沿 **+X** 从枪口螺纹旋出。

联动细节：复进簧仅在套筒离架后显现并随行程展开；击锤随套筒后移而被压倒。
循环采用 `t<0.5 展开 / t>0.5 回装` 的对称映射，保证首尾严格闭合。

### 可选高阶项：AR-15

15s 慢动作分解，**严格机械关联、按真实枢轴/滑轨运动**：

1. 弹匣垂直落下；
2. 拉机柄后拉，带动枪机框（BCG）；
3. **后分解销横向退出** —— 上机匣在此销退出约 85% 后才被允许转动（互锁，验证通过）；
4. 上机匣绕**真实前枢轴销**打开约 35°；
5. BCG 沿上机匣导轨后移，复进簧/缓冲管同步压缩；
6. 枪机头旋转 22.5° 解锁（真实 AR 闭锁凸榫角度）。

可视化小部件：拉机柄、抛壳挺、复进簧/缓冲管、击锤、扳机、阻铁、击发断开器、弹匣释放、空仓挂机、保险、助推器、导气座、导气管、导气键、抽壳钩、击针、弹匣。
材质为哑光黑阳极氧化铝 + 深色钢，影棚布光，CAD 风格引出线标注。

### 过程中定位并修复的问题

1. **动画"跳变"误报**：初版以"单步位移 < 0.12"判定跳变，枪管在 t≈0.275 处测得 0.324 被判失败。
   进一步用**步长减半法**复核（120 → 480 采样，位移 0.3238 → 0.0825，比值 3.92 ≈ 4），
   确认这是缓动峰值速度而非真实不连续；遂改用连续性判据替代速度阈值。
2. **flat shading 统计口径**：初版把 7 个 `MeshBasicMaterial`（标注锚点、背景色镂空块）
   也计入，误判失败；改为只统计受光材质。同时发现地面平面漏设 `flatShading`，已在源码补上。
3. **外部资源检测误报**：正则 `.obj` 命中了代码里的 `p.obj.position`；
   改为只匹配加载器标识符与带引号的资源路径。
4. **AR BCG 断言方向错误**：初版假设 BCG 在整个枢轴过程中保持在前方，
   与"BCG 在机匣打开后才后移"的设计相悖；改为断言阶段顺序与互锁关系。
5. **构建脚本非幂等**：`build.py` 曾把输出文件当作模板读取，重复执行会自我追加导致体积翻倍；
   改为从独立 `template.html` 读取，已验证连续两次构建均为 48293 字节。
