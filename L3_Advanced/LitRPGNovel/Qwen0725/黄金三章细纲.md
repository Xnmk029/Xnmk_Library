# 《方块深渊》黄金三章细纲

## 设计原则
- 三章内完成"世界观建立+核心悬念抛出+读者粘性锁定"
- 第一章：感官冲击+认知颠覆（"这是什么地方？"）
- 第二章：生存压力+机制发现（"怎么活下去？"）
- 第三章：恐惧升级+悬念钩子（"死了会怎样？"）

---

## 第一章：直角（约2000字）

### 场景流
苏醒与环境观察 → 第一次触碰方块 → 发现物理法则异常 → 黄昏降临+远处威胁暗示

### 分镜细纲
1. **开场（300字）**：沈既白脸朝下趴在草地上。先给触觉——草叶刺扎脸颊，但"草"的触感不对，太硬、太均匀、像塑料丝。翻身。睁眼。天空是过饱和的蓝。太阳——方形的。
2. **环境观察（400字）**：坐起来。环顾。草原延伸至地平线。所有"草"一样高。所有"泥土"是完美的1m³方块。远处一棵橡树——树干是方形截面，树冠是球形？不，是"方块堆砌的近似球形"。没有风。没有鸟鸣。安静得不正常。
3. **第一次触碰（400字）**：他伸手摸地面。指尖触到泥土方块的边缘——完美直角，90度，无误差。用指甲抠——泥土以"整块"的形式碎裂，不产生碎屑，裂面光滑如切割。他站起来，走向那棵树。手掌按上树干。木纹是"贴图"——平面印刷在方块表面，没有年轮，没有树皮的凹凸。
4. **认知崩塌（400字）**：他蹲下，试图挖一块泥土。手指插入泥土与泥土的"接缝"——接缝是完美的直线。用力。一整块泥土脱离地面。然后——它悬浮了。脱离地面的泥土块静止在半空，不掉落。他松手。它依然悬浮。沈既白后退一步。心跳加速。他抬头看那棵树——树冠底部距离地面两米。没有支撑。它不应该悬在那里。
5. **黄昏+悬念（500字）**：太阳在移动。匀速。太快了。光线从正午的白转为橘黄，只用了十几分钟。影子在拉长。温度在下降。沈既白意识到——他没有庇护所，没有工具，没有食物。草原尽头，光线照不到的阴影中，有什么东西在动。一个模糊的轮廓。人形。但姿态不对——肩膀塌陷，头歪着，像在"嗅"什么。一声低沉的喉音从那个方向传来。沈既白开始跑。

### 本章钩子
- 核心悬念：这是什么世界？为什么物理法则不对？
- 情绪钩子：黄昏+未知威胁=生存恐惧
- 断点：主角在跑，身后有东西在追

## 第二章：七拳（约2000字）

### 场景流
夜间躲避 → 第一次"空手撸树" → 物品栏体验 → 合成机制的惊悚 → 天亮

### 分镜细纲
1. **夜逃（300字）**：沈既白跑。身后的喉音不止一个——三个、五个、更多。他不敢回头。月光（方形）照亮前方的地形。他看见一个天然"凹坑"——三面泥土墙，一面敞开。他冲进去，蹲下，用手扒拉旁边的泥土块试图"堵"住缺口。
2. **徒手挖土（300字）**：手指插入泥土接缝。拔。一整块脱离。他把它塞到缺口处。刚好。1m×1m。完美契合。他继续挖。手指已经破了，指甲缝里全是泥。但痛觉告诉他这是真的。他用泥土把自己封在一个2×1×1的空间里。完全黑暗。外面的喉音近了。有东西在"撞"他刚封上的泥墙。一下。两下。墙没碎。
3. **漫长的夜（300字）**：黑暗中计数。呼吸声。外面的撞击持续了约二十分钟后停止。取而代之的是"咔嗒咔嗒"——像骨骼碰撞。然后安静。沈既白不敢动。他数着自己的心跳。一千下。两千下。光线从泥土缝隙中渗入。天亮了。
4. **第一次撸树（500字）**：他拆掉泥墙出来。阳光。安全。他需要工具。记忆中有"游戏"的知识——Minecraft。空手撸树。他走到那棵橡树前。攥拳。砸下去。第一拳：木刺扎入指缝。痛。他咬牙。第二拳。第三拳。树皮（贴图）碎裂，露出下面均匀的木质。第四拳。第五拳。手掌已经血肉模糊。第六拳——他几乎要放弃。第七拳。树干"碎了"。不是断裂——是整块木头突然缩小，旋转，被"吸入"他的掌心。手掌处的空间短暂塌陷。木头消失了。他的手中什么都没有。但"意识"中多了一个"格子"，格子里有一块橡木原木。
5. **合成+天亮（600字）**：他蹲在地上，盯着自己的手掌。五分钟。然后他"知道"了——不是"学会"，是"本能地知道"——把原木"分解"，可以得到木板。他在意识中"操作"。原木消失。四块木板出现在手中。然后——他把四块木板按2×2排列放在地上。它们开始震动。低频嗡鸣。木板之间的缝隙发出微光。然后——它们融合了。没有钉子、没有胶水、没有外力。四块独立的木板自行"生长"为一个工作台。沈既白后退三步。他盯着工作台。工作台安静地蹲在草地上。像什么都没发生。他咽了口唾沫。远处，方形太阳完全升起。新的一天。

### 本章钩子
- 核心悬念：物品栏和合成的"机制"到底是什么？
- 情绪钩子：第一次夜间生存的恐惧+机制发现的惊悚
- 断点：工作台的出现意味着"更多可能"——但也意味着"更多未知"

## 第三章：球形（约2000字）

### 场景流
制作工具 → 第一次击杀 → 饥饿与进食 → 苦力怕爆炸 → 第一次死亡与重生 → 记忆缺失

### 分镜细纲
1. **工具（300字）**：工作台。沈既白"知道"配方——木棍、木镐、木剑。制作过程：材料放上去，物质再次自行融合。他已经不会后退了。但手在抖。木镐入手——重量、质感、握持感，完全真实。像一把真正的工具。
2. **第一次杀（400字）**：一只猪。他需要食物。木剑刺入猪的颈部——阻力。皮肉。温热的血溅在手背上。猪尖叫。他拔剑。再刺。猪倒下。他蹲在旁边干呕了三十秒。然后他"知道"——生肉不能吃。需要"熔炉"。需要"燃料"。他做了。烤猪排的气味。咬下去。热量在数秒内从胃部扩散到四肢——太快了。违反生理学。但他顾不上了。
3. **苦力怕（400字）**：下午。他在挖石头（木镐敲碎石块，石粉呛入气管）。专注。没有注意到身后的"影子"。直到——"嘶……"极轻的。像引线燃烧。他转头。一个绿色的人形。没有表情。体表在"膨胀"。他跑。一步。两步。爆炸。气浪。肋骨碎裂的声音——他"听见"了自己骨头断的声音。痛。无法呼吸。视野变红。变黑。
4. **重生（400字）**：光。草原。他躺在草地上。身体完好。没有伤口。没有血。他坐起来。手摸肋骨——完整。呼吸——正常。他活着。但——他试图回忆爆炸前的画面。嘶声。转头。绿色。膨胀。然后……然后是什么？他跑了几步？一步？两步？他记不清了。那段记忆——从"嘶声"到"黑暗"之间的三秒——消失了。干干净净。像被人用橡皮擦从大脑中抹去。
5. **日志+悬念（500字）**：他回到死亡地点。物品散落。捡起。爆炸坑——完美的球形凹陷。半径三米。泥土、石头、草，全部消失。球面光滑如镜。他站在坑边。手在抖。然后他发现——草地上多了一样东西。一本书。牛皮封面。空白。他翻开。第一页有字。他的字迹。写着："爆炸前最后三秒：你跑了两步。第二步时左脚绊到了草。你摔倒了。所以气浪是从背后来。"他看完。文字褪色。消失。页面重新变为空白。他翻到最后一页。一行字。也是他的字迹。但墨水更旧。像写了很久。"别去末地。"沈既白合上书。方形太阳正在西沉。他还有大约十分钟的天光。他需要一面更厚的墙。

### 本章钩子
- 核心悬念：死亡代价是记忆。日志是什么？"别去末地"是谁写的？
- 情绪钩子：第一次死亡的冲击+记忆丧失的恐惧
- 断点：新悬念（日志、末地）+生存压力持续（天快黑了）
