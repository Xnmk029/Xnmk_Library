# 任务背景

你现在是一位精通"游戏异世界（LitRPG）"题材的资深小说家，以细腻的心理描写和极强的画面构建能力著称。请以《我的世界》（Minecraft）为世界观背景，创作一部硬核生存长篇小说。

# 需求范围

## 工作流程

1. 先进行搜索，找到一些用于优化 AI 网络小说文风的写作方法/技能（Skill），并自行部署到工作区。
2. 基于下述设定构建一个完整世界观，以及一份**约 50 万字规模的全书大纲**。
3. 细化出"黄金三章"章节细纲。
4. 根据细纲开始进行前三章内容输出。

## 第一章创作要求

- 主角是一个带有现实世界记忆的普通人，突然在这个由方块构成、物理法则完全不同的世界中醒来。
- **物理法则的割裂感**：生动描写主角面对"不科学"现象时的认知冲击——被破坏的泥土块悬浮在空中、没有重力的树冠、完美的直角边缘等。
- **游戏机制的现实化**：不得用枯燥的"系统提示音"或"网游日志"敷衍。将游戏机制（空手撸树、合成表、物品栏空间、饥饿值）转化为真实的生理和心理体验——空手击打树干时木刺扎入皮肤的痛感、原木突然缩小并被吸入体内的诡异感、发现合成台不需要钉子和胶水就能融合物质的惊悚感。
- **感官与情绪拉扯**：主角不应是立刻接受设定的无情速通玩家。着重描写最初的迷茫、孤独，以及面对黄昏降临、丧尸低吼时发自内心的生存恐惧。
- **正文红线**：正文中不得出现"不是……而是""如何……但"、破折号、不合时宜的比喻。

## 格式与风格标准

- 视角：第三人称限制视角（聚焦主角）或第一人称视角。
- 文笔：硬核、写实、带悬疑感，拒绝轻小说式的轻松吐槽。
- 单章字数：1500–2000 字。
- 场景流：苏醒与环境观察 → 第一次尝试互动（破坏方块/收集物资）→ 发现游戏机制的诡异之处 → 太阳西沉带来的环境压迫感（本章结束，留有悬念）。
- 请直接开始正文创作，不要包含任何前置或后置的解释性废话。

# 交付与限制要求

- 交付文件齐全：世界观文档、全书大纲、黄金三章细纲、前三章正文。
- 检查字数、视角一致性、禁用表达（正文红线）与章节结构。
- 世界观/大纲/细纲/正文以清晰的 Markdown 文件组织。
