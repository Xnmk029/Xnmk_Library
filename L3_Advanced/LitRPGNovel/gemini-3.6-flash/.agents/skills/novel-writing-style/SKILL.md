# 网络小说写作文风优化 Skill

## 1. 核心创作原则

### 1.1 消除“AI味”（去机械感）
* **拒绝总结性句式**：禁止在段末或总结处使用“这一刻，他意识到……”“这意味着……”等升华套话。
* **拒绝机械比喻**：禁止使用“如同被锤子重击”“仿佛时间静止”等陈腐或不合时宜的比喻。
* **动作与感官优先**：用生理疼痛、视觉异质感、环境压迫感的具体描写取代抽象的情感名词（如将“他感到害怕”替换为肌肉痉挛、瞳孔收缩、后背发凉的生理反应）。
* **硬核写实沉浸**：对游戏机制进行现实物理化拆解，注重机制与人类现实常识碰撞产生的异质惊悚与未知恐怖。

### 1.2 严格句式禁忌（ Negative Constraints ）
正文中**绝对禁止**出现以下句式与标点：
1. `不是……而是`（以及类似的对照对仗套式）
2. `如何……但`（以及句中转折套路句式）
3. 破折号`—` 或 `--`（严禁使用任何形式的破折号）
4. 不合时宜的比喻（如修仙/科技等跨界乱入比喻）

### 1.3 视角与语调
* **视角**：第三人称限制视角（严密聚焦主角感官与知觉范围），或第一人称视角。
* **语调**：写实、硬核、带悬疑与生存张力。严禁轻小说风格的吐槽、网游面板弹窗敷衍、无意义对白。

## 2. LitRPG 游戏机制现实化转化指南

| 游戏机制 | 传统轻小说处理（禁止） | 硬核现实化转化（要求） |
|---|---|---|
| 空手撸树 | 弹窗提示：木材+1 | 木刺扎入手掌掌肉的剧痛、皮肤破裂出血、木质纹理撕裂的沉闷钝响、原木瞬间缩微并没入体内的诡异触感 |
| 方块悬浮 | 忽略或吐槽“这不符合牛顿定律” | 视觉上的强烈割裂与生理眩晕感，完美直角的切口、没有落叶与崩塌的悬空树冠造成的认知失调 |
| 物品栏 | 打开UI界面查看格子 | 无法用语言解释的体内空间积压感、物质被抽离世界的空洞感 |
| 工作台合成 | 点击按钮一键合成 | 四个原木块置于光滑木台上，无须钉子、胶水或任何衔接件，物质分子层面强制无缝榫合的惊悚过程 |
| 黄昏与夜间怪物 | 提示“怪物将在夜晚刷新” | 光线拉长阴影、气温骤降带来的寒意、远处黑夜中骨骼碰撞与腐肉拖行发出的低吼造成的本能生存恐惧 |

## 3. 场景流与节奏控制

1. **第一阶段：苏醒与异质物理环境观察**（触觉、视觉、认知冲击）
2. **第二阶段：第一次生存互动尝试**（生理疼痛、物质破坏的怪异反馈）
3. **第三阶段：游戏机制现实化与深层恐惧**（无缝合成、空间物品收纳）
4. **第四阶段：昼夜交替的压迫感与悬念留白**（环境变化、生物低吼、求生本能）
