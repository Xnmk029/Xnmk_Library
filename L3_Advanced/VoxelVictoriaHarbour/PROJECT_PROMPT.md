# 任务背景

生成一个**体素风格的香港维多利亚港数字沙盘**。本项目的核心目标是考核模型在体素化城市尺度还原、两岸空间关系、标志性建筑识别度、上帝视角与第一人称双模式漫游、以及光影/氛围营造上的综合能力。

# 需求范围

## 城市与空间还原

- 使用**极其精细的体素**还原香港维港真实城市风貌，包括但不限于：
  - 维多利亚港海面、港口与岸线转折（尖沙咀海滨、中环 / 湾仔海滨）
  - **两岸城市布局**：港岛一侧（中环、金钟、湾仔）与九龙一侧（尖沙咀、西九龙）须可同时辨认，不得做成单岸贴图墙
  - 高密度城市街区肌理与路网
  - 标志性超高层与地标（须可辨识，至少包括：**国际金融中心二期（IFC Two）**、**环球贸易广场（ICC）**、**中银大厦**；并体现其分处两岸、相对高度与轮廓差异）
  - 港岛背后的山体轮廓（太平山 / 维多利亚峰一带的天际线衬底）
  - 港口设施可简（码头、渡轮航线感、防波堤等），但海面与港口空间必须存在
  - 极具辨识度的香港维港城市天际线

## 视角与交互

- **上帝视角**：可完整展示香港维港两岸与海面的宏大规模，支持缩放 / 环绕观察（轨道相机或等价控制）。
- **第一人称沉浸**：玩家可进入体素世界，在城市街道、海滨、码头与建筑之间自由移动探索，感受真实尺度与城市空间震撼。
- 两种模式应可切换，控制说明清晰。

## 光影、材质与环境

- 电影级光影目标：合理日夜或主光方向、阴影与氛围光，避免纯平涂塑料感。
- 真实材质感（在体素风格约束下）：玻璃幕墙、混凝土、水面、道路、绿化、山体等应有材质区分。
- 动态环境效果（至少其一）：水面波动、渡轮 / 车流、云层 / 雾、灯光呼吸或昼夜切换等。

## 风格定位

- 将体素艺术与数字孪生 / 开放世界体验结合；目标是**艺术级、游戏级**的香港维多利亚港体素世界。
- 尽最大程度展现空间理解、建筑还原、视觉设计与沉浸式体验能力。

# 交付与限制要求

- 优先交付**单 HTML**（Three.js 等引擎可通过可靠 CDN 引入），双击即可运行。
- 建筑与城市布局以程序化体素构建为主；不使用需要联网下载的外部 3D 模型文件作为主体（CDN 引擎库除外）。
- 不得抄袭工作区外的项目；不得只用一张贴图或视频冒充交互沙盘。
- 不得包含 TODO 或未完成占位符。
- 控制方案与模式切换方式需在界面上或 README/log 中说明。
