# 任务背景

你是一位资深 Web3D 图形开发者与技术美术（TA）。请编写一个网页版"3D Poolrooms（池核）"步行模拟器：在 Web 端构建一个无尽生成的阈限空间（Liminal Space），画面风格对标 Unreal Engine 5（Lumen + Nanite）的室内建筑可视化水准。不仅要实现物理上的 PBR 真实感，更要精准还原"池核"美学中潮湿、压抑、孤独且带有轻微模拟失真（Lo-Fi）的心理恐怖氛围。

# 需求范围

## 1. 空间生成逻辑（Procedural Architecture）

- 空间由正交几何体构成（笔直的走廊、方形立柱、对称的阶梯、平台、浅水区与深水区）。
- 无限随机生成：使用 Wave Function Collapse（波函数坍缩）、网格迷宫或自研等价算法，在玩家移动时**动态加载/卸载区块**。
- 场景内**绝对禁止**出现任何植物、家具或其他带有"生命气息"的道具。

## 2. 渲染管线与光影系统（Rendering & Lighting）

- **封闭室内光照**：废弃传统室外 HDRI 天空盒，采用纯封闭室内光照方案；使用环境光遮蔽（SSAO/HBAO）配合屏幕空间全局光照（SSGI）或预计算光照探针，模拟光线在白色瓷砖间的多次弹射。
- **光源设计**：仅使用天花板和墙壁的方形面光源（Area Lights/Emissive Materials），色温偏冷（苍白/幽绿/冷青），光照分布均匀扁平，避免锐利硬阴影。
- **体积雾**：青绿色指数衰减浓雾（Exponential Squared），限制视野深度，增强空间无尽感与水汽弥漫的潮湿感。
- **后处理矩阵**：Bloom（柔和扩散泛光）、轻微色差（Chromatic Aberration）、极轻微动态颗粒（Film Grain）；所有效果应可关闭以便性能对比。

## 3. 材质与物理渲染（Materials & PBR）

- 白瓷砖 & 混凝土使用高质量 PBR 信息（Albedo/Normal/Roughness/AO）；瓷砖粗糙度呈现不均匀"水渍"与高反光质感。
- **高质量水体**：
  - 反射：水面实时反射周围柱子、墙壁与泛光灯，反射边缘随水波扭曲。
  - 折射与深浅渐变：基于深度的颜色吸收，浅水偏白、深水过渡为浑浊深青/幽绿。
  - 微动态水波：多重 Gerstner Wave 或基于噪波的法线平移，生成极其缓慢凝滞的微小涟漪。
  - 焦散（Caustics）：池底与水面上方瓷砖墙壁投射缓慢游动的光斑。
- 不要求在不支持的设备上伪装 SSR/SSGI 成功；应提供能力检测与降级路径。

## 4. 交互与摄像机（Interaction & Camera）

- 纯粹的步行模拟器：**移除所有 UI、HUD、任务提示和背景音乐**。
- 第一人称控制：视界高度固定约 1.7m，移动速度缓慢，轻微头部浮动（Head Bobbing）与空间化脚步回声。
- 只能自由探索，无法跳跃过高或快速奔跑。

## 5. 性能

- 目标主流设备 60fps（报告必须记录实际硬件与画质档）。
- 大量重复瓷砖使用实例化（Instancing）或合并网格；动态区块有明确的加载、卸载与资源释放机制。

# 交付与限制要求

- 请先输出整体架构设计思路与 Shader 核心实现逻辑，然后逐步提供 Three.js/WebGPU 的初始化与渲染循环代码。
- 交付完整可运行网页工程（单 HTML 或模块化工程均可）。
- 不得包含 TODO 或缺失核心算法的占位符。
- 完成后用中文简要说明渲染管线、空间生成与性能策略。
