## 一、运行方式

**零依赖，双击即玩**：直接用浏览器打开 `index.html`（纯静态、无构建、无外部 CDN、离线可用）。
也可本地起服：`python -m http.server 8765` → `http://localhost:8765/index.html`。

| 技术 | 说明 |
|---|---|
| 渲染 | HTML5 Canvas 2D 双层画布（场景层 + HUD 层），自研 2.5D 微缩模型渲染管线 |
| 美术 | **100% 程序化矢量**——战术萌鸭、鸭尸、家具、地形全部代码绘制，无任何图片资源 |
| 架构 | 16 个经典 script 模块（core / data / world / entities / systems / render / hud / ui / game），全局单例解耦 |
| 存档 | localStorage JSON（藏身处、技能、仓库、设施、商人库存） |

## 三、硬核生存：《僵尸毁灭工程》底层架构的完整移植

### 3.1 角色状态管理（复杂度下限 → 全量补完）
- **部位制健康**：头/躯干/双臂/双腿独立 HP，加权合成总生命；腿部骨折→移速 42%，手臂骨折→挥速 55%
- **伤情体系**：抓伤 → 撕裂伤 → 咬伤（出血速率递增）；翻窗碎玻璃刮伤；绷带包扎（会**变脏**）
- **双重感染（僵毁 canon）**：
  - 伤口感染（细菌）：脏绷带/未消毒引发，酒精+抗生素可治
  - **克诺克斯病毒（无解）**：抓伤 7% / 撕裂 25% / 咬伤 100%，潜伏 15–25 游戏小时后发热→死亡，防刺背心/防护服可降低风险
- **Moodle 系统 21 项**：饥饿/口渴/疲惫/恐慌/压力/疼痛/无聊/不开心/恶心/发热/流血/骨折/包扎/淋湿/感冒/醉酒/超重/伤口感染/负重针/止痛/恢复针，四级色阶图标 + 悬浮说明
- **需求模拟**：食物中毒（生肉/毒蘑菇/脏水，特质「钢肠/胃弱」修正）、淋雨→着凉→**打喷嚏发出噪音引来鸭尸**、咖啡因抗疲劳、酒精减压但醉酒
- **恐慌系统**：可见追击鸭数量实时驱动，射击散布扩大 + 屏幕心跳缩放；「勇敢/胆小/退伍老兵(免疫)」特质修正

### 3.2 拟真视野机制
- 视锥朝向鼠标（110°），射线遮挡；**背后与墙后是盲区**（实体剔除）
- 昼夜动态：夜晚视距 -58%（夜枭减半衰减），黑暗中爬行鸭几乎不可见
- 手电照亮视锥（电池消耗、换电池）、实验室全图断电、路灯仅城区有电
- 鸭尸的感知同样拟真：视线锥 + 遮挡判定 + 潜行/光源修正

### 3.3 深度物资与环境交互
- **容器搜刮**：冰箱/橱柜/衣柜/药柜/工具架/货架/板条箱/军需箱/实验柜/收银机/鸭尸……按建筑类型分配战利品表（幸运特质加权稀有品）
- **负重系统**：kg 计重，超重移速 -38%；三种背包扩容；「负重针」应急
- **封窗钉门（木工）**：锤+木板+钉子三层加固，鸭尸会砸门窗（hp 机制）
- **制作**：绷带/夹板/长矛/钉球棒/烤肉/净水 + 工作台三级弹药压装（常规→蓝弹→紫弹→风暴电池）
- **野外搜集**：草地/林线搜集浆果蘑菇木棍（技能等级影响产出）
- **噪音传播**：走路/冲刺/潜行/枪声/尖叫/砸门/喷嚏半径各不同，惊动范围内鸭尸前来调查
- **天气时间**：1 现实秒 = 1 游戏分钟，昼夜循环 + 晴/阴/雨/风暴天气机，撤离时限后**尸潮模式**

### 3.4 技能/职业/特质（僵毁式开局构筑）

## 四、撤离经济与进程（鸭科夫骨架）

```
藏身处整备(设施/仓库/商人/保险箱) → 出击四图之一 → 搜打撤 + 求生 → 撤离点读条 6s
   ↑                                                              ↓
   └──── 撤离=物资入库 / 阵亡=失去身上一切(近战槽+保险箱除外) ←────┘
```

- **四张递进地图**：零号区(住宅镇) → 仓库区(典狱长) → **J-Lab**(断电/彩卡房/迷彩鸭/Boss路障) → **风暴区**(永暴雨/落雷/雷暴骑士)
- **保险箱 4 格 + 近战槽死亡保留**（鸭科夫规则）；1级凭证(合成/商人)进实验室，3级凭证(路障掉落)进风暴区
- **藏身处五设施**：工作台(弹药/改装)、厨房/健身房(属性)/医疗站(补给)/情报中心(凭证+稀有货架)
- **神秘商人**：只收现金；**隐藏结局**：击败雷暴骑士获神秘飞船图纸 → 🚀 完美结局
