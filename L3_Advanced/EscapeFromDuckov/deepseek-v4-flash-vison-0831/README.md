# 🦆 鸭科夫·毁灭工程 PROJECT ZOMDUCK

**《僵尸毁灭工程》(Project Zomboid) 的硬核生存机制 ×《逃离鸭科夫》(Escape from Duckov) 的废土鸭美学 —— 一个可运行的轻量版 3D 生存 Demo。**

这是关于你如何死去的游戏。活过三天，修好东边公路的汽车，然后——逃出去。

---

## 🚀 运行方式

### 方式一：直接运行（零依赖）
游戏已打包为 **单文件**，双击即玩（浏览器需支持 WebGL2）：

    dist/index.html

### 方式二：开发模式（模块化源码 + 本地服务器）
```bash
node serve.js        # 启动开发服务器
# 浏览器打开 http://localhost:8137
```

### 构建
```bash
node build.js        # esbuild 打包源码 → dist/index.html
```

## 🧟 核心系统（僵毁机制）

- **角色状态**：饥饿 / 口渴 / 疲劳 / 耐力 / 恐慌 / 压力 / 无聊 / 疼痛 / 醉酒 / 疾病 / 体温 / 血容量，实时衰减与 Moodle 心情图标分级。
- **部位健康**：头/躯干/双臂/双手/双腿/双脚 12 部位，抓伤 / 裂伤 / 撕咬 / 骨折 / 流血 / 深层伤口 / 感染，绷带 / 消毒 / 夹板处置。
- **丧尸感染（Knox）**：撕咬必感染，裂伤 25%、抓伤 7%，感染后 32-52 游戏小时发作死亡——这是你的死法。
- **拟真视野**：360° 射线视锥 + 墙体遮挡 + 记忆地图（去过的区域残留微光，未探索区域漆黑），窗帘挡视线、玻璃透光。
- **噪音系统**：脚步 / 奔跑 / 枪声 / 砸门 / 收音机制造声音事件，丧尸循声而来；潜行与特质降低噪音。
- **丧尸 AI**：游荡 → 侦查 → 追击 → 破门砸窗 → 扑咬；狂暴冲刺种蓄力红光；尸群连锁警报；随机元事件（枪声 / 直升机）拉动尸潮。
- **物资**：70+ 物品，重量与容量限制、食物保质期（腐烂）、罐头需开罐器、背包分层、容器按类型随机战利品（冰箱/药房/军械库/检查站……）。
- **战斗**：近战弧线打击 / 击退 / 暴击爆头 / 武器耐久与修理；枪械弹匣装填、散布受技能-移动-恐慌-疼痛影响、曳光弹、抛壳；护甲与甲弹等级。
- **环境交互**：门窗开关 / 撬锁 / 砸门 / 打碎玻璃翻窗 / 木板路障（4 层）/ 挂窗帘 / 搜刮计时 / 篝火烹饪 / 农田播种浇水收获 / 井水 / 睡觉快进 / 尸体留存。
- **世界节律**：昼夜循环（40 分钟一天）· 天气（晴/多云/雨/暴雨/雾）· 断电停水事件 · 发电机 · 街灯 · 雷暴。
- **成长**：建卡职业（警官/消防员/木工/农民/医生/修车工/厨师/猎人）+ 28 个正负特质点数系统；19 项技能 + 经验 + 技能书倍率。
- **存档**：localStorage 自动存档 + 手动存档，含世界状态（门窗/路障/农田/篝火/丧尸/任务）。

## 🦆 视觉管线（鸭科夫美学）

- 赛璐璐 Toon 光照 + 色带（Posterize Banding）+ 背面挤出描边 + 深度 Sobel 描边。
- **视线迷雾 Shader**：可视区/记忆区/盲区三态遮罩，全材质注入（fog chunk 改写）。
- 高度雾、昼夜冷调、低饱和废土调色 + 角色高饱和隔离。
- 后处理：血光暗角（随血量呼吸波动）、色差与屏幕抖动（疼痛/醉酒）、雨痕折射、噪点、热成像 / 夜视模式。
- 特效：枪口火光、弹道曳光、抛壳、击中木屑/火花、**羽毛爆散**（替代血浆的鸭式幽默）、手电筒体积光锥、雷暴闪电。
- 微缩模型感：剖面建筑（屋顶渐隐）、矮墙防遮挡、低多边形色块场景 + 高饱和战术萌鸭。

## 🎯 玩法闭环

1. 在出生民居醒来（"这就是你如何死去的"）。
2. 搜刮食物、武器、药品，加固藏身处。
3. 活过 3 天 → 修好东部公路的撤离车辆（蓄电池 + 汽油 + 引擎零件，需要汽修技能；零件散落在加油站、军械库与检查站）。
4. 抵达撤离点发动引擎 → **逃离鸭科夫**（胜利结局）。
5. 或者，被感染、被撕碎、被饿死——**死亡即永久**（This is how you died）。

## 🗂 工程结构

    index.html         开发入口（importmap → vendor/three.module.js）
    styles/ui.css      鸭科夫风格 UI
    src/               游戏源码（ES Modules，20 个模块）
    vendor/            本地化 three.js (r180)
    dist/index.html    最终单文件交付
    build.js serve.js  构建与开发服务器
    test.js frame.js game_test.js flow_test.js analyze.js   开发自测工具（CDP 无头验证）
    docs/              视觉与系统融合设计文档 + 原始报告

> 无头验证：本工程使用 headless Chrome + CDP 对 渲染帧像素 / 移动 / 搜刮 / 射击 / 近战 / 存档读档 / 死亡 / 胜利 全链路做了自动化验证。
