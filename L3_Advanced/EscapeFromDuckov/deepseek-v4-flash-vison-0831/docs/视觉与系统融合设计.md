# 《鸭科夫·毁灭工程》视觉与系统融合设计文档

> 本文件记录如何将工作区两份《逃离鸭科夫》解析报告中的视觉标准与玩法设定，系统性地缝合到《僵尸毁灭工程》式硬核生存机制中，并落地为可运行 Demo（dist/index.html）。

## 一、视觉管线的逐条落实（对照《视觉风格与着色器特效技术分析》）

### 1.1 赛璐璐卡通着色器 → Lambert + Posterize 色带
原报告要求 URP Toon Shader 的阶梯光照（Ramp Map）。本作在 WebGL 下采用 MeshLambertMaterial 计算光照，随后在全屏后处理中对亮度做 4 级 Posterize 量化，得到硬朗的亮/过渡/暗三带色阶；材质经 onBeforeCompile 注入自定义 chunk。

### 1.2 卡通描边 → 双通道实现
- 背面挤出法：角色（鸭人与感染鸭）以 BackSide 外壳放大 1.09 倍渲染为深色描边，轮廓清晰。
- 深度 Sobel 描边：场景写入带 DepthTexture 的离屏目标，后处理对深度缓冲做 Sobel 边缘检测，为静物批量描边。

### 1.3 2.5D 战术视野与视线迷雾 → 三态视野 Shader
这是本作最核心的玩法 Shader：
1. 游戏逻辑每帧从玩家位置发射 460 条 DDA 网格射线，被墙/门/窗帘阻挡，产出 200×200 可视掩码 DataTexture；
2. 另有一张「记忆地图」纹理累积所有去过区域（去过的区域以 55% 亮度保留微光，未探索区域漆黑）；
3. 全部场景材质经 fog chunk 注入采样两张纹理：mask = max(vis, explored*0.55)，盲区向深蓝黑色插值——与报告中「障碍物后方阴影蒙版」一致，且丧尸的可见性同时在 JS 侧做剔除防作弊。

### 1.4 动态手电筒 → 聚光灯 + 体积光锥
手电为附加的圆锥网格 + Additive 半透明材质（丁达尔光柱），由玩家瞄准方向驱动；配合夜景与室内黑暗环境，是夜间探索的核心光源。

### 1.5 热成像 / 夜视 → 全屏后处理模式
按 T 键循环三种视野：正常 / 热成像（灰度冷调背景，受击与光源呈橙红高亮）/ 夜视（绿色增益 + 噪点），对应报告中热成像瞄准镜的显示逻辑。

### 1.6 战损反馈 → 血光暗角 + 色差 + 噪点
低血量/流血时屏幕边缘红色椭圆暗角随血量正弦呼吸波动；疼痛与醉酒驱动 RGB 通道偏移（色差）与噪点；恐慌驱动屏幕噪点幅度。

### 1.7 风暴气候 → 雨痕折射 + 高度雾 + 雷闪
暴雨天气下全屏雨滴法线对采样 UV 偏移产生「雨水沿镜头流淌」的折射；高度雾随距离消隐场景；雷暴伴有随机闪电白闪与音效。

### 1.8 粒子与战术反馈
- 枪口火光：十字星形 billboard，0.06s 生命周期；
- 抛壳：黄铜弹壳抛物线落地，2s 后消失；
- 曳光：头部高亮、尾部淡出的线段；
- 击中反馈：羽毛爆散 —— 用黄白色羽毛粒子替代血浆，还原「卡通荒诞」主题；击中墙体则溅出木屑/水泥碎渣。

### 1.9 全局色调 → 低饱和废土底 + 高饱和角色隔离
后处理压低整体饱和度、伽马提亮对比；场景资产全部采用低饱和冷色（鼠灰绿、水泥灰、砖褐），而鸭人本体使用高饱和明黄（#ffd23e）、感染鸭使用病态灰绿，保证在暗色废墟中的可读性。

### 1.10 微缩模型 / 剖面建筑
建筑无屋顶遮挡问题：玩家进入建筑时屋顶实时渐隐；面向镜头一侧的墙体矮化（1.35m），防止上帝视角遮挡。

## 二、玩法系统的深度融合（对照《游戏设定与复刻还原指南》+ 僵毁架构）

### 2.1 搜刮与撤离 → 搜打撤闭环
僵毁的容器搜刮（计时、按容器类型掷战利品表）与鸭科夫的撤离目标结合：修好撤离车辆（蓄电池/汽油/引擎零件）→ 抵达东部公路撤离点 → 发动引擎胜利。死亡惩罚为僵尸毁灭工程的「死亡即永久」，但撤离成功即「逃离鸭科夫」。

### 2.2 单人 PvE 与暂停机制
纯单人 PvE（AI 感染鸭），ESC 随时暂停——保留报告中的「奶爸/上班族友好」设计。

### 2.3 甲弹关系
伤害公式沿用鸭科夫：实际伤害 = 基础伤害 × 2/(护甲等级 − 穿透等级 + 2)；护甲同时提供对撕咬/抓挠的免伤判定与耐久损耗。

### 2.4 狂暴搜刮者 → 狂暴冲刺感染鸭
高速感染鸭冲锋前身体发出红光（emissive 闪烁），冲锋锁定玩家；玩家可用翻滚（0.26s 无敌帧，报告中的 Dodge Roll）拉扯。

### 2.5 医疗系统
流血→绷带；骨折→夹板；疼痛→止痛药；感染→消毒水；深伤口→缝合；急救包需静止使用。部位级伤情 + Moodle 图标全盘继承僵毁。

### 2.6 视角与操作
俯视角 3D 体验：WASD + 鼠标瞄准 + 翻滚 + 手电 + 潜行；Q/V 旋转视角，滚轮缩放——介于僵毁的等距视角与鸭科夫双摇杆之间。

### 2.7 僵毁核心系统保真清单
- 建卡：职业（8 种）+ 特质（28 个正负特质，点数系统）；
- 状态：12 部位健康、9 项体征、9 级 Moodle、丧尸病毒感染进程；
- 技能：19 项 0-10 级技能 + 技能书经验倍率 + 职业/特质修正；
- 物资：重量/容量、变质、罐头、容器战利品表、武器耐久与修理；
- 世界：门窗/撬锁/路障/窗帘/破窗翻越、农田、井、篝火烹饪、睡觉、断电停水、发电机、街灯、昼夜与天气；
- 丧尸：视野锥 + 听觉噪音传播 + 尸群连锁 + 元事件 + 重生；
- 存档：世界全状态 JSON 序列化 + localStorage。

## 三、技术架构

| 层 | 技术 |
| --- | --- |
| 渲染 | three.js r180（本地 vendor，零 CDN 依赖），WebGL2，单 pass 场景 → RT（颜色+深度）→ 全屏后处理 |
| 着色 | Lambert + onBeforeCompile chunk 注入（视野遮罩/高度雾/记忆区），Posterize 色带，BackSide 描边 + 深度 Sobel |
| 世界 | 200×200 网格，墙段为位掩码边表，DDA 射线 LOS，桶形空间索引，程序化城镇/森林/湖泊生成 |
| 系统 | 纯 ESM 模块（game/world/renderer/postfx/env/status/player/zombie/interact/loot/craft/ui/menu/input/audio），事件总线解耦 |
| 音频 | WebAudio 全程序化合成（枪声/呻吟/脚步/雷声/风声，无外部资源） |
| 交付 | esbuild 打包为单文件 dist/index.html（约 1.4MB），双击即玩 |
