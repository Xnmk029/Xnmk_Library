## 0. 交付形态

- 纯前端 **Canvas 2D + 原生 JS（零依赖、零外部资产）**，双击 `index.html` 即玩。
- 目录：`duckov-z/index.html` + `css/style.css` + `js/*.js`（模块化命名空间 `DZ.*`）。

| 鸭科夫原始技术 | 本作 Canvas 实现 |
|---|---|
| URP 卡通阶梯光照（Ramp Map 三段影） | 双色块 cel-shading：固有色 + 固定光向暗部月牙 + 全员深色描边 |
| 角色高饱和 / 场景低饱和废土 | 角色 #FFD23F 明黄鸭体；场景去饱和冷灰绿调色板；全局对比+12%/饱和−20% 的暗角滤镜 |
| 微缩模型剖面建筑（无屋顶/动态隐藏） | 伪 3D 挤出墙体（顶面亮带），每栋建筑独立屋顶画布，玩家进入即淡出 |
| 2D 射线 FoV 迷雾 + 屏幕空间遮罩 | 射线求可见多边形，盲区压黑；已探索区域半亮记忆；盲区内敌人严格剔除（防作弊式剔除） |
| 手电圆锥体积光（丁达尔） | 光照层 destination-out 抠洞 + 加色暖光锥 + 微尘闪烁 |

| 低血量红晕呼吸 + 色散抖动 | DOM 径向渐变红晕按血量/流血正弦脉动 + 重伤时 hue-shift 屏震 |
| 曳光弹颜色分弹药等级 | 普通弹橙黄 / 独头弹亮白粗线 / 步枪细长青白曳光 |
| 击中羽毛爆炸代替血浆 | 全部命中反馈为黄白羽毛飞散（含僵尸），卡通荒诞基调统一 |
| 枪口星状火光 / 黄铜抛壳物理反弹 | 十字星火光 2 帧 + 弹壳小刚体（落地反弹、渐隐销毁） |

## 2. 僵毁机制提炼（检索来源见文末）

硬核下限四支柱全部落实并加深：

1. **复杂角色状态**：6 部位独立 HP（头/躯干/双臂/双腿）、抓伤/撕裂/咬伤三级伤口与流血、骨折需夹板、疼痛/恐慌/湿冷/负重 Moodle 组、饥饿/口渴/疲劳三消耗、僵尸病毒感染（咬伤必死倒计时，抗生素仅延命）、细菌感染（可治愈）、六项成长技能（力量/体格/射击/装填/急救/木工）、六职业出生配置（消防员/警员/厨师/医生/木匠/无业游民）。
2. **拟真视野**：可见多边形实时遮挡、昼夜光级（夜视半径骤减）、手电锥光会暴露自身、窗帘遮挡视线、雨天雾天衰减、蹲伏减被发现半径。
3. **深度物资环境交互**：60+ 物品、容器搜刮、冰箱保鲜/食物腐坏、停水停电日程（D2 断电、D4 断水）、炉灶烹饪/篝火、水槽接水/雨水收集器、窗户翻越/上窗帘/钉木板（3 层耐久）、撬棍撬锁、砍树立木取材、采集浆果、汽车后备箱、加油泵（断电后失效）、燃烧瓶与爆炸桶、尸体搜刮。
4. **世界模拟**：1 秒 = 2 游戏分钟、睡觉跳时（会被噪音惊醒）、天气状态机（晴/阴/雾/雨/雷暴，影响视野与听觉传播）、枪声全图热度吸引尸群、夜间尸潮事件（收音机预警）、Day7 正午直升机撤离（需 3 桶燃料）——**把鸭科夫的"搜打撤"闭环嫁接到僵毁的持久生存上**。

## 3. 系统级缝合点

| 缝合点 | 设计 |
|---|---|
| 撤离循环 | 僵毁开放生存 + 鸭科夫撤离目标：收集燃料 → D7 正午学校操场直升机撤离（可续自由模式） |
| 甲弹关系 | 鸭科夫护甲等级思想 → 玩家防弹衣 1/2/3 级减伤 + 头盔，僵尸啃咬被护甲吸收降级为抓伤 |
| 敌人视觉语言 | 僵尸=灰绿腐鸭（羽毛飞散），冲锋者攻击前红光蓄力（狂暴搜刮者的 telegraph） |
| 战术 UI | 鸭科夫琥珀色战术 HUD 承载僵毁的 Moodle/部位面板；声音以扩散涟漪可视化 |
| 无敌帧 | 鸭科夫翻滚 → V 键战术翻滚（0.28s 无敌帧，消耗体力） |

## 4. 操作

WASD 移动 / Shift 疾跑 / C 蹲伏 / V 翻滚 / 鼠标瞄准 / 左键攻击·开火 / 右键稳瞄 / R 装填 / F 手电 / N 夜视仪 / Space 推开·挣扎 / E 互动 / Tab 背包(合成/技能) / M 地图 / J 收音机日志 / Esc 菜单。
