## 它是什么

你是一只流落废土"鸭鸣镇"的战术萌鸭。搜刮、筑防、管理六处身体创伤与十几种生存状态，在停电停水、尸潮与暴雨中撑到第 7 天正午——带上 3 桶燃油，去学校操场搭乘撤离直升机。

- **视觉基调**（源自 `docs/逃离鸭科夫_视觉风格与着色器特效技术分析.md` 的完整转译）：
  卡通双色块 cel-shading + 全员描边 · 高饱和角色 vs 低饱和废土场景 · 伪 3D 剖面建筑（进入即隐屋顶）· 射线可见多边形战术迷雾 · 手电锥形体积光 · 夜视仪热源高亮 · 低血量呼吸红晕 · 弹壳物理抛掷 · **击中即羽毛爆炸**（拒绝血浆，贯彻反差萌）
- **生存骨架**（Project Zomboid 设计提炼）：
  六部位独立血量 / 抓伤·撕裂·咬伤 / 骨折夹板 / 疼痛·恐慌 Moodle 组 / 饥饿·口渴·疲劳 · **咬伤 = 病毒倒计时死亡**（抗生素仅延命）· 六职业技能成长 · 六职业出生配置 · 停电(D2)/停水(D4) 日程 · 枪声全图热度引尸 · 天气状态机影响视野与听觉 · 睡眠跳时会被噪音惊醒

## 世界

约 132×96 瓦片的确定性小镇：消防局、警署、诊所、中学（撤离点）、超市、餐馆、汽修、加油站、仓库（含上锁军械角）、七栋民居与中央公园。82+ 可搜刮容器、可砍伐树木、可采集灌木、可引爆油桶、可翻越/钉板的窗户、可上锁的门。

## 技术要点

- Canvas 2D 单线程渲染：地形一次性预烘焙 + 每栋建筑独立屋顶画布做淡出
- 视线：射线法可见多边形（静态墙体空间索引 + 动态门窗遮挡），盲区实体严格剔除
- 光照：离屏暗层 multiply + destination-out 抠光 + screen 加色暖光（篝火闪烁/枪口闪光/手电锥光按视野多边形裁剪）
- 音频：WebAudio 全程序化合成（枪声分武器、尸吼随机泛音、雨雷环境层、心跳随威胁加速）
- 存档：种子 + 差异序列化到 localStorage，自动/手动双通道
- 自测：`#selftest=1` 无头自检；`node test/headless.js` 逻辑冒烟测试（36 项断言）
