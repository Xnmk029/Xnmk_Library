# VN1：8×8 轮式步兵战车家族程序化建模与 WebGPU 工作室

## 分类元数据

- **测试领域**：3D 图形、物理仿真与 Shaders
- **难度等级**：`L3`（高级）
- **核心技术栈**：WebGPU / WGSL / 程序化几何 / PBR 与渐进累积渲染 / 军武装备考证
- **核心考核点**：8×8 轮式底盘程序化硬表面建模、公开影像资料考证与证据分级、改型差异（标准外贸型/泰国UW4B/加蓬型/委内瑞拉型/任务改型）、分舱内构与乘员战位、物理 PBR 材质与定向服役旧化、双模式 WebGPU 渲染工作室（实时+累积路径追踪）、4K/8K 大画幅无损导出

## 任务定位

测试模型在公开资料约束下，对中国 NORINCO VN1 8×8 轮式步兵战车及其公开确认的家族改型进行图片对照级程序化三维建模、内构与证据分级管理，以及在零外部三维资产依赖下实现专业级 WebGPU PBR 渲染与大画幅导出的综合能力。

本项目严格遵循**公开资料驱动的装甲车辆数字考证、程序化建模与 PBR 可视化系统**定位，严禁臆造机密或未公开参数，且明确与 VT-4 主战坦克（履带/125mm炮/盘式装弹机/后置动力舱）区分。

## 任务要点

- **底盘与车体**：基于 8×8 轮式装甲底盘，复现前部楔形车体、前左驾驶舱、前右动力舱、中部炮塔/武器站、后部载员舱与尾门坡道、双水上推进装置、中央充放气接口与挡泥板。严禁出现履带式负重轮或后置动力舱等坦克逻辑。
- **资料考证与证据分级**：建立内部证据账本，严格划分 A 级（确认特征）、B 级（高可信推定）、C 级（示意复原）与禁止复原项。C 级结构必须采用中性灰或半透明材质标明示意状态。
- **武器系统与家族改型**：
  - **基准型 VN1 步兵战车**：30mm 机关炮、并列机枪、有人炮塔、可选 HJ-73C/D 导弹导轨。
  - **泰国型 VN1（UW4B 构型）**：UW4B 遥控无人武器站、光电观瞄模块、泰军涂装与编号。
  - **加蓬型 / 委内瑞拉海军陆战队型**：对应国籍涂装、编号与特定配置。
  - **家族任务改型**：VS27 装甲救援车、SM4A 120mm 自行迫击炮、VE36 指挥车、救护车等，以模块替换方式实现。
- **分舱内构与乘员战位**：建立前左驾驶、前右动力包（柴油机/传动箱/冷却风扇）、中部操作区与后部载员舱（防冲击座椅/下车通道），配备带装具骨架的驾驶员、车长、炮手及步兵乘员。
- **PBR 材质与定向旧化**：基于 Cook-Torrance BRDF 与微表面细节，区分装甲钢、焊缝、机加工件、橡胶轮胎、光学玻璃、防滑层等独立材质；边缘磨损依据曲率、接触频率与受冲击区域定向生成，非全车均匀噪波。
- **WebGPU 专业渲染工作室**：
  - **双模式渲染**：60 FPS 实时预览（Forward+/集群光照/CSM）+ 视口静止自动收敛的累积路径追踪（GI/软阴影/精确 AO）。
  - **物理相机**：轨道/飞行/转台/正交视图、焦距、光圈景深、曝光补偿、ACES 色调映射。
  - **程序化环境与地面**：纯代码生成沙场/兵营/摄影棚环境、带八轮轮胎压痕的微地形、GPU 扬尘粒子。
  - **大画幅输出**：支持 4K/8K 超高分辨率分块无损导出。

## 自动化验收建议

1. **底盘与形态甄别**：一眼可确认为 8×8 轮式步兵战车，前轮具备合理转向联动，无外部 `.gltf`/`.obj` 依赖；绝对无履带、负重轮或坦克自动装弹机残留。
2. **改型与差异高亮**：基准有人炮塔型与泰国 UW4B 遥控武器站构型切换正常，外观与光电差异显著，差异对比工具能热区高亮变化部件。
3. **证据账本可追溯**：界面支持查看特征的 A/B/C 证据等级，C 级特征正确标记为示意结构。
4. **内构与解构模式**：外壳透明、X-Ray、剖切盒与爆炸分解图工作正常，深度排序正确无乱序面。
5. **PBR 与磨损分布**：金属度-粗糙度符合物理，磨损集中在踏板、舱口、拉手、锁扣等真实受力磨损点。
6. **渲染收敛与相机响应**：静止状态累积帧数递增，阴影与接触遮蔽平滑收敛；相机变动时累积缓冲瞬时重置。
7. **大画幅导出**：测试 4K/8K 导出流程，检查分辨率与 PNG 完整性。
