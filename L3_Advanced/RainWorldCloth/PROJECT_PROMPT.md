# 任务背景

You are an expert in WebGL and physics engine development. Please create a single-file HTML project that implements a 3D soft-body cloth physics simulation based on a "Mass-Spring System" or "Position-Based Dynamics (Verlet Integration)."

# 需求范围

## 项目格式要求

- 交付为单个 `index.html`，包含全部 HTML、CSS 与 JavaScript。
- 3D 渲染、交互与 UI 库可通过可靠公共 CDN 引入（如 Three.js + OrbitControls）。
- 核心布料物理必须完整实现。

## A. 动态网格分辨率

- UI 可调整布料网格分辨率（如 10×10 至 40×40）。
- 调整后系统应平滑销毁旧粒子网格，并按新分辨率重建布料（释放旧粒子/约束/几何资源）。

## B. 核心动作与环境模拟

1. **风力模拟**：动态三维风向量，包含时变随机扰动或噪波（正弦波或简单噪声函数）；UI 可调：风开关、风速、风向角。
2. **台阶碰撞**：场景中央下方生成 2–3 层台阶的静态结构；实现布料粒子与台阶的碰撞检测与响应（含简单摩擦与回弹）；布料初始位于台阶上方，模拟开始后自然落下并真实地垂搭/折叠在台阶上。
3. **布料折叠**：
   - 物理模型必须包含弯曲约束（弯曲弹簧或角度约束），使布料保持形态并产生自然褶皱。
   - 交互折叠：支持鼠标/触摸拾取并拖动任意节点以拉伸和折叠布料。
   - 预设折叠：提供 "Fold Cloth" 按钮，通过对特定角施加相对力自动演示对折（如对半折）。

## C. UI 控制面板

- **布料配置**：网格分辨率、重力大小、刚度参数、重置布料按钮。
- **风控制**：风开关、风速、风向。
- **交互与预设**：Drop onto Steps（释放到台阶）、Fold Action（自动折叠）。

## D. 视觉与场景细节

- 包含基础光照（方向光 + 环境光）并支持阴影以增强 3D 效果。
- 布料材质双面渲染（不禁用背面剔除）。
- 场景提供地面平面，与台阶协同提供深度感知与投影。
- 物理更新与渲染循环分离，使用稳定时间步防止模拟不稳定。

# 交付与限制要求

- 提供完整、可直接运行的 HTML 代码，不得省略任何关键算法实现。
- 不得包含 TODO 或缺失核心算法的占位符。
- 代码结构清晰，物理循环与渲染循环解耦。
