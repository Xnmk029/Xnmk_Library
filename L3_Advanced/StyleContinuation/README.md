# StyleContinuation：有文风参考的网文续写

## 分类元数据

- **测试领域**: 文字创作与叙事（Web 游戏与交互逻辑相邻的文字轨）
- **难度等级**: `L3`（高级）
- **核心技术栈**: 中文网文文风遵循 / 自由间接引语 / 手机端排版节奏
- **核心考核点**: 长文风规约遵守、人物与口语对白延续、情节承接、段落节奏

## 任务定位

测试模型在给定长篇风格范文与硬性文风红线的前提下，完成高完成度续写，并保持人物、车辆/咖啡线索与手机网文节奏。

## 提示词

> 📋 **完整提示词以 [`PROJECT_PROMPT.md`](./PROJECT_PROMPT.md) 为唯一标准**（含全文风规约 + 参考正文 + 执行要求）。
> 评测时请直接使用提示词原文，**不要修改任何技术约束**。

### 任务要点速览

- 身份：资深白金网文作家；输出即正文。
- 红线：禁「不是……而是」、禁破折号、禁排比、禁生硬比喻、禁否定式段首。
- 排版：单段 30–100 字；高潮单句成段。
- 承接：自倒计时「1」之后续写，延续侯天一/小智与奥德赛 vs 86 线索。

## 输出要求

- 纯续写正文 ≥ 1200 字（建议）。
- 符合规约；可选 `log.md` 思路说明 ≤ 200 字。

## 自动化验收建议

- 红线扫描：正文无「——」、无「不是……而是」模板、无大段排比、无「没有/这绝非/这不是」段首。
- 段长统计：无 >150 字文字墙；高潮段落存在单句成段。
- 人物一致性：仍为侯天一 / 侯广智，口语与白将军/咖啡/车辆线索未丢失。
- 字数与完整性：1200 字为建议，不能作为自动淘汰线；正文完整且非复述原文。
