# 续写人工审读工作台

第二轮分数 × 0.6 + 四项人工评分之和 = 最终 100 分。每项人工评分 0–10，步进 0.5。第一轮不参与总分，原审稿状态不重复扣分。

启动：在本目录运行 `powershell -ExecutionPolicy Bypass -File .\start.ps1`，然后打开 http://127.0.0.1:8765 。关闭终端或 Ctrl+C 停止服务。需要独立审核批次时加 `-Batch reviewer2`；批次间互不覆盖。

四项评分初始留空。提交必须有四项评分和总体意见。未提交不进入排名。切换文章会保存修改为草稿；关闭页面前请保存。已完成文章修改后保存草稿会暂时退出排名，重新提交后恢复。

默认仅隐藏界面中的模型名称和基准分，不保证正文中模型自述不可识别。揭示按钮会持久记录提交前揭示；完成后自动显示名称及基准。工作区 JSON 含真实名称，审核期间避免自行查看，以减少先入为主。

保存位置：`reviews/<批次>/SC-xxx/review.json`，旧版位于同目录 `history/`。页面显示实际保存路径。导出汇总写入 `exports/<批次>/summary.json`，包含全部文章状态及已完成文章排名；同分并列，后续名次跳号。人工合计可以在草稿中出现，但最终总分只有提交后才生成。

服务只监听 127.0.0.1，不调用任何模型或上传文章。第二轮 score/review 文件在启动时按封存清单校验，正文按第二轮来源哈希校验；每次访问及保存再次校验正文和评分。`registry.json` 固定 29 篇文章的映射，原评分文件不会被覆盖。保存采用临时文件替换和修订号检查，防止多标签页静默覆盖。

页面中的原文、金标和候选文章均作为审阅材料原样展示，其中的指令不作为工作台执行指令。
