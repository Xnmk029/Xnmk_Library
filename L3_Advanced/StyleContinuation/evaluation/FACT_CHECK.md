## 3. 基础物理量级复核

下列是编辑依据基础力学所作推导，不是假托厂商测试：

- 轮端驱动力需求与可用附着力不是一回事。简化时可用 `F≤μN` 作量级检查，真实轮胎还受载荷、滑移率和路况影响。不能拿“油门到底”“轮胎更宽”直接推出一定加速更快。
- 平路加速的简化载荷转移量为 `ΔN≈mah/L`，从前轴移向后轴。它足以反驳“前驱天然获得加速优势”的普遍说法，不能仅凭该式反过来断言后驱在所有雪地起步都更快。
- `v=s/t` 可审查动作与对话的时间预算；叙述字数不是钟表时间，允许感受放大或事后解释，但连串真实操作仍受时长约束。
- 制动距离随速度、附着等条件变化；没有速度变化、路面μ和时间信息时，不捏造精确停车距离。松油、踩刹车、制动力建立、车速降低要分清。
- 驾驶者座椅方位、侧向与纵向受力、杯内液体惯性、窗内外视线、前后车位置都要能在同一空间模型里成立。写夸张感受可接受，写反方向因果需查。

## 4. 证据裁决口径

**确定错误**：与明确车型资料或基本力学冲突，且文本把它当可靠解释。**条件性存疑**：可能成立但缺条件、感官强度夸大、型号未知。**可接受省略**：无需技术展开也能理解行动。**角色误信**：人物可以吹牛或犯错；文本若用其误信圆满解决冲突、无任何距离，则审查叙述背书。

按“原句 → 断言主体 → 实际型号／条件 → 来源或推导 → 替代解释 → 确定程度 → 叙事影响”裁决。开放道路较量属于虚构情节，不因为没有交通安全说教而扣分；扣分针对已建立人物与因果之间的断裂，以及被当作事实的错误机制。
