# 实际第二章金标分析

金标定位：**叙事与风格参照 + 可被纠错的真实样本**，不预设为 100 分或物理知识权威。

## 1. 证据定位与第一章底稿

`P001–P056` 为 `PROJECT_PROMPT.md` 中【风格与剧情参考原文】之后、交付要求之前的空行分段；`G001–G057` 为 `REFERENCE_ANSWER.md` 的空行分段。对应段落全文和原始行号由预检 JSON 保存；本版金标第 n 段起始行为 `2n-1`。文件变化须重新编号并检查哈希。

| 事实组 | 可确认内容 | 不能擅自补成既定事实 |
|---|---|---|

## 2. 分级钩子账本

层级表示预计兑现时间，不表示文学价值高低。L0为眼前动作，L1为本场冲突，L2为人物／道具中程线，L3为跨章悬念，L4为质感与母题。状态区分：完整回收、局部回收、激活／升级、合理保留、遗失、矛盾、伪回收。最后三种必须给出证据；保留长线不等于遗失。

| ID／层级 | 第一章埋点 | 第二章实际处理 | 状态与读者收益 | 对候选的基础要求 |
|---|---|---|---|---|

| H02 L1 | P041–P049，互骂与MPV／跑车反差 | G005–G013追赶，G031–G047再追与让过 | 完整；胜负悬念经主动收手结束 | 本章须有冲突状态改变或局部结果；胜负方向不限 |
| H03 L1 | P039–P042，半热熔与雪天不匹配 | G005甩尾，G020–G022压水退后，G049解释收手 | 局部至完整；知识成为转折原因，但压水机制写得含糊 | 环境／轮胎知识应影响观察或选择；无需事故来“验证” |

| H10 L4 | P038–P039，雨刮异响烦躁 | G014、G020水雾雪水；无修理雨刮 | 环境延续；具体异响合理保留 | 雨刮不是必修伏笔；真写视野问题须与雨雪相容 |
| H11 L4 | P007、P029–P031、P045白将军 | 本章未再点烟 | 合理保留；前章已丢烟头 | 不出现不扣分，误写同一支烟状态才查连续性 |
| H12 L4 | P011、P015、P018麻将与春节闲聊 | 本章无专门后续 | 合理保留；生活底色并非每章任务 | 禁止以“麻将没回收”机械扣分 |
| H13 新L1→L3 | 无第一章直接种子；G015–G030新建路况 | 窄道在G031–G047兑现；加油坑只帮助解释收手 | 窄道完整，加油坑保留；危险预告支撑退出 | 新设险情需在决定前给出可读证据；可以走另一条路 |
| H14 新L3 | G056“游戏赢了讲故事” | G057情感加重后截章 | 有效新钩；问题具体，答案延后 | 章末有可继续的行动／情感问题即可，不考原作情节预测 |

评钩子的单位是“承诺—后效”。提到轮胎却完全不影响行为属于弱回收；凭天降发动机改装解释所有胜负属于伪回收。减少新钩子数量、把眼前一件事写完整也可以得高分。

## 3. 金标场景节拍与因果链

| 段落 | 推进内容 | 推进手段 | 复审重点 |
|---|---|---|---|
| G001–G007 | 奥德赛抢跑，86追来 | 声音→身体感受→镜中位置；先兑现再制造不稳定优势 | 雪湿路起步白烟是否夸大；车型强弱不是绝对规律 |
| G008–G014 | 技术解释、弟弟争胜、速度上升 | 对话插入追赶，量表与车身相对位置增加压力 | 前驱解释错误；直道侧向力缺触发；后视镜／玻璃位置需可读 |
| G015–G030 | 窄道、水坑、波浪路与加油坑 | 熟路知识改写胜负问题：抢先进入不等于能安全跑完 | 路况介绍偏长；静态资料消耗追逐的实时感 |
| G031–G044 | 二次加速、转视角看对手、160与侧滑 | 技术爽点→对手挫败→风险反噬 | VTEC因果、转速与变速关系；对手转速来源是视角切换而非透视能力 |
| G045–G050 | 出口松油、86越过、解释收手 | 给出反预期结果，再揭示主角选择 | 松油不等于瞬间低速；“安全最重要”与先前风险行为需人物化解释 |
| G051–G052 | 咖啡梗，回家 | 道具轻喜剧降温；省略非必要路程 | 咖啡只暗示去向；场景跳转可以省略时间但不应矛盾 |
| G053–G057 | 旧车显影、游戏邀约、嗓音沙哑 | 品牌轻视→车型正名→情感失态，章末把悬念换轨 | 不把R32当日产；不把此情节强制成唯一合格结尾 |

整章有效结构为：**即时兑现 → 对手追近 → 资源／路况成为变量 → 二次抬高期待 → 主动放弃表面胜负 → 生活道具降温 → 长线情感升起。**可以学习这一功能结构，不能要求相同场景顺序、车速或车型揭示。

## 4. 文风指纹与延续边界

| 特征 | 原文／金标证据 | 评审时观察什么 |
|---|---|---|
| 生活圈口语 | “哥”、脏话、吐槽、自问与打断；P025–P027、G021、G035 | 是否符合说话者的关系和当下情绪；脏话数量没有目标值 |
| 专业兴趣入场 | 称豆、轮毂、轮胎、VTEC、旧车正名 | 细节同时塑造人物并影响情节；不以术语密度奖励知识炫耀 |
| 兄弟反差 | 哥哥知道却不说尽，弟弟问、催、怕、惊叹 | 信息落差、亲密与嘴硬能否一起成立 |
| 身体承接心理 | P052缩进座椅、P055吸气；G043后背冒汗 | 感受由事件触发，少用旁白概括；物理反应本身还要合理 |
| 音响与短段 | 发动机声、单句转折、对话贴着动作 | 声音承担动作或节拍功能，避免整页拟声词 |
| 俗常到隐痛 | 咖啡玩笑转旧车与哽咽 | 情绪换挡有物件与动作作桥；不靠作者宣布“他有故事” |
| 叙述距离可变 | 第一章本就有全知家史；金标G039–G041进入对手心理 | 不按“绝对单一限知视角”误判；审切换是否有标识、知识是否错装进角色头脑 |

题面要求更严格的白描和自由间接引语；原章同时存在解释性旁白、反问和拟人。冲突时保护题面硬约束，在允许范围内延续口语、关系与节奏。不把原章所有习惯都当成可复制特征。

## 5. 金标缺陷复审清单

以下为已读文本的编辑判断；车辆依据见 `FACT_CHECK.md`。严重度区分 Critical（核心失效）、Major（显著问题）、Minor（局部问题）、Note（偏好／待辨）。金标也按同一标准登记。

|---|---|---|---|
