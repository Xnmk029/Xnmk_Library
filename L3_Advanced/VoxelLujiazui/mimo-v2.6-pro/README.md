# 陆家嘴 · 体素数字沙盘（Voxel Lujiazui）

单文件 HTML 交互式体素城市数字沙盘：程序化体素还原上海陆家嘴城市风貌与黄浦江岸线，
支持**上帝视角**与**第一人称**双模式漫游，内置昼夜光影、水面波动、车流船只与城市灯光。

## 运行方式

- 双击 `index.html` 即可在浏览器运行（Chrome / Edge）。
- 引擎库 Three.js（r160）通过 jsDelivr CDN 引入，**首次运行需要联网**；
  除此之外无任何外部资源（无模型文件 / 贴图视频下载），建筑与城市全部为程序化体素生成。
- 建议使用桌面端 + 独立显卡以获得流畅帧率（体素经 InstancedMesh 合批）。

## 控制方案（界面左下角常驻说明，`H` 键可隐藏/显示）

### 上帝视角（默认）

| 操作 | 说明 |
| --- | --- |
| 左键拖拽 | 环绕旋转（轨道相机） |
| 滚轮 | 缩放（拉远可俯瞰全城与黄浦江） |
| 右键拖拽 / Shift+左键拖拽 | 平移 |
| 闲置 6 秒后 | 自动缓慢环绕展示 |
| `V` 或 `Tab` | 切换到第一人称（镜头平滑飞行过渡） |

### 第一人称

| 操作 | 说明 |
| --- | --- |
| 点击画面 | 锁定鼠标进入转向（`Esc` 释放鼠标） |
| 鼠标 | 环顾四周 |
| `W` `A` `S` `D` / 方向键 | 行走 |
| `Shift` | 奔跑 |
| `Space` | 跳跃 |
| `V` 或 `Tab` | 切回上帝视角 |

可在街道、广场、陆家嘴中心绿地、滨江步道与亲水平台自由行走；建筑实体与江面有碰撞，
亲水平台可走到江面上方，滨江步道高于地面约 2m（防汛墙）。

### 通用

| 操作 | 说明 |
| --- | --- |
| `N` / 「速度」按钮 | 昼夜时间流速：暂停 → 1× → 8×（1× 约 5 分钟一昼夜） |
| 「跳至黄昏」「跳至夜景」按钮 | 快速切换到 17:36 / 21:12 观赏光影 |
| `L` | 建筑 / 地标文字标签开关 |
| `H` | 控制说明面板开关 |

## 内容清单

- **黄浦江**：带转折岸线的动态水面（顶点波浪 + 波面法线 + 岸线泡沫），船只往返航行；
  防汛墙、栏杆、路灯、长椅、挑江亲水平台与台阶。
- **滨江步道**：双色体素铺装、行道树、花坛。
- **标志性建筑（可辨识）**：
  - 上海中心大厦 632m —— 圆角三角截面、随高度扭转 120°、螺旋幕墙凹槽、顶部开口皇冠与桅杆
  - 上海环球金融中心 492m —— 立面收分 + 顶部「开瓶器」风洞（夜间内沿灯带）
  - 金茂大厦 421m —— 多级收分塔身、密檐挑檐段、塔冠台阶与尖顶
  - 东方明珠广播电视塔 468m —— 三球、斜撑、立柱、太空舱与航空桅杆
  - 上海国金中心 IFC 双塔、震旦大厦（临江 LED 巨幕，夜间动态像素动画）、时代金融中心、
    花旗集团大厦、中国银行大厦、汇丰大厦、正大广场等
- **城市肌理**：高密度体素街区（玻璃幕墙 / 混凝土 / 砖石多套材质与窗格纹理、裙房灯带招牌、
  屋顶设备与天线），陆家嘴环路、世纪大道（中央绿带 + 行道树）与方格路网，
  跨江高架匝道（桥墩、防撞护栏、桥面车流）。
- **绿化**：陆家嘴中心绿地（草坪、环形步道、中心湖、树丛）、街旁绿化。
- **光影与氛围**：主方向光实时阴影 + 半球光 + 环境反射贴图（玻璃幕墙反射天色），
  连续昼夜循环（日出 / 正午 / 黄昏 / 夜景四套天色调和），夜间窗灯、路灯、车灯亮起并缓慢「呼吸」，
  星空淡入、云层漂移、雾气随昼夜变化。
- **动态效果**：水面波动、车流（双向多路段 + 高架匝道）、船只、云层漂移、灯光呼吸、
  震旦 LED 巨幕昼夜两套动画、昼夜切换。

## 技术说明

- 单 HTML 文件，Three.js r160（jsDelivr CDN，import map）。
- 全部建筑 / 地形要素为程序化体素：2m 体素壳层生成，按材质合批为 InstancedMesh
  （混凝土 / 玻璃 / 铺装 / 绿化 / 夜光五批），无任何外部模型或位图资源
  （路面与基座网格纹理为运行时 Canvas 程序化生成）。
- 第一人称碰撞采用地表高度图 + 建筑占地区 + 江面/堤岸规则；小地图、标签为 HTML 覆盖层。
- 页面内 HUD 实时显示体素数、帧率、车流数量与时刻。
