# 任务背景

生成一个**体素风格的上海陆家嘴数字沙盘**。本项目的核心目标是考核模型在体素化城市尺度还原、标志性建筑识别度、上帝视角与第一人称双模式漫游、以及光影/氛围营造上的综合能力。

# 需求范围

## 城市与空间还原

- 使用**极其精细的体素**还原上海陆家嘴真实城市风貌，包括但不限于：
  - 黄浦江沿岸空间（滨江步道、岸线转折、江面）
  - 高密度城市街区肌理与路网
  - 核心金融区组团
  - 标志性超高层建筑（须可辨识：上海中心大厦、环球金融中心、金茂大厦等「三件套」及周边重要高层）
  - 道路交通系统（主干道、匝道/桥梁感、车流动态可简但需存在）
  - 极具辨识度的上海城市天际线轮廓

## 视角与交互

- **上帝视角**：可完整展示陆家嘴与黄浦江沿岸的宏大规模，支持缩放/环绕观察（轨道相机或等价控制）。
- **第一人称沉浸**：玩家可进入体素世界，在城市街道、滨江空间、广场与建筑之间自由移动探索，感受真实尺度与繁华感。
- 两种模式应可切换，控制说明清晰。

## 光影、材质与环境

- 电影级光影目标：合理日夜或主光方向、阴影与氛围光，避免纯平涂塑料感。
- 真实材质感（在体素风格约束下）：玻璃幕墙、混凝土、水面、道路、绿化等应有材质区分。
- 动态环境效果（至少其一）：水面波动、车流、云层/雾、灯光呼吸或昼夜切换等。

## 风格定位

- 将体素艺术与数字孪生/开放世界体验结合；目标是**艺术级、游戏级**的陆家嘴体素世界。
- 尽最大程度展现空间理解、建筑还原、视觉设计与沉浸式体验能力。

# 交付与限制要求

- 优先交付**单 HTML**（Three.js 等引擎可通过可靠 CDN 引入），双击即可运行。
- 建筑与城市布局以程序化体素构建为主；不使用需要联网下载的外部 3D 模型文件作为主体（CDN 引擎库除外）。
- 不得抄袭工作区外的项目；不得只用一张贴图或视频冒充交互沙盘。
- 不得包含 TODO 或未完成占位符。
- 控制方案与模式切换方式需在界面上或 README/log 中说明。
