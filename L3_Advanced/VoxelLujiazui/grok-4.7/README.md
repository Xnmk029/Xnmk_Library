# 陆家嘴体素沙盘

双击 `index.html` 即可在浏览器中打开（需能访问 jsDelivr，用于加载 Three.js r147）。场景全部由程序化体素搭建，不依赖外部模型。

默认是黄昏时分的上帝视角：从外滩一侧望向陆家嘴。画面左侧偏北是东方明珠，金茂大厦为逐层收分的塔形，环球金融中心顶部有贯穿的开孔，上海中心是最高的扭转玻璃塔。黄浦江、滨江步道、陆家嘴中心绿地、世纪大道、街区路网和南浦大桥（含浦西螺旋匝道）都在场景里。

## 操作

- **上帝视角**：按住左键旋转，滚轮缩放，右键平移。点击小地图可把观察中心移到该处。
- **步行漫游**：点击「步行漫游」或按 `V`。再点击画面锁定鼠标。`WASD` 或方向键移动，鼠标环顾，空格跳跃，`Shift` 加速。可在外滩步道、陆家嘴滨江、中心绿地、世纪大道、南浦桥面之间传送。
- **昼夜**：黎明 / 正午 / 黄昏 / 夜景，或拖动时间条。勾选「昼夜自动」后约 140 秒转完一天。`N` 在黄昏与夜景之间切换。
- **其他**：`H` 收起或展开说明，`M` 开关小地图，`F` 全屏。小地图上方为北。

江面会波动，路上有车，江上有船，夜景亮窗与塔顶警示灯会呼吸。
