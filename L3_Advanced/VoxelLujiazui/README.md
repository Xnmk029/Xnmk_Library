# VoxelLujiazui：体素陆家嘴三件套场景搭建

## 分类元数据

- **测试领域**: 3D 图形、物理仿真与 Shaders
- **难度等级**: `L3`（高级）
- **核心技术栈**: Three.js / Voxel / Procedural City
- **核心考核点**: 体素城市尺度还原、地标天际线辨识、上帝视角+第一人称、光影与动态环境

## 任务定位

测试模型用体素语言搭建可探索的陆家嘴数字沙盘，并同时给出宏观天际线与街巷尺度体验。

### 任务要点速览

- 精细体素：黄浦江岸、路网、金融区、三件套等地标、天际线。
- 双模式：上帝视角环绕 + 第一人称街道/滨江漫游。
- 电影感光影、材质区分、动态环境（水面/车流/雾/昼夜等）。
- 单 HTML 优先；禁止抄袭工作区外项目、禁止贴图冒充。

## 输出要求

- 单 HTML 可运行（CDN 引擎允许）。
- 模式切换与操作说明可发现。
- 无 TODO/占位；主体不依赖外部 glb 等模型下载。

## 自动化验收建议

- 静态：含可辨识的上海中心 / SWFC / 金茂比例关系或轮廓特征；黄浦江与岸线存在。
- 交互：至少上帝视角相机 + 第一人称移动两条路径；说明可读。
- 动态：存在帧循环驱动的环境效果（水面、灯光、车流或昼夜之一）。
- 性能：常规桌面首帧可接受；禁止静态截图式假交付。
