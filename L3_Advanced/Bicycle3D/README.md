你是一名高级 WebGL/Three.js 开发者、创意技术专家和自行车车架工程师。请创建一个完整可运行的单文件 HTML 应用：交互式 3D 自行车工作室与装配模拟器。

### 完整自行车系统

- 程序化生成完整自行车，不使用外部 3D 模型。
- 至少覆盖车架、前叉、碗组、把立、弯把、手变、把带、线管、座管、坐垫、中轴、曲柄、牙盘、脚踏、前后拨、刹车、碟片、轮组、花鼓、辐条、飞轮、轮胎。
- 使用清晰的层级、锚点、局部坐标、组件注册表和重建函数维护机械依赖。
- 参数变化后，相关部件必须继续对齐，不得漂浮、穿插或脱离安装点。

### 车架参数

- 独立控制 Stack、Reach、头管角、座管长度、座管角和后下叉长度。
- 提供车架紧凑度/压缩参数。
- 支持传统与下沉式后上叉。
- 参数变化应真实影响轮距、前三角、转向轴和接触点。

### 传动与适配

- 支持 1、2、3 片牙盘。
- 支持 7–12 速飞轮，数量、宽度、间距和齿片尺寸可见变化。
- 显示 1×12、2×11、3×9 等配置文本。
- 支持坐垫前后、座管高度、车把宽度、抬升和外撇角。

### 分解动画

- 分解动画沿真实安装轴和连接关系运动。
- 轮组沿车轴外移，前叉沿转向轴分离，碗组沿头管分解，座管向上移出，曲柄沿中轴方向分开。
- 动画可逆、平滑，不使用随机放射式散开。

### 视觉与环境

- 使用明亮可读的动漫赛璐璐、轮廓线、色块和适度像素化/海报化视觉。
- 避免整体过暗、阴影吞噬结构或 bloom 遮挡轮廓。
- 场景为有尺度感但不过度杂乱的仓库自行车工作室。
- 提供车架、前叉、轮圈、传动和座舱配色及 gloss、matte、metallic、carbon-inspired 等表面预设。

### UI 与规格

- 控件按 Frame Geometry、Drivetrain、Fit & Cockpit、Assembly、Colors & Finishes、Render Style、Specifications 分组。
- 实时显示几何参数、传动规格和估算重量。
- 提供重置、相机预设、标签、UI 折叠等基础功能。

### 轻量传动台子任务

- 另提供低多边形动态自行车传动展示台。
- 包含曲柄、牙盘、链条、5–7 片飞轮、后拨和透明亚克力支架。
- 支持电机启停、升挡、降挡和当前挡位显示。
- 换挡时后拨与链线平滑插值，并保持传动同步。

## 输出要求

- 交付可复制运行的单个 HTML 代码块。
- Three.js 与 OrbitControls 可通过可靠 CDN 引入。
- 不得输出伪代码、局部片段、TODO 或要求用户补齐核心功能。

## 自动化验收建议

- 对每个参数执行最小值/中值/最大值测试，并检查有限数值。
- 自动记录关键锚点距离和机械部件对齐误差。
- 换挡后验证飞轮数量、后拨位置、链线路径和 HUD 一致。
- 分解后再复位，比较组件世界矩阵与初始状态。
- 收集 FPS、draw calls、三角形和内存指标。
