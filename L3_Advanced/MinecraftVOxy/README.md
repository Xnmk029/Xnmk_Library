## 自动化验收建议

- 确定性：node 单测验证同 seed 输出逐位一致；跨 chunk 读写正确。
- 网格：3×3×3 实心立方体 = 12 三角形；面剔除、贪婪合并、AO 烘焙、六向分组全部生效。
- 群系：同 seed 下 7 类群系（平原/森林/沙漠/高原/盆地/湖泊/雪山）可辨识，河流贯穿多群系。
- 交互：Pointer Lock + AABB 扫掠碰撞无穿模；DDA 射线拾取支持破坏/放置/中键拾取；行走/跳跃/飞行正常。
- 流式加载：Worker 生成/网格化零拷贝回传；进出视距加载卸载无内存泄漏。
- LOD：视距 8192 时每级 draw call 个位数；森林绒感、雪山白帽、巨树地标、河湖走向可辨识。
- 打包产物断网双击可运行，HUD FPS 与 F3 调试面板数据完整。
