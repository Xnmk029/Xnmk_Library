## 验收与评分

核心结果 40、异常边界 25、状态语义 20、可操作演示 10、可复现交付 5。基础试测只对实际执行的断言报告通过率，不等同完整百分制成绩。正式排名需要进一步冻结完整夹具与反例校准。

**独立验收设计：**

1. 并发插入不丢任一方内容，结果满足声明的确定性排序；不能只比较“两边一样”。
2. A 删除旧字符、B 在邻近位置插入新字符，重连后保留未被观察到的新插入。
3. 相同操作重复投递、乱序投递后，去重和因果依赖正确；用固定操作历史验证最终文本。
4. 在收到服务确认后终止服务，重启不能丢失已确认编辑。
5. 离线刷新客户端后仍保留未确认操作；再次同步不会重复字符。
6. 对随机生成的合法操作序列，用独立参考语义核验收敛和内容保全；包括中文和非 BMP 字符。

**典型失败：**最后一次整篇覆盖导致另一方编辑丢失；界面相同但数据都丢了；只用 localStorage 在同浏览器标签间同步伪装网络协作。
