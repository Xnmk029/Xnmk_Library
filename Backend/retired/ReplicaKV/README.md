## 验收与评分

核心结果 40、异常边界 25、状态语义 20、可操作演示 10、可复现交付 5。基础试测只对实际执行的断言报告通过率，不等同完整百分制成绩。正式排名需要进一步冻结完整夹具与反例校准。

**独立验收设计：**

1. 任意已确认写入经历一台节点故障后仍可读，不能依靠浏览器缓存回显。
2. 1+2 分区下，单节点一侧不得成功提交写入；两节点一侧可以在选主完成后继续。
3. 隔离旧主后，它不能提供声称线性一致的陈旧成功读取。
4. 日志写入和响应确认边界崩溃，恢复不丢已提交数据，未提交后缀正确处理。
5. 相同 request_id 跨选主重试不会重复产生状态效果；冲突参数有确定拒绝规则。
6. 采集调用/返回时间、请求 ID、返回值和超时记录，独立执行有界历史的线性一致性检查；最终三份数据相同不是充分证据。

**典型失败：**三个状态卡片实际共用一个内存 Map；主节点切换只改 UI 标签；少数派照常写；只比较最终快照而遗漏中间错误读取。
