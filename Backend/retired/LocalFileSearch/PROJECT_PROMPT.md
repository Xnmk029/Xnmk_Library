# 本地文件搜索与增量索引

实现限定工作目录内的文件搜索服务和界面，索引 `.txt`、`.md` 文件。支持文件名与正文的字面子串搜索、命中片段、索引进度；新增、修改、改名、删除后更新结果；重启服务仍可搜索已提交的索引。

## 数据与行为契约

根目录由启动参数指定。索引 UTF-8 文件，单文件最大 1 MiB，超限或解码失败要记录跳过原因。路径以相对根目录形式输出；符号链接和 Windows junction 不跟随。查询为区分大小写的字面子串，不是 SQL 或正则；结果按相对路径排序。允许文件监听或轮询，但正常变更在 3 秒内可见，压力下用队列进度明确表示未完成。提供显式全量重扫以修复漏掉的文件事件。

## 交付要求

后端、持久化索引、搜索界面、启动/重扫入口、README。可使用 SQLite FTS 等索引库，但本题规定的查询语义必须保持。根目录外的内容不能被搜索或预览。

## 运行与交付契约

使用 Node.js 24 原生模块，不安装第三方依赖，不生成 node_modules。交付 server.js、界面和 README；可拆分普通文件。启动为 node server.js --port <端口> --data <数据目录>，额外参数见各题。所有服务仅监听 127.0.0.1；GET /health 返回 JSON {"ok":true}，GET / 提供可操作界面。数据目录不存在时创建；重启指使用同一目录重新启动。JSON 响应 Content-Type 正确，错误返回非 2xx 与 {"error":"原因"}；响应不能假装成功。界面从真实 API 获取结果，能完成题述演示，不能用随机数或固定样例模拟后端状态。用户提供的文本按纯文本展示。

交付不包含 TODO、未实现分支或需用户补充的核心逻辑。README 写明启动方式和操作流程。用到的样例数据由程序或用户在本地生成，不依赖账号、网络服务或其他项目文件。

## HTTP/CLI 接口

额外启动参数 --root <被索引目录>。POST /api/rescan 在扫描原子提交后返回 {ok:true}。GET /api/search?q=<字符串> 返回 {matches:[{path,snippet}]}，每文件最多一条，空查询返回所有已索引文件；GET /api/preview?path=<相对路径> 返回 {path,content}。根目录不存在则启动失败。文件监听或轮询在 3 秒内更新。GET /api/status 返回 {indexed,skipped:[{path,reason}]}。
