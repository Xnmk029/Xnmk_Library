## 验收与评分

核心结果 40、异常边界 25、状态语义 20、可操作演示 10、可复现交付 5。基础试测只对实际执行的断言报告通过率，不等同完整百分制成绩。正式排名需要进一步冻结完整夹具与反例校准。

**独立验收设计：**

1. 测试夹具同时包含中文、空格文件名、同名不同目录和不可解析文件；与直接扫描的真值比较。
2. 修改前后文件大小相同，且修改时间被恢复，执行全量重扫后仍必须发现内容变化。
3. 连续新增/改名/删除并重扫后，不残留旧路径、不出现重复命中。
4. 服务在索引批次中被终止；重启后结果来自完整提交状态，能够继续重建。
5. API 直接请求 `../`、绝对路径及通过链接指向根外的路径，均不能读出根外内容。
6. 禁止通过只修改页面列表来模拟索引更新：关闭界面，继续修改文件，再由独立 API 请求验证。

**典型失败：**只用 mtime 判断变化；路径参数直接拼接；重启后索引丢失；文件删除后搜索仍命中。
