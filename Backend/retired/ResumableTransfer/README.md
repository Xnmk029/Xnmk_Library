## 验收与评分

核心结果 40、异常边界 25、状态语义 20、可操作演示 10、可复现交付 5。基础试测只对实际执行的断言报告通过率，不等同完整百分制成绩。正式排名需要进一步冻结完整夹具与反例校准。

**独立验收设计：**

1. 分块乱序、重复和并发到达后，成品逐字节一致。
2. 向一块注入损坏数据，必须拒绝且状态不能计为完成。
3. 在块落盘、状态提交、成品发布的边界中断进程；恢复后已确认块可复用，状态不会谎报完成。
4. 重试合并请求只能发布同一份结果；下载永不返回部分文件。
5. 用独立网络记录确认恢复后只补传缺块；不把重传整个文件包装成断点续传。
6. 0 字节文件、非整块文件、同名不同内容文件及路径穿越文件名都有确定行为。

**典型失败：**仅浏览器内保存进度；重复块损坏输出；先返回成功再落盘；合并时读入整个大文件导致资源失控。
