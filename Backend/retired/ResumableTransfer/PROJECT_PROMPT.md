# 大文件断点续传工作台

实现文件上传服务和工作台。将文件分块并发上传，显示每块状态；刷新浏览器、终止服务或中断连接后恢复；仅补传缺块，最终提供可下载文件和 SHA-256 校验结果。

## 数据与行为契约

创建上传会话时提交文件字节数、块大小和整体 SHA-256，返回独立 upload_id；块编号从 0 开始，除末块外大小固定，每块附 SHA-256。查询会话返回已提交块集合。相同编号、相同内容重复上传幂等；不同内容返回 409，不能覆盖已确认块。全部块校验成功后原子发布成品；下载接口在发布前不可读到半成品。文件名仅是显示信息，落盘路径不能由用户文件名直接决定。

## 交付要求

上传/查询/合并/下载 API、界面、持久化状态和故障恢复说明。客户端选回同一文件时验证其身份，不能把另一文件的后半段接入旧会话。

## 运行与交付契约

使用 Node.js 24 原生模块，不安装第三方依赖，不生成 node_modules。交付 server.js、界面和 README；可拆分普通文件。启动为 node server.js --port <端口> --data <数据目录>，额外参数见各题。所有服务仅监听 127.0.0.1；GET /health 返回 JSON {"ok":true}，GET / 提供可操作界面。数据目录不存在时创建；重启指使用同一目录重新启动。JSON 响应 Content-Type 正确，错误返回非 2xx 与 {"error":"原因"}；响应不能假装成功。界面从真实 API 获取结果，能完成题述演示，不能用随机数或固定样例模拟后端状态。用户提供的文本按纯文本展示。

交付不包含 TODO、未实现分支或需用户补充的核心逻辑。README 写明启动方式和操作流程。用到的样例数据由程序或用户在本地生成，不依赖账号、网络服务或其他项目文件。

## HTTP/CLI 接口

POST /api/uploads 接收 {name,size,chunkSize,sha256} 返回 201 {id}。GET /api/uploads/<id> 返回 {id,received:[块编号],complete}。PUT /api/uploads/<id>/chunks/<编号> 接收原始二进制及 X-Chunk-SHA256；验证成功返回 200，哈希错误 422，越界/大小错误 400，相同块不同内容 409。POST /api/uploads/<id>/complete 触发合并，缺块返回 409，最终哈希错误 422，成功返回 {sha256,size}。GET /api/uploads/<id>/download 在完成前返回 409，完成后返回文件原始字节。界面包含选文件、开始/暂停/恢复、块状态和下载。
