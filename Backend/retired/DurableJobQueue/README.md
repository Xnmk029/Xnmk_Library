## 验收与评分

核心结果 40、异常边界 25、状态语义 20、可操作演示 10、可复现交付 5。基础试测只对实际执行的断言报告通过率，不等同完整百分制成绩。正式排名需要进一步冻结完整夹具与反例校准。

**独立验收设计：**

1. 并发领取时，同一个有效租约不能被两个 worker 同时拥有。
2. worker 计算后、提交前崩溃；重新执行后只出现一次有效发布。
3. 暂停 worker 直到租约过期，接管后再恢复旧 worker，旧 token 不能覆盖新结果。
4. 相同幂等键并发提交只产生一个任务，服务重启后仍成立。
5. 暂时性错误、永久性错误分别走正确重试路径，尝试次数和等待顺序可核验。
6. 独立读取产物哈希和状态历史；界面显示 succeeded 但产物不存在视为失败。

**典型失败：**宣称“只执行一次”却没有处理崩溃窗口；用内存锁代替跨进程互斥；旧 worker 覆盖接管后的结果。
