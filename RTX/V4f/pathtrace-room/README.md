# 路径追踪小房间 · GPU Benchmark

纯前端（HTML + WebGL2 + GLSL ES 3.00）的路径追踪基准程序：在浏览器里实时渲染一间小客厅，
用显卡计算光线多次弹射后的真实光照（软阴影、颜色溢出、金属/玻璃反射与折射），并自动测量多档分辨率下的采样速率。

## 运行

直接双击 `index.html` 即可运行；也可双击 `serve.bat`（自动启动本地服务器并打开浏览器），或手动执行：

```bash
python -m http.server 8080
```

然后访问 http://localhost:8080 。

> 两种方式均无需安装依赖；`file://` 直开与本地服务器行为一致。

## 操作

- 拖拽旋转视角，滚轮缩放，右键平移，双击或按 `R` 重置视角
- 左侧面板可切换场景、渲染比例、最大弹射次数、SPP、曝光
- 空格或点击按钮开始/停止自动基准测试

## 基准协议

固定「经典客厅」场景与机位，依次运行 5 档：

| 档位 | 分辨率 | 最大弹射 | 时长 |
| --- | --- | --- | --- |
| 720p | 1280×720 | 5 | 预热 2s + 测量 3s |
| 1080p | 1920×1080 | 5 | 预热 2s + 测量 3s |
| 1080p | 1920×1080 | 10 | 预热 2s + 测量 3s |
| 1440p | 2560×1440 | 8 | 预热 2s + 测量 3s |
| 4K | 3840×2160 | 8 | 预热 2s + 测量 3s |

每档统计平均/最低 FPS，换算为 M 采样/秒（分辨率 × SPP × FPS），综合得分为 5 档几何平均。
结果可导出 CSV，历史记录保存在浏览器本地。

## 技术说明

- 自研 GLSL 路径追踪：球 / 立方体 / 矩形面片 / 平面解析求交，场景与材质数据通过浮点纹理上传
- 材质：漫反射 + GGX 金属微表面 + 光滑玻璃（菲涅尔、全反射、折射）
- 面积光采样（NEE）+ 功率启发式 MIS，俄罗斯轮盘终止，多帧渐进累积（RGBA16F 乒乓缓冲）
- ACES 色调映射 + Gamma 校正输出
- 无第三方依赖、无网络请求，可完全离线使用
