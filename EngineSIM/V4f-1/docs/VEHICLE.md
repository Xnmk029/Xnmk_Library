# V4f 车辆物理与转向辅助说明

## 车辆模型（`src/sim/`）

四轮双轨模型，全部为纯 JS、无 three 依赖，可在 Node 离线测试：

- **轮胎**（`tire.mjs`）：每轮独立 Pacejka 魔术公式；相似法复合滑移（摩擦椭圆）；
  载荷敏感性（μ 随 Fz 下降）；侧向一阶松弛；滑移角限制 ±69°（防 tan 翻转）。
- **底盘**（`vehicle.mjs`）：车身系积分保留科里奥利耦合
  `vx_dot=Fx/m+vy·r`、`vy_dot=Fy/m−vx·r`（否则车辆会以零滑移“滚过弯”）；
  Ackermann 内外轮转角；开式差速器（等扭矩、无静态抓地力上限）；每轮独立刹车。
- **动力总成**（`drivetrain.mjs`）：6.4L NA V8 扭矩曲线（420~625 Nm）、
  半隐式离合器（先预测 ωe 再算传递扭矩）、6 速 + 倒挡 + 终传 3.09、
  限速器火花切断（>6800rpm 切断，回落 6400rpm 恢复，带滞回）。
- **电子辅助**：TC（抓地力估算扭矩上限 + 滑移比例削减 + 起步轮加速度限制，
  默认开）、ABS（滑移超峰释放制动力，默认开）、转向辅助（默认开，Y 切换）。
- **路面 μ**：`setSurfaceMu()` 按赛道位置缩放轮胎力
  （柏油 1.0 / 路肩 0.72 / 砾石 0.55 / 草地 0.38）。

## 实测指标（`tools/experiments/vehicle-metrics.mjs` 可复现）

| 指标 | 目标 | 实测 |
| --- | --- | --- |
| 0-100 km/h（TC 开） | 5.34 s | 5.49 s（后轮峰值滑移 0.087 <0.8） |
| TC 关 | 烧胎且更慢 | 9.90 s（滑移 1.2） |
| 100→1 km/h 制动 | 37.5 m | 36.8 m（峰值减速度 11.4 m/s²） |
| 稳态弯道峰值 | ≥0.85 g（实测 1.02） | 0.91 g |
| 直线 100km/h 5s 漂移 | <0.3 m | 5e-9 m（航向变化 ~0°） |
| 30s 随机滥用 | 0 NaN，横摆率 ≤28°/s | 24.3°/s |
| 满舵前轮滑移（无/有辅助） | 4.46°→2.24° | 25.4°→1.64°（峰值 g 0.97 保持） |
| 80km/h 甩尾救回（辅助） | 0.30 s / 0.10 rad | 0.18~0.27 s / 0.07~0.12 rad |

说明：满舵无辅助的实测滑移高于文档示例值，但“辅助把滑移砍掉一半以上且保持
峰值 g”的验收关系成立；甩尾无辅助在本模型下直接失控（>4s 未恢复），辅助救回
时间比无辅助快一个数量级以上。

## 转向辅助（`steering.mjs`，默认开）

1. **防推头限幅**：`R=v²/(μg)` → `θ=atan(L/R)`，capResponse 1.0 自适应
   （前轮滑移在线学习 2°~14° 有界，学习值高时限幅收紧最多 -35%）；
   目标轮角 9Hz 低通。
2. **自回正/漂移反打**：带符号前轮滑移角按 `alignGain·(1-|input|)` 把车轮推向
   前轴速度方向；后轴滑移 5°~12° 平滑增强反打（方向 = 后轴滑移方向）。
3. **电控横摆阻尼**：`-r·K·(1-|input|)`，松手时最强。

状态融合：后轴滑移 2°~5° 且玩家反打（输入与横摆方向相反）→ 限幅放宽到满舵；
<15km/h 淡出（1m/s 以下全关）；空中禁用。

踩坑记录：滑移角必须**带符号**传入辅助器，绝对值会让自回正修正永远朝“加深
转向”方向推，导致稳态弯道自激甩尾；侧向力方向必须与侧滑相反（Fy=-Pacejka(α)），
否则横摆自激发散。
