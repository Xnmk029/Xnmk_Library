# V4f 引擎声学 DSP 说明

## 总览

`src/engine-dsp.js` 是浏览器（经典脚本 + AudioWorklet）、Node（离线渲染/测试）三端
共用的**单文件、零依赖** DSP。文件刻意不使用 import/export：

- 页面以经典脚本加载：`<script src="src/engine-dsp.js">` → 暴露 `window.EngineDSP`；
- AudioWorklet 以模块方式加载同一文件（无 import/export 的 JS 也是合法模块）：
  `audioWorklet.addModule(new URL('./src/engine-dsp.js', document.baseURI))`；
- Node 以 CommonJS 加载：`require('./src/engine-dsp.js')`。

配置常量在 `src/engine-config.mjs` 保留一份面向 Node 工具链的副本，
`test/dsp.test.cjs` 的“配置一致性”测试锁定两份不漂移。

## burble 机制（禁止“burble 强度”参数）

十字曲轴 V8（LS 风格点火顺序 1-8-4-3-6-5-7-2）每个缸组在 720° 循环内的点火间隔
为 **270°/180°/90°/180°**（左右缸组相位互补）；平轴 V8 每侧恒为 180°。
单侧排气歧管（等长芭蕉）输出的脉冲序列因此天然携带 0.5 阶分量——这就是 burble
的全部来源。**两侧求和后总点火仍是均匀 90°**，0.5 阶会在声压中相消，因此 burble
必须按“单侧歧管通道”测量，这也解释了文档强调“单侧排气歧管自然涌现”的原因。

量化指标（`internal.analyzeBurble`）：真实点火顺序 → 单侧脉冲列车 →
等长芭蕉差分梳状 → 72Hz 二阶高通（模拟排气系统对极低频的衰减）→ FFT，
测量 0.5 阶 / 4 阶幅度比：

- 十字曲轴：≈ 0.093（测试锁定 0.04~0.2，目标 ≈ 0.09）；
- 平轴：≈ 1e-8（测试锁定 < 0.02）；
- 两者相差 ≥ 15 倍（实际 6 个数量级以上）。

## 等长芭蕉 = 每侧一根延迟线

闭端反相反射的差分梳状滤波器：

```
y[n] = x[n] - x[n-N],   N = round(2L/c * fs)
```

`L = 0.5212 m`、`c = 343.15 m/s` 时基频 `f0 = c/(4L) = 164.6 Hz`；
频率响应在 `f0, 3f0, 5f0, ...` 处为峰（共振），偶次模被抑制。
冲激响应测试锁定“只有 1/3/5… 奇次模”。

## 混响：8×8 FDN

- 反馈矩阵：Sylvester 构造的 8×8 Hadamard，乘以 1/√8（正交，能量不放大）；
- 延迟线：8 条连续素数长度（约 40ms 基准，任意采样率下两两互质）；
- 早期反射：固定 4 个反射时刻（12/30/65/110ms），预设只改增益；
- 预延迟：单条循环缓冲，预设切换时新旧读取指针交叉淡化；
- 立体声去相关：左右声道分别取 Hadamard 第 0/1 行作为湿声权重；
- 8 组预设：零延迟、小房间、车库、大厅、隧道、教堂、体育场、开阔地。

**零点击切换**：FDN 延迟线长度与早期反射时刻在所有预设下保持不变，切换时
反馈/阻尼/湿声/早期增益按 25ms 指数平滑，预延迟交叉淡化。测试锁定切换窗口
最大样本跳变不超过稳态的 2 倍。

## 声音分量

- 燃烧/排气：每侧缸组事件 → 脉冲振荡（幅度带缸间微差，确定性）→ 芭蕉梳状 →
  集管低通（随转速/油门）→ X-pipe 交叉管（3 样本交叉馈送）→ 车身亥姆霍兹
  低频加浓（二阶低通 65~110Hz）；
- 进气嘶吼：LCG 白噪声 → 带通（320~1100Hz），增益随转速/油门；
- 气门机械声：每次点火事件的高频短促咔哒（仅 high 档）；
- 断油：点火/断油标志位 → 燃烧增益 8ms 淡出，恢复供油时可能触发回火；
- 回火：快速收油（Δthrottle < -0.35 且 rpm > 3500）或断油恢复时，延迟 15~50ms
  在随机一侧排气总线注入低频爆音；
- 主输出：软限幅 `tanh(1.15x)/1.15`，峰值 ≤ 1.0。

## 质量档与 CPU

- `lite`：单正弦脉冲、无气门咔哒、FDN 不变；
- `high`：双正弦脉冲 + 气门咔哒。

20s 离线渲染实测（本机 Node 24）：lite ≈ 2~4% 单核、high ≈ 4~7% 单核
（`node tools/render-offline.mjs` 可复测）。测试锁定 lite 不慢于 high、
CPU 占比上限宽松（lite < 50%）。

## 离线渲染与桥接

- `tools/render-offline.mjs [秒] [lite|high] [输出.wav]`：20s 默认驾驶脚本，
  写 16-bit PCM 立体声 WAV，打印 CPU 占比与 burble 指标；
- `tools/bridge-server.mjs [udpPort] [httpPort]`：UDP 4001 接收外部模拟器状态
  （JSON 或 `rpm,throttle` 文本），HTTP 8081 提供 `GET/POST /state` 与
  `GET /poll`（10s 长轮询）供浏览器同步。

## 测试锁定（10 项）

1. 十字曲轴 burble 比 ≈ 0.09；2. 平轴极弱且差 ≥15 倍；3. 芭蕉只有奇次模；
4. FDN 稳定衰减；5. 预设切换零点击；6. 20s 渲染有效性与开销；7. 30s 参数滥用
无 NaN/Inf；8. 点火顺序相位表；9. 输出主频跟踪 4 阶；10. 双份配置一致性。
