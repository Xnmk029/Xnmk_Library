# V4f 3D 驾驶游戏操作指南

本文档面向 **V4f EngineSIM 驾驶模拟（Three.js 3D 驾驶场景）**，说明如何启动游戏、使用键盘 / 手柄 / 触屏操作车辆、读懂 HUD，以及一些实用驾驶技巧。

---

## 1. 启动游戏

### 方式一：本地服务器（推荐）

在项目根目录执行：

```bash
npm run sim
```

然后浏览器访问：

- 入口页：<http://localhost:8080/>
- 驾驶模拟：<http://localhost:8080/sim.html>

`npm run serve` 与 `npm run sim` 等价。

### 方式二：从入口页进入

打开入口页后，点击「驾驶模拟（Three.js 场景）」卡片即可进入游戏。

> 注意：页面必须通过本地 HTTP 服务器访问。直接用 `file://` 打开 `sim.html` 会显示加载警告，无法正常运行。

### 进入游戏

进入驾驶场景后，页面会显示标题界面。**点击页面任意位置（或按任意键）即可启动发动机并解锁声音**。浏览器出于自动播放限制，必须在用户手势后才会输出音频；即使音频不可用，画面和物理仍会正常运行。

## 2. 键盘操作

| 按键 | 功能 |
| --- | --- |
| `W` / `↑` | 油门 |
| `S` / `↓` | 刹车 |
| `A` / `←`、`D` / `→` | 转向（左 / 右） |
| `Space` | 手刹 |
| `Shift`（左 / 右） | 离合器（手动模式踩离合） |
| `Q` / `E` | 降档 / 升档 |
| `M` | 自动 / 手动变速箱切换（默认自动） |
| `G` | 前进 / 倒挡切换 |
| `I` | 点火 / 熄火 |
| `V` | 十字曲轴 V8 ⇄ 平轴 V8 切换（发动机与声音同步切换） |
| `N` | 循环切换混响空间（8 组） |
| `K` | 循环切换天空时段（4 组） |
| `T` | 牵引力控制 TC 开 / 关（默认开） |
| `B` | ABS 开 / 关（默认开） |
| `C` | 循环切换视角 |
| `R` | 复位回赛道 |
| `P` | 暂停 / 继续 |
| `H` | 显示 / 隐藏控制帮助面板 |
| `F11` | 全屏 / 退出全屏 |

### 视角循环顺序

按 `C` 依次切换：

1. **追尾视角**（chase）——默认视角，随车速自动拉远、加宽视野
2. **引擎盖视角**（hood）
3. **座舱视角**（cockpit）——驾驶员视野，车内声学效果最强
4. **轮毂特写**（wheel）
5. **环绕视角**（orbit）——缓慢绕车旋转，适合欣赏车辆

## 3. 手柄操作（XInput / 标准手柄）

连接手柄后页面会提示手柄名称，之后可全程用手柄驾驶：

| 手柄输入 | 功能 |
| --- | --- |
| 左摇杆 | 转向（带死区与平滑） |
| `RT`（右扳机） | 油门 |
| `LT`（左扳机） | 刹车 |
| `A` | 手刹 |
| `B` | 离合器 |
| `RB` / `LB` | 升档 / 降档 |
| `Y` | 切换视角 |
| `X` | 前进 / 倒挡切换 |
| `Back` / `Select` | 复位回赛道 |
| `Start` | 暂停 / 继续 |
| 十字键上 / 下 | 切换混响空间 / 天空时段 |
| 十字键左 / 右 | 转向辅助（未使用摇杆时） |
| 左摇杆按下 | 点火 / 熄火 |
| 右摇杆按下 | TC 开 / 关 |

轮胎严重打滑时手柄会振动（浏览器支持 Gamepad 振动 API 时）。

## 4. 触屏 / 移动端操作

在触摸设备上（`pointer: coarse`）会自动显示虚拟按键：

- 左侧：**油门**、**刹车**
- 右侧：**左转**、**右转**、**视角**、**复位**、**R**（前进 / 倒挡）

建议横屏游玩，双手分别控制左右两侧按键。

## 5. HUD 仪表解读

### 中央仪表

- **转速表**：弧形表盘，红区为红线区域；指针进入红区或断油时换挡指示灯点亮。
- **车速**：表盘中央大字，单位为 km/h。
- **挡位**：转速上方显示当前挡位（`1`–`6`、`R`、`N`），下方显示 `AUTO` / `MANUAL`。
- **踏板条**：左侧红色条为刹车力度，右侧绿色条为油门力度。
- **转向指示点**：踏板下方滑动的小点，指示当前转向方向与幅度。
- **状态灯**：`TC`（牵引力控制介入）、`ABS`（防抱死介入）、`SLIP`（车身侧滑）、`OFF`（驶出赛道）。

### 左上角圈速面板

- **LAP**：当前圈已用时
- **BEST**：最佳单圈
- **LAST**：上一圈用时
- **PROGRESS**：本圈完成进度（%）与圈数；若该圈驶出赛道（草地 / 砂石）会显示 `INV`，该圈不计入最佳成绩

### 右上角诊断面板

显示 FPS、绘制调用数、三角形数、音频 DSP 占用、采样率、当前混响空间、发动机型号、视角模式、输入设备（`KB` / `PAD`）以及当前路面与抓地系数（mu）。

## 6. 驾驶与操作技巧

### 基本起步（自动挡）

默认是自动变速箱，直接踩油门即可起步。想提高起步转速时：**踩住刹车 → 踩油门把转速踩到目标值 → 松开刹车**，离合器会自动半联动接合。

### 手动模式

按 `M` 切换为手动（`MANUAL`）：

- `E` 升档、`Q` 降档
- 换挡瞬间系统会自动切断点火，避免顿挫
- 按住 `Shift` 踩离合，可脱离动力自由轰油
- 红线约 6400 rpm（十字曲轴）或 7600 rpm（平轴），超过后断油保护
- 手动模式下按 `G` 在前进挡与倒挡之间切换

### 弹射 / 烧胎

关闭 TC（按 `T`）后：

- **烧胎**：拉住手刹（`Space`）同时踩油门，后轮会突破抓地力空转冒烟
- **弹射起步**：踩住刹车轰油门，松刹车瞬间油门到底（后轮滑移率会明显上升）
- 手柄上对应为：`A` 手刹 + `RT` 油门

### 漂移

1. 按 `T` 关闭牵引力控制（TC）
2. 入弯前重刹减速、打方向
3. 拉手刹让车尾甩出
4. 反打方向，用油门维持姿态

> 漂移时仪表 `SLIP` 灯会亮起，轮胎打滑超限时会有烟雾、胎响和手柄震动反馈。

### 圈速

- 赛道为闭合环形赛道，从棋盘格起跑线开始计圈
- 完整跑完一圈（超过 12 秒）才会计入圈数
- 四轮压上草地或砂石会使本圈标记为 `INV`（无效圈），不计最佳成绩
- 若车辆被困在赛道外且几乎停止，约 3 秒后会自动复位回赛道

### 声音体验

- `N` 循环切换 8 组混响空间：露天赛道 → 座舱 → 维修区 → 车库 → 隧道 → 峡谷 → 音乐厅 → 录音棚，可感受排气声在不同空间中的反射差异
- `V` 切换十字曲轴 / 平轴 V8，发动机声浪会随点火顺序同步变化（十字曲轴特有的煮水声 burble 会消失或出现）
- `C` 切到座舱或引擎盖视角时，车内低频共振与声浪会更强

## 7. 常见问题

### 页面一直停在标题界面或提示加载失败

大概率是直接用 `file://` 打开了页面。请运行 `npm run sim`，改用 `http://localhost:8080/sim.html` 访问。

### 没有声音

浏览器要求先有点击 / 按键等用户手势才能输出音频。回到标题界面重新点击任意位置即可；如果音频确实不可用，画面与物理仍会正常运行（右上角显示 `audio dsp off`）。

### 画面卡顿

参考右上角诊断面板的 FPS；可以尝试关闭浏览器其他标签页、确保使用独立显卡，并按 `F11` 全屏游玩。

### 车辆冲出赛道 / 翻不回来

按 `R` 立即复位回赛道；如果车辆停在赛道外低速不动，系统也会在约 3 秒后自动回收。

## 8. 相关命令速查

| 命令 | 用途 |
| --- | --- |
| `npm run sim` / `npm run serve` | 启动本地服务器并进入驾驶模拟 |
| `npm test` | 运行物理与 DSP 自动化测试 |
| `npm run bundle` | 重新打包 `sim.bundle.js`（修改 `src/` 后执行） |
| `npm run render` | 离线渲染发动机声音 WAV 到 `out/` |
| `npm run analyze` | 频谱分析（半阶能量、等长芭蕉共振等） |
| `npm run udp` | 启动 UDP(4001) + HTTP(8081) 桥，供外部模拟器驱动声音 |
