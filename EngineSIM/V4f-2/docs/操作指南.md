# EngineSIM 驾驶模拟 — 操作指南

## 开始驾驶

1. 打开 `http://localhost:8080/`（自动进入驾驶场景 sim.html）。
2. 点击 **「开始驾驶」**（点击同时解锁音频，标题页会显示音频状态：
   `audio: worklet` 或 `audio: scriptprocessor`；若显示 unavailable 请检查浏览器
   自动播放权限）。
3. 起步（手动挡逻辑）：
   - 车辆默认挂 1 挡，引擎怠速。
   - 按住 **Shift（离合）** + **W（油门）** 拉转速，松开离合起步；
     或者直接按 W 起步（模拟快速抬离合，TC 会限制打滑）。

## 键盘操作

| 键 | 功能 |
|---|---|
| W / S | 油门 / 刹车 |
| A / D | 转向 |
| Q / E | 降挡 / 升挡 |
| Space | 手刹（漂移利器） |
| Shift | 离合（起步/弹离合） |
| G | 倒挡（再按回 D 挡前需先换挡） |
| I | 点火/熄火（熄火后按 I 重新点火会带起动机） |
| V | 十字曲轴 ⇄ 平轴（音色即时对比） |
| N / K | 混响预设循环 / 天空时段循环 |
| T / B | 牵引力控制开关 / ABS 开关 |
| Y | 转向辅助开关（防推头/自回正/横摆阻尼） |
| C | 视角循环：追尾 → 引擎盖 → 座舱 → 轮毂 → 环绕 |
| R | 复位到发车点（同时重置挡位到 1 挡） |
| P | 暂停 |
| H | 帮助面板 |
| F11 | 全屏 |

## 驾驶技巧

- **起步**：1 挡 + 离合踩住 → 油门到 3000+ rpm → 快放离合；TC 开启时打滑会被限制，
  关闭 TC（T 键）可以烧胎起步（更慢但更有气势）。
- **换挡**：红线 6400 rpm 前升挡；转速低于 1600 rpm 降挡；**M 键**可在自动/手动之间
  切换（默认手动逻辑由玩家控制，Q/E 换挡）。
- **漂移**：入弯前重刹 → 打方向 + 拉手刹（Space）让后轴滑出 → 反打方向并给油维持；
  转向辅助开启时（Y 键，默认开）系统会自动反打救车，关闭后更考验技术。
- **防推头**：高速弯中转向辅助会主动限制前轮转角（按 R=v²/μg 计算可用半径），
  并在前轮滑移峰值附近自适应；HUD 诊断面板显示 cap% 实时值。
- **限速器**：转速到达 6600 rpm 触发火花切断（HUD 亮 CUT），伴随回火声；
  红线前尽快升挡。
- **断油滑行**：松油门且转速 >1100 rpm 时进入断油（HUD 亮 CUT），引擎声变为进气为主，
  带发动机制动。
- **视角**：追尾视角带转向预判与 G 力姿态，速度越高视野越宽（FOV 自适应）；
  若出现“视角莫名切到侧面”，请确认使用最新版本（角度回绕已修复）。

## HUD 说明

- 左侧：车速（km/h）、圈速计时（过线自动记圈）。
- 右侧：转速表（红色换挡区）、挡位（N/R/1-6）。
- 指示灯：TC（牵引力介入）、ABS、SLIP（后轮打滑）、CUT（断油/限速）、
  OFF（熄火）、ASST（转向辅助开）。
- 底部诊断：FPS、音频链路（worklet/scriptprocessor）、路面 μ、转向限幅 cap%、
  混响预设名。

## 声音与画面

- **V 键**对比十字曲轴（煮水声）与平轴（高转顺滑）——两者差异即
  “真实点火顺序 + 单侧排气歧管”的阶次结构差异（2 阶/4 阶 ≈ 0.09 vs 0.006）。
- **N 键**循环 8 组空间混响预设（录音棚/开阔地/车库/隧道/大厅/峡谷/维修区/座舱），
  切换零点击。
- **K 键**循环 4 个天空时段（晨/日/昏/夜），光照与雾同步变化。
