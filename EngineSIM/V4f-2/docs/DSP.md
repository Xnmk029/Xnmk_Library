# 音频 DSP 设计

## 1. 建模思路（参照 engine-sim 公开原理的简化实现）

```
每缸事件调度（720° 周期，90° 均匀）
  ├─ 排气门开启（EVO 300°ATDC，开度 70°）
  │    └─ 宽带脉冲（一次管共振 164.9Hz + 收集器共振 95.3Hz + 湍流噪声）
  │         └─ 汇入所在排气管边（左/右）
  │              └─ 四分之一波谐振延迟线（符号翻转反馈 → 只保留奇次模）
  │                   └─ X-pipe 部分合并（0.492 交叉）
  │                        └─ 消音器低通（1050Hz）→ 尾管延迟 → 立体声
  ├─ 进气门开启（IVO 350°ATDC）→ 集气箱带通（320Hz）
  └─ 机械声：气门嗒声、皮带声（2.3×曲轴）
立体声干声 + 8×8 FDN 混响（8 组预设）→ DC 阻断 → tanh 软限幅
```

## 2. 点火顺序与阶次结构（数学关系）

- 十字曲轴 V8：点火顺序 1-8-4-3-6-5-7-2，发火间隔严格 90°，每 720° 8 次发火
  → 主阶 = 8/2 = **4 阶**；8 阶/12 阶为点火谐波。
- 排气边分配：左岸 {1,4,6,7} 发火角 {0,180,360,540}（每边均匀 180°）
  → 单侧排气 = 2 阶基波 + 4 阶谐波；两侧 2 阶分量相位差 180°，
  经 X-pipe 部分合并（0.55/0.45 权重）后每声道保留 (1−2x) 的 2 阶残差
  → **煮水声（burble）自然涌现**：半阶/4 阶 ≈ 0.09（实测 0.096@3600rpm）。
- 平轴（Ford Voodoo 布局 1-5-4-8-6-3-7-2，左岸 {1,2,3,4}）：
  每边发火角 {0,90,450,540}，2 阶分量精确抵消 → 合并后几乎纯 4 阶
  （实测 0.0001，与十字相差约 **1000 倍**）。
- 全程**没有任何“burble 强度”参数**；差异完全来自点火顺序 × 管边几何。

## 3. 等长芭蕉 → 每侧一根延迟线

- 一次管长 0.52m → 四分之一波共振 f = c/4L = **164.9 Hz**。
- 数字实现：`y[n] = x[n] − g·y[n−D]`，D = 2L/c（往返延迟），g = 0.82
  → 极点位于奇次模 (2k+1)·164.9 Hz，**偶次模被抑制**（测试验证 2f₁/4f₁ < 奇次模 20%）。
- 反馈路径带 850Hz 低通（管壁摩擦衰减高次模）。

## 4. 混响：8×8 FDN

- 8 条**两两互质**延迟线（29.7–83.9 ms，避免梳状染色）。
- Sylvester-Hadamard 正交反馈矩阵（÷√8），每线阻尼低通。
- 预延迟 + 4 抽头早反射（延迟随 size 平滑）→ 混响输入。
- 立体声去相关：左右声道抽头错开 1–3 样本。
- 8 组预设：录音棚/开阔地/车库/隧道/大厅/峡谷/维修区/座舱。
- **切换零点击**：wet/decay/size/预延迟/早反射全部一阶平滑
  （测试：切换瞬间逐样本增量 < 0.3）。
- lite 档降为 4×4 FDN（CPU 减半）。

## 5. 动态行为

- 怠速闭环（700 rpm 目标）、转速平滑（τ≈12ms，防爆音）；
- 断油：松油门（rpm>1100）或限速器（≥6600）→ 火花切断（排气脉冲消失，
  进气/机械声保留，测试验证 4 阶分量下降 >5 倍）；
- 回火：断油/限速器切断瞬间注入低频爆音（测试验证瞬态峰值 >0.1）；
- 输出安全：DC 阻断 + tanh 软限幅（峰值 ≤0.92）+ NaN/Inf 归零；
- CPU：20s 离线渲染 ~0.6s（≈33× 实时，单核），lite 档更快。

## 6. 运行环境（同一份 DSP 三用）

- **AudioWorklet**：`ctx.audioWorklet.addModule('./src/engine-dsp.mjs')`
  （URL 基于 document.baseURI，避免 import.meta.url 打包后 404）；
- **ScriptProcessor 兜底**：worklet 加载失败时用同一 DSP 逐块直跑；
- **Node 离线**：`import { EngineDSP }` → `render(seconds, paramFn)`。
