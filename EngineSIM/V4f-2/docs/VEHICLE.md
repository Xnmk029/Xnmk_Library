## 2. 轮胎模型（Pacejka 魔术公式）

- 每轮独立：侧向 Fy = D·sin(C·atan(Bα − E(Bα−atan(Bα))))，纵向同构；
- **相似法复合滑移（摩擦椭圆）**：合成滑移 s = √(κ² + tan²α)，力按滑移分量分配，
  合力 ≤ μ·Fz；
- 载荷敏感性：μ 随 Fz/Fz0 增大略降（−10%/−8%）；
- 侧向一阶松弛（σ=0.35m）；纵向同构松弛（速率随轮面速度 |ω·r|）；
- 滑移角硬限制 ±69°（防 tan 翻转）；**烧胎衰减**（κ>0.5 力回落）、
  **极端侧偏角衰减**（α>20° 力回落）——否则开式差速器把微小不对称放大成自旋；
- 表面 μ 缩放：柏油 1.0 / 砾石 0.58 / 草地 0.42（按赛道位置查询）。

## 3. 车身动力学

- 四轮双轨刚体；**车身系积分保留科里奥利耦合项**：
  `vẋ = Fx/m + vy·r`、`vẏ = Fy/m − vx·r`（否则车辆会以零滑移“滚过弯”）；
- 载荷转移：纵向 m·ax·h/L、横向按轴 m·ay·h/t 分配；
- 横摆率软上限 1.5 rad/s（≈86°/s，保留漂移空间）；
- **低速运动学区混合**（<11 km/h）：横摆由转向几何决定 r = vx·tanδ/L、
  侧向速度强阻尼、轮胎横摆矩淡出——消除低速起步/停车时的侧偏角饱和失控；
- 轮胎速度增益：Fy 按 (vx/1.5)² 衰减（轮胎需滚动才产生侧向力）；
- 空气阻力 0.5ρCdA·v² + 滚动阻力（静止时滚阻为 0）。

## 4. 传动系

- 引擎扭矩曲线（查表插值，峰值 4400 rpm）；
- **半隐式离合器**：Tc = k·Δω（k=260·grip），上限 620 Nm；空挡时输入轴随引擎
  自由旋转；熄火后离合断开、发动机制动 = 摩擦经传动比（泵气损失随节气门变化）；
- 输入轴转速 = 驱动轴 × 传动比（引擎比轮子快 ratio·final 倍）；
- 怠速闭环调速器（Kp=0.8 Nm/rpm）+ 起动机（熄火后点火可重新着车）；
- **开式差速器**：等扭矩分配；后轴锁定近似（左右 ω 严格相等，
  消除低速混沌区发散，弯道横摆仍由滑移差产生）；
- TC：离合侧限制 ≤ 后轮牵引力总量（引擎保持高转）+ 轮侧滑移回落
  （慢适应状态机，目标峰值滑移 κ≈0.13，下限 0.35）；
- ABS：前后轮制动力钳制在抓地极限（隐式 ABS，无振荡）。

## 5. 转向辅助（默认开，Y 键切换）

1. **防推头限幅**：R = v²/(μ·g) → 允许轮角 θ = atan(L/R)（capResponse 0.8 留余量），
   9Hz 低通；前轮峰值滑移在线自学习（有界 2°–14°，限幅自适应 ±35%）；
2. **自回正/漂移反打**：前轴速度方向 ψ 充当主销后倾（全速域生效），
   车轮被推向 ψ，按 (1−|input|) 加权；后轴滑移 5°–12° 平滑增强；
3. **电控横摆阻尼**：−r·K·(0.3 + 0.7·(1−|input|))，松手时最强；
4. 状态融合：后轴滑移 >5° 且 |r|>0.2 且**反打**（输入与横摆方向相反，
   即 sign(input)·sign(r)>0）时限幅放宽到满舵；<15 km/h 限幅/阻尼淡出；空中禁用。

## 6. 渲染姿态与车轮

- 车身姿态：加速翘头（pitchTarget = −ax·0.05）、刹车点头、转向向外侧倾
  （rollTarget = −ay·0.045；three.js 约定：左转 ay>0 → 车身向右倾）；
- 车轮旋转：**正 omega（前进）→ spin.rotation.x += omega·dt**；
- 前轮：转向 pivot（Ackermann 内外轮转角）+ 滚动 pivot；后轮：滚动 pivot；
- 轮胎烟/刹车痕由滑移超过阈值触发。
