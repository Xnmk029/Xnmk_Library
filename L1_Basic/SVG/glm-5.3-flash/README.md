## 复刻方法（简述）
1. **构图对位**：从 C2RMF 扫描目测转写关键地标（头顶 ~y180、眼线 ~y432、鼻端 ~y510、唇线 ~y560、颏 ~y616、交叠双手 ~y1380–1510、右岸拱桥 ~y540、左岸蜿蜒山路 ~y650–1020、不对称山水与雾状远山），并按 1200/1600 画幅比例映射。
2. **笔触体系**：`stroke()` 生成短二次贝塞尔弧线描边（圆头笔帽、透明度 0.03–0.7）；`hatch2()` 沿“体积中心椭圆场”以阻尼切线方向排布面部/胸颈笔触（避免同心环伪影）；`flow()` 处理头发/衣纹/水纹的方向场；`taper()` 生成锥形笔触（手指、发缕、衣褶）。
3. **sfumato 分层**：面部按 阴影层→中间调层→亮部层 三层罩染（各为独立 `<g>`），再以暖色大笔触低透明度统一罩染；嘴角与眼窝另设柔化晕染。
4. **色板**：肤色暖赭多层（#482c1b→#e2b276）；衣裙深棕橄榄（#12100c→#62573c）；袖为暗金赭（#3c2e1a→#b48c56）；背景蓝绿空气透视（远山偏灰绿、水色 #405a52→#88a086、两道雾带横贯）。
5. **合规**：参考位图绝不嵌入——SVG 内 `image=0、base64=0、href=0`，全部形体为矢量路径。
