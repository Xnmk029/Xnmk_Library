## 3. 画法：程序化晕涂（sfumato）笔触引擎

画面以固定随机种子的生成式笔触引擎逐层"画"出。核心方法：

1. **形体构造层**：以多边形/胶囊体/椭圆定义头颈、躯干、衣袖、双手、山体、河桥等结构；
2. **明暗场建模**：面部用高斯明暗函数合成体积光（额丘/颧骨/下颌尖高光 + 眼窝/鼻侧/颏下投影），光源取左前上方；
3. **色阶量化 + 邻近抖动**：连续明暗值量化为 5–7 级离散色阶，并在级间随机抖动——远看是柔和的明暗渐变，近看呈现古典油画的"分层罩染"笔触带；
4. **方向场排布**：面部笔触沿环绕面部中心的等势线走向（额部趋平、颌部转竖）、发丝沿下垂流场波动、衣袖褶皱沿肢体轴向、水面笔触水平、山体沿水平地层；
5. **软边处理**：所有轮廓以低透明度跨界笔触"熔接"，配合高斯模糊雾带与人物光晕层实现 sfumato 无硬边过渡；
6. **统一罩光**：最后以超宽半透明暖釉笔触（glaze）统调，四缘暗角收束视线。
