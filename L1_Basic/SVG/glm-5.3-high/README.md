## 合规声明

- 交付的 `.svg` 为纯矢量：画面由 **21,048 个 `<path>` 笔触** + 3 个 `<rect>` + 5 个 `<ellipse>` 底层色块构成（合计 21,056 个图形元素），无 `<image>`、无 base64、无外链资源、无任何 `linearGradient`/`radialGradient` 渐变元素——形体全部由短弧线笔触（round cap、低透明度多层罩染）与锥形填充笔触（两端渐尖的一笔）层叠塑造。
- 底部仅有一层不透明显色的"imprimatura 打底色"用于统一底调，其上由两万余笔笔触覆盖塑形，非以平涂或照片级渐变替代主要形体。

## 绘制方法

生成脚本 `generate.js`（Node.js，固定随机种子 mulberry32 seed=1503，可复现，`node generate.js` 重新输出同一路径）采用「区域流场笔触」法，按古典作画顺序分层绘制（对应 13 个绘制函数，下文按视觉层展开）：

1. ** imprimatura 打底**：天空/中景/近景三段底色 + 人物剪影底形。
2. **天空**：雾状蓝绿灰长弧笔触，越近地平线越暖越亮（4 个色带，1,100 笔）。
3. **远山与冰蚀岩峰**：沿山脊线排布的短弧笔触 + 混入雾色的空气透视淡笔（远脊高雾感、近脊高对比），两上角冰蚀尖峰带雪光高光。
4. **中景大地**：左右不对称——左侧丘陵土坡，右侧偏暖；近景两侧深棕岩壁。
5. **蜿蜒小径（左）**：从左下之字形盘旋上升至垭口的暖土色道路笔触，含路缘阴影笔。
6. **河流与拱桥（右）**：蜿蜒缎带状河流 + 四孔石拱桥（桥面、拱洞暗部、桥墩倒影）。
7. **雾状远景罩染**：地平线附近半透明冷/暖雾笔，模拟达·芬奇空气透视。
8. **凉廊柱基**：画面两侧极暗的竖向柱身微影。
9. **衣裙**：深棕橄榄色裙褶流向场（褶谷压暗、褶脊提亮）、领口金线刺绣链、紧身胸衣的十字系带与"groppo"绳结、放射状集束褶。
10. **胸颈肤色的暖赭多层**：受光、胸骨凹陷、下颌投影的晕涂过渡。
11. **头发与薄纱**：中分发缝放射流（冠顶）+ 波浪下垂长发的 S 形流线，细亮发丝高光；头顶半透明灰褐薄纱罩染与额前纱缘。
12. **面部**：两遍共 3,900 余笔（粗层 + 细层高频邻近色抖动）沿额头/眼窝/鼻梁/颊/口周/下颌体积方向排布；无描边眉毛与睫毛（对位原作），眉脊仅存柔影；眼（双层眼睑、虹膜、瞳孔、角膜点光）、鼻（侧影长晕、鼻尖、鼻翼、鼻孔）、**嘴角轻挑的神秘微笑**（嘴角 sfumato 晕影 + 颊窝暗示 + 下唇中央高光）、颏球高光与颏唇沟，最后整脸透明罩染统一。
13. **双手与扶手**：右手松弛搭在左腕上（背手肌腱、五指锥形笔触圆柱明暗、指背高光、指尖指甲暗示、腕褶与袖口薄纱），左手四指弯向右下；pozzetto 扶手织物流垂褶。
14. **最终光油层**：透明暖色罩染 + 四角暗角，模拟古画釉面。

色板贴近原作：赭褐 / 暗金 / 橄榄绿 / 深棕为主（10 级肤色阶梯 + 10 级发色 + 10 级裙色 + 6 组背景色带），每笔颜色在邻近色范围内随机抖动（±3~7/255 通道），低透明度层层罩染，明暗过渡柔和无硬边——远看成画、近看可见笔触。
