## 参考图来源与许可状态

- **作品**：列奥纳多·达·芬奇《蒙娜丽莎》（Mona Lisa / La Gioconda），约 1503–1506 年，现藏法国巴黎卢浮宫（INV 779）。
- **参考图**：Wikimedia Commons 文件 *File:Mona Lisa, by Leonardo da Vinci, from C2RMF retouched.jpg*（卢浮宫 / C2RMF 提供的公开高清扫描）
  - 文件页：https://commons.wikimedia.org/wiki/File:Mona_Lisa,_by_Leonardo_da_Vinci,_from_C2RMF_retouched.jpg
  - 直链：https://upload.wikimedia.org/wikipedia/commons/e/ec/Mona_Lisa%2C_by_Leonardo_da_Vinci%2C_from_C2RMF_retouched.jpg
- **许可状态**：原作创作于 16 世纪初、作者 1519 年去世，已进入全球公共领域（公有领域作品，PD-old-100；美国亦属公有领域）。该扫描件为公共领域原作的忠实复制品，不产生新的独立版权（PD-scan / faithful reproduction），故构图参考使用完全合规。
- **使用边界**：仅用于构图测量（人物比例、位置、明暗分区）。参考位图**未嵌入** answer.svg、未做像素描摹；所有形体均以程序化笔触重画。

## 生成方法

1. `generator.js` 用固定种子（20260825）的伪随机数产生 ~1.26 万条短二次贝塞尔弧线（quill-stroke），每条为独立 `<path>`，`stroke-linecap="round"`、无填充。
2. 按油画"由远及近、由暗及亮"的画家式顺序分 19 层沉积笔触：
   - 天空（空气感横摆笔触，左上暖光）→ 三层雾状远山（蓝绿空气透视）→ 雾霭带 → 左岸山水（橄榄丘陵、树线、蜿蜒小径、石拱桥）→ 右岸山水（岩石、河流与倒影）→ 两侧边缘柱廊（对应原作的圆柱边框）→ 近景暗部 → **人物暗色厚涂打底** → 深棕长发（中分瀑布式流向）→ 裙装（橄榄深棕，垂直褶皱明暗分层 + 金线领口刺绣）→ 衣袖 → 颈部 → **面部九层 sfumato**（暖赭打底/中层/右侧暗部/左侧受光/额部弧线/眼窝/鼻影/口周阴影/颧颊红晕，笔触沿脸颊椭圆切线即体积方向排布）→ 五官精绘（淡眉、双眼、鼻梁高光、神秘微笑的口角微扬笔画 + 鼻翼至嘴角暗影线）→ 薄纱（头顶与肩部的半透明低透明度笔触）→ 双手交叠（下左手、上右手 + 指间阴影）→ 木扶手 → 罩染融合层（极低透明度长笔触，模拟晕涂）→ 画布暗角 → 高光细笔。
3. 色板以赭褐 / 暗金 / 橄榄绿 / 深棕为主，肤色为多层暖赭，天空与远山、河流为蓝绿空气透视序列；每个层次都是邻近色数组 + 抖动，配合低透明度多层叠加形成柔和过渡——远看成画、近看可见笔触。
4. 全文件无位图、无外链、无渐变、无 base64，无 TODO/占位；可用任意浏览器或 SVG 解析器直接打开。

## 自知局限

- 程序化笔触为风格化复刻：五官、手部与解剖为示意级精度，非人工逐笔画调整，无法逐像素还原原作。
- 生成器与参考图、渲染检查产物均保留在工作区以供复核。
