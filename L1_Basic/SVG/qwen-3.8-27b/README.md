# 蒙娜丽莎 · 纯 SVG 笔触研究性复刻

达·芬奇《蒙娜丽莎》（c. 1503–1519，巴黎卢浮宫，馆藏编号 Inv. 779）的纯矢量笔触复刻。
画布 1200×1600（竖幅），全部画面由 **51,202 条锥形笔触**（两头尖、中间宽的叶状 `<path>`）
逐笔排布而成，模拟古典油画的罩染与晕涂法（sfumato）：远看成画，近看可见笔触。

## 画面构成（与原作对位）

- **人物**：居中半身像；头部微侧（观者右）、身体微转（观者左）的四分之三姿态；
  深色长发中分、头顶浅色薄纱；神秘微笑（嘴角微扬 + 嘴角暗点 + 唇下柔影）；
  双手交叠于画面下方椅面扶手（上层右手四指微曲、指缝暗线，下层左手指尖露出）。
- **背景（左右不对称山水）**：观者左——暖褐色蜿蜒小径（近宽远窄、渐入雾中）、小径上的石拱小桥、
  前景岩坡；观者右——蓝绿色河流（近宽远窄、波纹亮带）与石拱桥；两侧雾状远山（左暖右冷），
  地平线雾带统一空气透视。
- **色板**：赭褐 / 暗金 / 橄榄绿 / 深棕为主；肤色用暖赭多层分层
  （阴影 (142,100,66) → 中间调 (182,138,98) → 亮部 (216,176,130)，18 项高斯塑形项构成
  额头/眼窝/鼻梁/鼻侧/鼻尖/口周/颌线等柔和体积）；背景蓝绿空气透视渐远（景物与雾霭色按深度混合）。

## 技法说明

- 每条笔触为锥形描边：`M p0 Q c1 p1 Q c2 p0 Z` 叶状闭合路径，两端尖、中部宽，
  宽度与方向逐笔随机抖动（±12°），颜色含邻近色抖动与明暗分层。
- 底层为一遍长笔触罩染（wash，低透明度），其上按 48 个"表面"（天空/远山/岩坡/小径/拱桥/河流/
  头发/颈/面部/五官/薄纱/长袍/袖/扶手/双手…）逐层排笔；面部笔触沿轮廓切向与体积走向混合排布，
  明暗过渡全部由高斯/平滑阶函数连续调制，无硬边。
- 生成器 `gen.js` 使用固定种子（mulberry32 0xC0FFEE），输出可完全复现。
