🔬 达·芬奇 Sfumato (晕涂法) 算法映射

达·芬奇在笔记中写道：“明与暗之间应当毫无硬界，犹如烟雾弥漫空中消逝。”


本复刻在纯 SVG 环境下建立流场微笔触（Directional Flow Glazing）：

  • 短弧贝塞尔（Quadratic Bezier）：沿骨骼与肌肉走向弯曲，曲率抖动模拟手工油画排笔。
  • 多层半透明罩染：透明度严格控制在 0.4~0.85，经 30~50 层渐进叠色呈现皮肤温润通透感。
  • 邻近色微扰（Color Jitter）：在 RGB 空间施加 ±6~12 的细微色相震荡，消除机械平涂感。
📐 背景透视与不对称构图

背景严格还原卢浮宫原作的非对称地平线：左侧地势较低，含蜿蜒小径与奇岩；右侧地势较高，含三孔石拱桥、冰川湖泊与空气透视渐远雾山，制造出神秘的时空张力。

2. 纯矢量与零位图合规声明

本作品为 100% 纯矢量 SVG，包含 17,459 个 <path>、<rect>、<filter> 标签，完全无任何 base64 嵌入位图或外链图像。所有光影、形体与微笑神态均由矢量贝塞尔笔触层叠塑造。
