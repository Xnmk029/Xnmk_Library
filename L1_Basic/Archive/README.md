## 输出要求

- 多文件交付：每个脚本独立成文件，附带 `README.md` 说明用途、用法与依赖。
- 零额外依赖优先：优先使用系统自带能力（PowerShell 5.1+ / Bash / Python 标准库）。
- 安全合规：不执行破坏性系统操作；涉及文件写入必须带备份与回滚说明。
- 明确标注脚本运行平台，跨平台脚本需做平台分支。
- 脚本须可直接运行，不得包含 TODO 占位或需要用户补齐的核心逻辑。

## 自动化验收建议

- 主题切换：验证修改前生成带时间戳的备份文件；重复执行不重复写入（幂等性）；切换结果可通过配置文件 diff 验证。
- 文件批处理：dry-run 模式仅输出操作清单不落盘；删除/覆盖类操作须二次确认并产生操作日志。
- 环境巡检：输出对齐文本表格或 JSON；抽查版本、磁盘字段与真实探测结果一致。
