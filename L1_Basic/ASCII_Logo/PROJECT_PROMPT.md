# ASCII 文字图画：模型 ID + Logo（自主命题）

> 无参考，仅提示词文字。测试模型的纯 ASCII 字符艺术构图能力与单文件交付能力。

## 任务

在单个 HTML 文件中完成一幅 ASCII 文字图画，主题为**被测模型自身的「模型 ID + Logo」**：

1. **主体**：模型 ID 文字（被测模型应如实输出自己的 ID 与版本号，例如 `GLM-5.3`）的纯 ASCII 字符画，使用 `# @ % * + = - : . ~ / \ | ( )` 等可打印 ASCII 字符拼绘，主体尺寸不小于 **80 列 × 16 行**。
2. **Logo**：配套一个同风格 ASCII Logo 图形（几何抽象或具象均可），与文字主体共同构成完整版面，含边框装饰。
3. **交互**：提供「复制全部」（复制 ASCII 文本到剪贴板，含成功反馈）与「下载 .txt」两个按钮。
4. **风格**：深色终端风格页面（黑底绿字或琥珀字），等宽字体展示；**禁止**使用图片、SVG、canvas 像素转储——所有视觉必须由 ASCII 字符构成。
5. **交付**：单文件 HTML，双击即可运行，无外部依赖、无网络请求。

## 约束

- 不得含 TODO / FIXME / placeholder / TBD 等占位符。
- ASCII 画必须手工构图排版（字符密度渐变体现立体感），不得退化为一行纯文本标题。
