# PY 流光 — 桌面 CPU / 内存悬浮球（PyQt6）

一个置顶、无边框、半透明的桌面悬浮球小部件：实时显示 CPU / 内存占用率，
液态玻璃质感（径向 / 锥形渐变、高光、光晕、旋转光环），支持拖拽移动与多种视觉样式切换。

## 运行方式

```bash
# 1. 安装依赖（Python 3.9+）
pip install -r requirements.txt
# 或直接安装：
pip install PyQt6 psutil

# 2. 启动
python main.py
```

启动后悬浮球直接可见、可交互。首次启动位于主屏右下角偏内侧，拖拽后位置会被记忆。

## 功能说明

### 悬浮球本体
- 无边框（Frameless）+ 置顶（Always-on-Top）+ 工具窗口（Tool）+ 透明背景。
- 鼠标左键按住可拖拽移动；右键菜单提供「设置...」「重置位置」「退出」。
- 球体直径可在设置面板中调节（60–140px）。

### 数据展示
- 后台 `QThread` 线程每 1 秒采样一次 CPU 与内存占用率（psutil 真实读取；
  若未安装 psutil 则自动退化为平滑模拟数据源），通过 Qt 信号投递到 UI 线程，不阻塞主线程。
- 外环弧 = CPU 占用率，内环弧 = 内存占用率，中央显示数字百分比（默认 CPU，可切换为内存）。
- 鼠标悬停显示 tooltip：CPU / 内存具体数值。

### 视觉样式（液态玻璃）
- 彩虹 / 单色光环切换：彩虹模式使用锥形渐变全彩环；单色模式为明暗渐变光环（颜色可选）。
- 多层低透明度圆环形成外发光光晕；玻璃球体使用径向渐变 + 顶部高光。
- 光环旋转速度可调（0–360°/s，0 = 停止），旋转动画定时器仅在需要时运行以降低占用。

### 设置面板
右键菜单 → 「设置...」打开，包含：直径滑块、光环模式下拉框、颜色选择器（QColorDialog）、
线宽滑块、窗口不透明度滑块、旋转速度滑块、显示模式下拉框（常显 / 悬停显示）、中央指标下拉框。
**所有改动即时生效，并自动保存到 `~/.py_flowing_light.json`**（含窗口位置），下次启动恢复。

## 模块结构

| 文件 | 职责 |
| --- | --- |
| `main.py` | 程序入口：组装监控线程、悬浮球与设置面板 |
| `config.py` | 配置模型（dataclass）与 JSON 持久化（含取值范围校验、原子写入） |
| `monitor.py` | 后台采样线程（psutil 优先，缺失时模拟数据） |
| `ball_widget.py` | 悬浮球窗口与全部自绘逻辑（光环 / 弧线 / 玻璃质感 / 拖拽 / 右键菜单） |
| `settings_dialog.py` | 设置面板（滑块 / 颜色选择器 / 下拉框，即时生效并保存） |

## 平台说明

- **Windows**：窗口透明、无边框与置顶均正常工作（主要适配平台）。
- **Linux**：需要桌面合成器（如 Picom / GNOME/KDE 自带合成器）支持 ARGB 透明窗口，否则会出现黑底；置顶与无边框不受影响。
- **macOS**：无边框 + 透明可用；Tool 窗口在切换到其他应用时可能自动隐藏（系统行为），置顶正常。

## 已知限制

- 关闭设置面板不会退出程序；退出请通过悬浮球右键菜单 → 「退出」。
