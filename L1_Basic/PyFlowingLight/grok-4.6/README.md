# PY 流光：桌面悬浮球

置顶、无边框、半透明的桌面悬浮球，实时显示 CPU / 内存占用率，支持拖拽移动、液态玻璃视觉与设置持久化。

## 环境

- Python 3.10+
- Windows 10/11（完整支持透明背景、置顶、工具窗口）
- macOS / Linux 可运行，但窗口合成效果取决于系统（见下方平台说明）

## 安装依赖

```bash
pip install PyQt6 psutil
```

或使用本目录依赖文件：

```bash
pip install -r requirements.txt
```

## 启动

在本目录执行：

```bash
python float_ball.py
```

启动后屏幕右侧会出现悬浮球，无需额外操作。

## 操作

| 操作 | 说明 |
| --- | --- |
| 左键拖拽 | 移动悬浮球 |
| 左键双击 | 打开设置 |
| 右键菜单 | **设置** / **退出** |

设置项修改后立即生效，并写入配置文件。

## 设置项

- 直径：60–140 px
- 光环颜色、线宽、不透明度（30%–100%，对应窗口透明度）
- 旋转速度（0 表示停转）
- 光环样式：Rainbow / 单色
- 显示模式：常显 / 悬停显示（百分比文字）
- 中央指标：CPU / 内存 / 双显

球体内圈为 CPU 弧、内环为内存弧；中央显示对应百分比。

## 配置持久化

配置文件路径（与脚本同目录）：

```
float_ball_config.json
```

完整路径即 `float_ball.py` 所在目录下的该文件。首次运行使用默认值；拖拽松手或修改设置后自动保存，包含窗口位置。

## 平台说明

- **Windows**：无边框 + 置顶 + Tool 工具窗口 + `WA_TranslucentBackground` 透明背景为完整实现目标，任务栏不占用常规按钮。
- **macOS**：置顶与透明通常可用；Tool 窗口仍可能出现在 Dock。
- **Linux**：透明依赖合成器（KWin / Mutter 等）。无合成时背景可能显示为黑块，置顶行为因窗口管理器而异。

## 实现要点

- UI 主线程只负责绘制与交互。
- `ResourceMonitor` 后台线程每 1 秒读取 `psutil` 的 CPU / 内存占用，通过 Qt 信号更新界面。
- 旋转光环由 33ms 定时器驱动，不阻塞资源采样。

## 文件

- `float_ball.py` — 程序入口
- `ball_widget.py` — 悬浮球窗口与液态玻璃绘制
- `settings_dialog.py` — 设置面板
- `monitor.py` — 后台资源采样线程
- `config.py` — 配置读写
- `requirements.txt` — 依赖声明
