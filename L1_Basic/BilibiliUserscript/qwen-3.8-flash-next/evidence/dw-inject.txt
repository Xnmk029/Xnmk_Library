The strategies are automatically selected based on the URL pattern using a router-based approach. For information about how the userscript is injected into pages, see Script Injection Architecture . Overview The IP Location Display System employs three different technical approaches to inject location information into comments, each tailored to specific Bilibili page architectures: Strategy Technique Target Pages Complexity Lit Custom Elements Proxy-based component interception Video pages, new list pages, opus pages, courses High bbComment Patching Prototype method interception Festival pages, blackroom ban pages, old bangumi pages Medium MutationObserver Direct DOM manipulation Activity pages, manga pages, articles, topic pages Low The system uses a Router class to match URL patterns and dispatch to the appropriate strategy.
