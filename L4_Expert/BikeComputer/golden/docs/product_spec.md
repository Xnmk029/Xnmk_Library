# 产品定义与功能规划（golden 最小样例）

## 产品定位

GPS 自行车码表：1.54" 圆角方形彩屏、旋转编码器单键交互、离线地图 + 轨迹记录、700mAh 锂电池、光固化 3D 打印外壳。对标 Garmin Edge 130 档位的入门功能集 + 离线地图差异化。

## 功能清单与可行性

| 功能 | 实现路径 | 可行性结论 |
|------|----------|------------|
| 骑行数据（速度/距离/时间/海拔/爬升/卡路里/航向） | GPS NMEA RMC/GGA 解析 + 卡尔曼/滑动滤波 | ✅ 可做 |
| 离线地图 + 实时定位 + 缩放 | PC 端下载 OSM 瓦片 `/z/x/y.png` → 转换工具输出 RGB565 二进制 `/MAP/z/x/y.bin` → SD 卡 → 运行时按需加载至 RAM 缓存 | ✅ 可做（核心差异化功能） |
| 轨迹记录 + GPX 导出 | 1Hz 定位点抽稀后追加写入 `/TRACK/*.gpx` | ✅ 可做 |
| 轨迹回放 | 读取 GPX → 投影到当前瓦片视口 → 折线渲染 | ✅ 可做 |
| 计步 | LSM6DSM 内部计步 IP（embedded function）直接读步数 | ✅ 可做 |
| 地磁罗盘 | LIS3MDL 三轴磁力 + 倾角补偿（LSM6DSM 加速度）→ 方位角 | ✅ 可做 |
| RTC 时钟/表盘待机页 | MCU 内置 RTC，首次 GPS 定位后用 UTC+时区校准 | ✅ 可做 |
| 掉电数据保存 | 关机事件 → 写 `/SystemSave.json`（里程累计、设置、默认定位点） | ✅ 可做 |
| 续航目标 | 常亮屏 + GPS 连续 ≥4h | ⚠️ 受限（背光主导功耗） |
| 气压海拔 | BOM 无气压计 | ❌ 不可做（用 GPS 海拔替代，精度 ±10m） |
| 无线同步 | BOM 无 BLE/WiFi | ❌ 不可做（拔卡/未来 USB 导出） |

## UI 页面树与交互模型

```
开机 Logo 动画 (Startup)
└─ 时钟表盘 (Dialplate) —— 待机主页
     ├─ 旋转 → 骑行数据页 (SportData) —— 速度大字 + 3×2 数据格
     ├─ 旋转 → 实时地图页 (LiveMap) —— 瓦片 + 定位光标 + 轨迹层
     ├─ 旋转 → 轨迹回放页 (TrackReplay)
     ├─ 旋转 → 计步页 (Pedometer)
     └─ 长按 → 系统菜单 (SystemMenu)
           ├─ 记录控制（开始/暂停/结束）
           ├─ 罗盘校准
           ├─ 设置（亮度/时区/单位/地图源）
           └─ 系统信息（电量/SD/卫星/版本）
状态栏（全页通用）：GPS 星数 · 录制中 · SD 卡 · 电量
```

编码器操作模型：旋转 = 切页/列表选择；短按 = 确认/进入；长按 = 呼出菜单或返回表盘。

## 资源量化论证（摘要，详见 hardware_design.md / firmware_arch.md）

- 全帧缓冲 240×240×16bit = **112.5KB**；采用 LVGL 双 1/4 屏 draw buffer（2×28.1KB）+ 部分刷新，峰值占用可控。
- 全屏 60fps 需 SPI ≈ 55.3Mbps；AT32F435 SPI1 最高 90Mbps（fPCLK/2），配合 DMA 与脏区域刷新可达 UI 动画 40-60fps。
- RAM 预算：LVGL draw buffer 56.3KB + 地图瓦片缓存 4 块 × 36.9KB(256² RGB565 半速加载实际按 128² 瓦片 32.8KB×4) + 轨迹环形缓冲 8KB + UI/系统 ~100KB，总量 < 400KB，余量充足。
- 续航：见 hardware_design.md 功耗表，估算常亮 ~160-190mA → **约 3.7-4.4h**。
