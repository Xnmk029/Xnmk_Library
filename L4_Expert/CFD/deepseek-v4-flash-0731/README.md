# CFD & SPH BENCHMARK V2.0.1

双模式流体仿真基准测试工具（工业分析风格，纯本地运行）。

## 运行

直接用浏览器打开 `index.html` 即可，无需服务器、无需联网（Three.js 已打包进 `dist/app.js`）。

修改 `src/` 下的源码后，在项目目录执行：

```powershell
npm run build
```

自动化验收：

```powershell
npm run qa
```

性能基准（CPU 物理步进，流动工况）：

```powershell
npm run bench          # Node 环境
npm run bench:web      # 无头浏览器环境
```

当前基准（2026-07-31，浏览器实测）：

| 预设 | 粒子数 | 物理耗时/步 | 60 FPS 物理预算 | 渲染耗时（软件） |
| --- | --- | --- | --- | --- |
| 低 | 968 | ~1.8 ms | ~5 ms | <1 ms |
| 中（默认） | 1404 | ~3.4 ms | ~11 ms | <1 ms |
| 高 | 3072 | ~5.8 ms | ~25 ms | ~12 ms |

中档在 60 FPS 下可保持 1.0x+ 实时倍率；高档由 AUTO 自动降低倍率以换取分辨率。

## 功能

- 标签页 01：F1 虚拟风洞 — 占位场景，仅提供几何线框预览，无求解器。
- 标签页 02：大坝决堤 SPH — 完整三维 PBF（Position Based Fluids）实时求解：
  - 水箱 1.20 x 0.75 x 0.60 m，水柱 0.40 x 0.55 m，开闸瞬间释放；
  - 闸门锁定静置阶段（T < 0），T = 0 自动开闸；
  - 空间哈希邻域搜索 + 对称粒子对缓存 + 鬼墙边界 + XSPH 粘性；
  - 三档质量预设（低 1.0K / 中 1.7K / 高 3.1K 粒子）；
  - 速度场 / 压力场两种粒子着色；
  - 实时遥测：水位 S1、波前位置、系统动能、物理耗时；
  - 自动时间倍率（AUTO）以 60 FPS 为同步目标。

## 技术说明

- 内核：SPH-PBF（Macklin & Müller 2013），密度约束采用 Poly6 / Spiky 核，
  基准密度按初始晶格实测标定，避免启动收缩；
- 边界：鬼墙（ghost wall）参与密度、约束梯度和位置修正，另加硬边界投影与壁面摩擦；
- 性能：哨兵网格消除邻域搜索边界分支，核权重跨阶段复用；中档实测约 3.4 ms/物理步，
  60 FPS 下物理+渲染约 12 ms/帧，可保持 1.0x+ 实时倍率；AUTO 模式在帧率吃紧时先降约束迭代再降倍率。
