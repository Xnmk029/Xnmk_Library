# One-Shot 提示词:《雾巷》——单文件 WebGL2 超拟真渲染技术演示

> 用法:整段复制给被测模型,要求单轮输出完整作品。
> 评测配套:固定种子 + 自动运镜,可在 T=5s/10s/20s 截图横向对比各模型产物。

---

## 提示词正文(以下为交给模型的内容)

你是一名资深图形程序员。请一次性输出一个**单 HTML 文件**的实时渲染技术演示作品《雾巷》:雨夜霓虹死胡同中的一座镜面雕塑。要求管线级的真实感,而非贴图堆砌感。

### 零、硬性约束(违反任意一条即失败)

1. **单文件**:全部 HTML/JS/GLSL 在一个 `index.html` 内,GLSL 用模板字符串,`#version 300 es`。
2. **零外部依赖**:禁止任何网络请求、CDN、图片、字体、模型文件、第三方库(不得使用 three.js)。所有纹理、几何、环境全部程序化生成。HUD 可用 HTML overlay + 系统 monospace 字体。
3. **原生 WebGL2**,需要 `EXT_color_buffer_float`(缺失时降级为 RGBA8 LDR 管线并在 HUD 标红说明)。
4. **确定性**:全局随机数用 mulberry32(seed=1337),自动运镜模式下任意两次运行逐帧一致。
5. 性能目标:1080p 下独显 60fps、核显 30fps;内置自动降级(见第九节)。
6. 禁止占位符与伪代码,输出完整可运行代码;预计规模 3000~4500 行,不得截断。

### 一、场景规格:L 形死胡同(可玩半径约 30m)

```
            ▓▓▓▓▓▓▓▓▓▓  ← 唯一开放端:雾墙(45/55/65m 三层剪影楼 + 70m 顶部红色航空灯,1.2s 周期闪烁)
   楼A(左) │            │ 楼B(右)
   内景映射窗×6│  ◆雕塑+基座 │ 两层玻璃幕墙(SSR 主秀面)
   青色竖霓虹  │  ◉主积水    │ 品红横霓虹
   金属卷帘门  │  井盖·白线  │ 公交站玻璃棚
   (锈水痕)   │            │ 自动售货机(自发光+点光)
   路灯†(雾锥)│            │ 路灯†(可开关)
            ▓▓│▁▁人行道▁▁│▓▓
              玩家起点(死胡同端,背靠墙)
```

- 巷宽 ≈8m、长 ≈30m,两侧楼高 15~20m,三面实体墙 + 一面雾墙完成封闭。
- 地面:中央沥青车道 + 两侧人行道地砖(POM)+ 路缘石(法线倒角)。
- 细节梯度:视线高度 ±2m、路径 8m 内的表面占用最高纹理/几何预算;POM 在 8m 处淡出。

### 二、程序化材质系统(LabPBR 风格,init 时烘焙)

启动时用 shader pass 将各材质烘焙到纹理(而非每帧在着色器里算):

1. 每种材质输出四张图:albedo / normal / height / **打包 specular(RGBA)**,打包规则遵循 LabPBR:R=感知平滑度、G=F0(0~229 电介质;230~237 硬编码金属:铁金铝铬铜铅铂银,用预置 F0 色)、B=孔隙度(0~64)、A=自发光。运行时按 `roughness=(1-smoothness)²` 解码。
2. 材质清单:沥青(Voronoi 骨料法线 + 2~10m 大尺度 ±5% 明度噪声破重复,albedo≈0.06)、人行道砖(砖缝 height 供 POM,缝内积灰)、浇筑混凝土墙(模板线 + 流挂污渍)、金属卷帘(波纹 + FBM 锈斑 + 垂直锈水痕)、白色路面标线(磨损 mask,smoothness 0.55)、井盖(放射纹)。
3. 程序化贴花:油渍(变暗+轻微虹彩)、招牌下锈痕、排水口周边污渍。
4. **材质纪律(强制)**:albedo 全部 ∈ [0.02, 0.9];roughness 任何表面不得为常数(基础值 + 小振幅 FBM + 大尺度变化);法线三层频率(结构/颗粒/微闪)。

### 三、主体物:高面数铬面雕塑(场景核心)

1. **环面纽结(p=2, q=3)**参数化生成,**≥80 万三角形**,32 位索引,交错 typed array;法线由参数偏导解析求出。
2. 顶点级"锤打"位移:3 octave 细胞噪声(胞径≈4cm、深≈3mm)沿法线位移,利用参数网格邻点重算法线——让曲面镜反射的扭曲诚实暴露真实几何密度。
3. 三段式材质分区(程序化 mask):顶面雨水浸润镜面铬(roughness≈0.03)、侧面拉丝各向异性金属(切向沿纽结方向,αt/αb=0.15/0.45)、背面/下部指纹污渍(0.3+FBM)。
4. **局部视差校正 cubemap**:init 时在雕塑位置烘 6×256² cubemap(含雾!),按巷道 AABB 盒投影校正;作为曲面镜 SSR miss 的回退,禁止直接用天空色回退。
5. 混凝土基座 + 黄铜铭牌;HUD 显示三角形数,按键可切线框叠加以自证面数。

### 四、光照与阴影

1. 冷月光方向光(≈8000K)+ 2048² shadow map(16-tap Vogel 盘 PCF;PCSS 可作加分项)。
2. 天空环境:init 烘焙程序化夜空 cubemap(月辉 + 薄云 + 星点),积分出 **SH9 环境光**;AO 只压间接光,并同时做 specular occlusion。
3. 点光:钠灯 2000K×2(其一带 5% 不规则微闪)、售货机 6500K、**每块霓虹牌配同色代理点光**(自发光面必须真的照亮环境)。平方反比 + 窗函数截断。
4. 能量比例:霓虹自发光 : 路灯 : 月光地面照度 ≈ 100 : 30 : 1,让自动曝光有戏可唱。
5. BRDF:GGX + 高度相关 Smith + Schlick Fresnel;漫反射用 Hammon 2017(禁止裸 Lambert);拉丝区用各向异性 GGX;能量守恒(diffuse×(1-F))。

### 五、雾气系统(把边界变成主角)

1. 指数高度雾**解析积分**(闭式,无步进):基础 σ=0.07/m(保证 65m 处透过率 <1%),高度标尺 H=6m;另叠 1.2m 高贴地蠕动雾层(2 octave 世界空间滚动噪声调制密度 ×2.5)。
2. 内散射:雾色 = mix(天空 SH 环境色, 光源色, HG 相位 g=0.7);每盏路灯用**点光内散射闭式解(atan 积分)**生成光锥,零步进成本。月光 god ray(16 步抖动 raymarch + 时域滤波)为加分项。
3. 雾墙叙事:三层零细节剪影楼(暗色 + 2% 稀疏亮窗)+ 顶部红色航空灯,暗示城市无限延伸。
4. 软边界:距起点 26m 开始移动阻尼,30m 停止;视觉上 60m 外已全遮蔽。
5. **一致性(强制,评分点)**:SSR 命中结果按反射光程二次施雾;局部 cubemap 烘焙时含雾;自发光按透过率衰减;bloom 在雾之后,光晕自然长毛。

### 六、水系统与互动

1. **雨滴涟漪**:程序化扩散圆环(hash 网格,同 Shadertoy ldfyzl 思路)扰动积水法线,密度随雨量变化。
2. **波动方程模拟**:512² RG16F ping-pong RT,`h' = 2h - h_prev + c²∇²h`,阻尼 0.985,边界吸收(必须无反射震荡,运行 5 分钟不爆);鼠标点击地面(射线-平面求交)注入高斯脉冲;**脚步落地自动在脚下注水**。
3. 积水 mask:多 octave 噪声 + smoothstep,湿区按孔隙度加深 albedo、smoothness 拉满;干湿过渡带 roughness 渐变。
4. **雨量旋钮(Q/E 或滑条,0→1)**:联动雨痕密度、涟漪生成率、积水覆盖(时间积分)、全场湿润度、雾密度(+20%)——证明这是参数化系统而非布景。
5. 点击雕塑:铬 → 拉丝 → 锤打哑光三态循环,0.5s 平滑过渡;L 键开关右侧路灯(动态光影 + 雾锥同步消失)。

### 七、反射/折射/内景

1. **SSR**:线性步进 32 步 + 二分精化 5 步 + 屏幕边缘衰减;粗糙反射用上一帧场景 mip 链按 roughness 选级(禁止随机采样+时域降噪的高风险路线);输出命中距离供施雾。miss 回退:雕塑用局部 cubemap,其余用含雾天空 cubemap。
2. 玻璃(幕墙/公交棚):forward pass,屏幕空间折射(法线偏移)+ Fresnel 混合 SSR,轻微脏污 mask。
3. **Interior Mapping(全程序化)**:楼A 窗户用盒投影虚拟房间,程序化墙面/地板色 + hash 随机亮灯(约 40%)+ 噪声伪家具剪影;房间不受外部雾影响但整体调暗,玻璃加结露 mask。

### 八、相机系统(步行运镜)

1. 路径:Catmull-Rom 样条过 6 个路径点,**弧长重参数化**(256 采样 LUT)保证 1.25m/s 匀速——严禁裸 t 采样。
2. 步行分层合成:垂直起伏 3cm(步频 1.8Hz,`pow(|sin|,1.5)` 制造脚跟触地不对称)、横摆 2cm(0.9Hz)、滚转 ±0.6°(与横摆同相)、1/f 手持噪声 ±0.15°、停步时呼吸起伏(0.25Hz)。
3. 注视:兴趣点序列(主积水 → 雕塑 → 玻璃幕墙 → 雾中路灯 → 航空灯),临界阻尼弹簧(ω≈2.5)滞后跟随。
4. 双模式(Tab 切换):自动巡游(默认、确定性、循环)/ WASD+鼠标自由行走(移动时复用同一套 bob)。
5. **静止收敛模式**:相机静止 >0.5s 后抖动累积渐进超采样,HUD 显示 "converging N spp",上限 256。

### 九、后处理滤镜链(严格按序)与降级

```
HDR(RGBA16F) → TAA(Halton 抖动+YCoCg 邻域裁剪;失败风险自评过高可改 FXAA,但需 HUD 注明)
→ Bloom(6 级 13-tap 下采样/tent 上采样,无阈值能量型,mix≈0.05;雾密度局部抬升 bloom 权重)
→ 自动曝光(log 亮度 mip 链归约到 1×1,EV 夹取,暗→亮 2s / 亮→暗 0.5s)
→ Purkinje 夜视偏移(暗部去饱和+偏蓝) → AgX 色调映射(备选 ACES fit,按键切换)
→ 分级(冷白平衡、轻微 teal-orange、饱和 1.05) → cos⁴ 暗角 0.35
→ 径向色差(仅边缘,峰值 0.25%) → 胶片颗粒(亮度调制 0.03,逐帧动画) → 三角抖动 → sRGB 输出
```

优先级与自动降级(连续 3s <45fps 依次降一档并 HUD 提示):
- P0 不可砍:线性 HDR 全流程、G-Buffer、阴影、GGX+Hammon、SH 环境光、雾系统全部、SSR+施雾一致性、积水+波动方程、≥80 万面雕塑、步行运镜、AgX+曝光+bloom+颗粒、调试视图。
- P1:GTAO、内景映射、玻璃折射、POM、各向异性、TAA+收敛模式、雨量全联动、局部 cubemap。
- P2:PCSS、god ray、色差、灯光微闪、WebAudio 程序化雨声。
- 降级顺序:SSR/雾降半分辨率 → AO 降 1/4 → 雕塑降至 40 万面 → 关收敛模式。

### 十、HUD、调试与自检(评测接口)

1. 数字键调试视图:0 最终画面 / 1 albedo / 2 法线 / 3 roughness+metal / 4 深度 / 5 AO / 6 SSR(颜色+命中 mask)/ 7 仅雾与体积光 / 8 波动方程高度场 / 9 雕塑线框叠加。
2. HUD:fps、各 pass 耗时(有 `EXT_disjoint_timer_query_webgl2` 则用 GPU 计时)、三角形数、收敛 spp、雨量值、当前模式、**各 pass 初始化状态清单(成功绿/降级黄/失败红)**。
3. 错误处理:任何 shader 编译失败必须弹出含行号的完整 log 覆盖层,禁止白屏;每个 FBO 检查 completeness。
4. 交付前自检清单(逐项确认):代码中无任何 fetch/URL;控制台零 WebGL 错误;中灰测试无双重 gamma;雾墙渐变无色带(抖动生效);自动模式匀速无脉冲(弧长参数化生效);SSR 倒影里有雾;波动方程 5 分钟稳定;seed 固定输出可复现。

### 评测备注(不随提示词发出)

- 横评机位:自动模式 T=5s(积水+霓虹倒影)、T=10s(雕塑近景)、T=20s(雾墙+路灯锥)。
- 快速穿帮检查表:①SSR 倒影是否比主画面"更清晰/无雾" ②夜空与雾墙是否有 8-bit 色带 ③运镜是否忽快忽慢 ④雕塑反射是否出现多边形折痕(面数造假) ⑤点击涟漪是否影响倒影 ⑥雾中路灯有无光锥 ⑦调试视图是否真实(AO/SSR buffer 是否糊弄)。
- 打分维度建议:管线正确性 30 / 材质纪律 15 / 雾与边界 15 / 主体物质量 10 / 运镜 10 / 交互耦合 10 / 性能与降级 5 / 自检与调试接口 5。
