# deepseek-v4-flash 四轮双轨车辆模型

车辆物理是**四轮双轨（dual-track）模型**：四个轮子各自独立计算，而不是把
一根轴的两只轮子合并成一条"轨道"。左/右载荷转移、Ackermann 转向、开式
差速器和每轮独立刹车都因此成为模型的一部分，而不是事后特效。

## 状态与坐标

底盘状态：`x, z, yaw, vx（纵向）, vy（横向，左正）, r（横摆角速度）`。

- 车身系：+x 前进，+y 左，+z 上；yaw 正 = 左转；
- 世界系：three.js 约定，+X 右、+Z 朝屏幕里；前向 = (sin yaw, cos yaw)，
  左侧 = (cos yaw, -sin yaw)，因此 `mesh.rotation.y = yaw` 直接可用；
- 四轮位置：FL/FR 在前轴 `(+a, ±track/2)`，RL/RR 在后轴 `(-b, ±track/2)`，
  其中 `a = L(1-wf)`、`b = L·wf`。

## 每轮力学

每轮一个 `Tire`（Pacejka 魔术公式，见 `src/sim/tires.mjs`）：

```
F(s) = D sin( C atan( B s - E (B s - atan(B s)) ) )
```

- `B` 由 `solveB` 在构造时二分求解，保证峰值**恰好**落在指定的
  `kappaPeak / alphaPeak` 上、峰值**恰好**等于 `μ·Fz`；
- 复合滑移用相似法：纵向/侧向滑移各自归一化后合成一个 σ，跑一次公式，
  再按滑移向量方向分解回来——得到真正的摩擦椭圆，刹车和转弯不能同时
  占满抓地力；
- 侧向力带一阶松弛（`relaxLength`），力随滚动距离建立而不是瞬间跳变；
- 载荷敏感性：`μ = μ₀·(1 - k·(Fz/Fz₀ - 1))`，载荷翻倍抓地力不翻倍；
- 打滑角限制在 ±69° 内：`tan(α)` 在超过 90° 后会翻转符号，把一次侧滑
  变成持续自旋——这是开发中被滥用测试抓出来的数值稳定性问题。

## 垂直载荷

```
Fz_FL = FzF0/2 - ΔFz_long/2 - φ·ΔFz_lat      （+ 前轴下压力/2）
Fz_RL = FzR0/2 + ΔFz_long/2 - (1-φ)·ΔFz_lat   （+ 后轴下压力/2）
ΔFz_long = m·ax·h/L        纵向转移（上一帧加速度）
ΔFz_lat  = m·ay·h/track    横向转移
φ = 0.62                   前轴侧倾刚度占比
```

## 转向：Ackermann

平均轮角 `δ` 对应转弯半径 `R = L/tan δ`，内/外轮分别按
`atan2(L, R ∓ track/2)` 计算，左转/右转符号都正确。转向随速度衰减
（高速时最大轮角自动减小），并且速率受限（3.4 rad/s），避免给前胎
阶跃激励。

## 转向辅助（src/sim/steering.mjs）

默认开启（`Y` 键开关），三部分均为纯物理/控制推导，不修改轮胎模型：

1. **防推头限幅**：速度 v、前轴有效摩擦 μ 下，前轮能维持的最小半径是
   `R = v²/(μ·g)`，对应轮角 `θ = atan(L/R)`。玩家输入被限幅到该角度
   （`capResponse=0.9`，留一点峰值余量），全油门满舵也不会把前胎压过
   魔术公式峰值而推头。前轮滑移角在接近极限时在线自学习（有界低通，
   默认 9° 附近），对限幅做 ±35% 内的自适应修正。
2. **自回正/漂移反打**：前轴速度方向 ψ 充当主销后倾——车轮被推向 ψ，
   在甩尾时就是自动反打；按 `(1-|input|)` 加权，玩家已主动打方向时不
   干预。后轴滑移超过 5°–12° 时该项强度平滑提升。
3. **电控横摆阻尼**：`-r·K·(1-|input|)`，松手时最强，用于在打转初期
   就把横摆角速度压回去；玩家打满方向时自动让位。

状态融合：后轴滑移 >2°–5° 且玩家正在反打（输入与横摆方向相反）时，
防推头限幅从抓地极限线性放宽到满舵，允许救车；低于 15 km/h 辅助整体
淡出，倒车入库手感与纯物理一致。

实测效果（Node 测试）：80 km/h 甩尾松手，辅助开启 0.30 s 救回（偏航
累积 0.10 rad），关闭需 1.77 s 且扫过 1.35 rad；100 km/h 满舵前轮
饱和从 4.46 降到 2.24，峰值侧向 g 仍达 1.02。

## 动力总成

- 发动机：曲轴单自由度（转动惯量 0.21 kg·m²），来自 deepseek-v4-flash 引擎配置的
  扭矩曲线 + 摩擦/泵气损失 + 怠速 PI 调速器 + 旋转断油限速器；
- 离合器：半隐式粘性耦合（对滑差做 backward Euler），任意刚度无条件
  稳定；自动离合在怠速上方渐进结合，车速 >4 m/s 后全锁，踩刹车停稳时
  自动分离——既能蠕动起步，又不会停着车把引擎闷熄；
- 变速箱：6 速 + 倒挡 + 终传 3.09，自动模式按**输出轴车速**换挡
  （自由轰油的引擎不会在换挡瞬间触发连锁升挡）；
- 开式差速器：左右轮等扭矩分配，**没有静态抓地力上限**——扭矩超过轮胎
  能吸收的极限时，轮速上升、滑移越过魔术公式峰值、力走下坡段，烧胎和
  限滑因此是涌现行为而不是参数。

## 底盘积分

车身系加速度包含**科里奥利耦合项**（这是四轮模型最容易漏掉的一项）：

```
vx_dot = Fx/m + vy·r
vy_dot = Fy/m - vx·r
r_dot  = Mz/Izz
```

没有 `-vx·r` 项，车辆会以零滑移"滚动过弯"——没有侧偏角、没有侧向力、
也就没有抓地力极限。测试在 1.02g 稳态弯道验证了这项的必要性。

## 与音频的关系

车辆每帧把 `engine.audioState(cabin)` 喂给 deepseek-v4-flash 的 `EngineSoundDriver`：

- 断油（限速器/换挡瞬间）→ DSP 旋转断油 + 回火；
- 松油滑行 → overrun 噼啪声强度由引擎负载与转速计算；
- TC 修的是**油门踏板**，所以被限滑时排气声真的像司机抬脚；
- 视角（追尾/机盖/座舱）改变 `cabin` 参数 → 车内低频共振与面板轰鸣；
- 轮胎滑移超过峰值时触发轮胎烟/刹车痕，`slip` 同时驱动环境声（胎噪、
  刮擦），与 DSP 完全解耦。
