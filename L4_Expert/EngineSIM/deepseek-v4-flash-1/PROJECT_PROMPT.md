## 1. 项目定位

参考 [ange-yaghi/engine-sim](https://github.com/ange-yaghi/engine-sim) 的引擎
发声思路，做一个**精简、低 CPU 占用、带混响优化**的引擎声音驱动模块，并配一套
用于验证声音与驾驶的 Three.js 场景。首个音色目标：**前中置引擎、等长芭蕉
（equal-length headers）、十字曲轴 V8** 的美式现代肌肉车，6.4L 自然吸气，
真双出排气 + X-pipe。本项目是学习项目，允许使用现成 3D 模型，但必须记录
来源与许可。

3. **分层**：`src/sim`（纯 JS 物理，可 Node 测试，不依赖 three）、`src/render`

6. **测试纪律**：物理/DSP 必须是纯函数、可离线测试；`npm test` 当前 22 项全绿，

## 3. 引擎声音 DSP 需求

- 十字曲轴 V8 的 **burble（煮水声）** 必须由真实点火顺序 + 单侧排气歧管自然
  涌现，禁止设置“burble 强度”参数（半阶/4 阶幅度比约 0.09，flat-plane 约
  0.006，差 15 倍）。
- 等长芭蕉退化为**每侧一根延迟线**（LTI 恒等变换）：理论共振 164.6 Hz
  （c/4L），偶次模被抑制，测试验证只有 1/3/5… 奇次模。
- 混响为 **8×8 FDN**：Hadamard 正交反馈矩阵、互质延迟线、早期反射 + 预延迟 +
  立体声去相关；提供 8 组空间预设（零延迟/大厅/隧道等），切换零点击。
- 断油/回火/进气嘶吼/气门机械声全部保留，控制在低预算内：`lite ≈ 4% 单核`、
  `high ≈ 7–10% 单核`（20 s 离线渲染测）。
- 浏览器与 Node 离线渲染共用同一份 DSP；提供 UDP(4001)+HTTP(8081) 桥供外部
  模拟器驱动；30 s 参数滥用 0 NaN/Inf。
- 环境音（胎噪/风噪/路缘）用少量原生节点实现，与引擎 DSP 解耦，随速度/滑移/
  座舱视角变化。

## 4. 车辆物理需求

### 4.1 底盘
- 四轮双轨模型：每轮独立魔术公式（Pacejka）+ 相似法复合滑移（摩擦椭圆）、
  载荷敏感性（μ 随 Fz 下降）、侧向一阶松弛；Ackermann 内外轮转角、开式差速器
  （等扭矩、无静态抓地力上限）、每轮刹车、半隐式离合器、6 速 + 倒挡 + 终传
  3.09、TC/ABS（默认开）。
- 车身系积分必须保留科里奥利耦合项：`vx_dot=Fx/m+vy·r`、`vy_dot=Fy/m−vx·r`，
  否则车辆会以零滑移“滚过弯”。
- 指标（当前实现，测试锁定）：0-100 km/h 5.34 s（TC 开，后轮峰值滑移 <0.8；
  TC 关则烧胎且更慢）、100→1 km/h 制动 37.5 m、稳态弯道峰值 ≥0.85 g（实测
  1.02 g）、直线 100 km/h 5 s 无横向漂移、限速器火花切断、30 s 随机滥用
  0 NaN 且横摆率 ≤28°/s。

### 4.2 转向辅助（`src/sim/steering.mjs`，默认开，`Y` 键开关）
按“转向物理辅助与自回正算法”指南实现，三部分：
1. **防推头限幅**：`R=v²/(μ·g)` → 允许轮角 `θ=atan(L/R)`，`capResponse=0.9`
   留峰值余量，9/s 低通；前轮峰值滑移角在线自学习（有界 2°–14°，限幅
   自适应 ±35%）。
2. **自回正/漂移反打**：前轴速度方向 ψ 充当主销后倾，车轮被推向 ψ
   （甩尾时即自动反打）；按 `(1-|input|)` 加权，玩家主动打方向时不干预；
   后轴滑移 5°–12° 平滑增强。
3. **电控横摆阻尼**：`-r·K·(1-|input|)`，松手时最强。
- 状态融合：后轴滑移 2°–5° 且玩家反打（输入与横摆方向相反）时限幅放宽到满舵；
  <15 km/h 整体淡出；空中禁用。
- 验收：100 km/h 满舵前轮饱和从无辅助 4.46 降到 2.24（峰值 g 仍 1.02）；
  80 km/h 甩尾松手 0.30 s 救回、偏航累积 0.10 rad（无辅助 1.77 s / 1.35 rad）。

### 4.3 渲染姿态与车轮
- 车身姿态：加速翘头、刹车点头、左转车身向外侧倾（roll/pitch 符号已修正，
  正 ax 是减速、正 ay 是左转，rollTarget 用 +ay、pitchTarget 用 −ax）。
- 车轮旋转：**正 omega（前进）对应 `spin.rotation.x += omega*dt`**（曾误用
  `-=` 导致前进时车轮倒转；`+=` 使轮胎冠部朝车头方向滚动）。
- 轮胎烟/刹车痕由滑移超过峰值触发，方向跟随车体。

## 5. Three.js 场景需求

- 赛道：闭合样条赛道、柏油贴图、双色路肩/路缘、草地/砾石（不同 mu）、
  程序化天空 4 时段（含环境 PMREM，金属/漆面不能发黑）、动态阴影跟随车辆、
  雾与天空同色、ACES 色调映射。
- 车辆模型：默认 **Quaternius Realistic Car Pack（CC0）SportsCar2**
  （`assets/models/quaternius-cars/SportsCar2.obj/.mtl`，纯色无贴图）；经典脚本
  内嵌 OBJLoader/MTLLoader 异步加载，按物理参数缩放对齐（轴距 2.946 m、
  轮距 1.62 m、轮径 0.352 m；模型原始 2.507/1.452/0.2805），车头 +Z；
  前轮挂转向+滚动 pivot、后轮合并网格挂单轴旋转组；MTL 升级为
  MeshStandardMaterial（漆面/玻璃/大灯/尾灯），尾灯随刹车发光；
  座舱视角隐藏外壳显示程序化仪表盘；加载失败自动回退程序化车身。
- 相机 5 模式：追尾/引擎盖/座舱/轮毂/环绕。追尾镜头已按 Enhanced Driver 思路
  优化：**转向预判（steering look-ahead）、G 力姿态（俯仰/横摆/侧倾）、速度 FOV、
  动态前瞻点、抖动反馈**。
- **相机角度回绕修复（必须保持）**：车辆 yaw 连续累加可越过 ±180°；相机所有
  角度统一包装域，速度方向用 `velAngle = yaw + bodySlip`（相对车头侧滑角，
  天然连续），禁止混用原始 yaw 与 atan2 包装角——否则每圈过缝瞬间相机跳
  ~126° 变成“莫名切侧视”。修复后顺行过缝 0°、漂移 2.8°、大侧滑 7.6°、倒行 0.5°。
- HUD：转速表（红区换挡灯）、车速/挡位/踏板、圈速（出赛道标 INV）、
  TC/ABS/SLIP/OFF/ASST 指示灯、诊断面板（FPS/音频 DSP/混响/mu/转向辅助 cap%）。

## 8. 已知踩坑记录

- bundle 正则漏掉 `export async function` → SyntaxError（已修）。
- Worklet 用 `import.meta.url` → 404 → 改用 `document.baseURI`。
- MTL 在 three r185 中 `parse()` 不预创建材质，需 `preload()` 后才有
  `materials.materials` 表；OBJ 多材质网格必须在重新挂载前升级材质，
  否则 `traverse` 会跳过已移出 root 的网格。
- 轮胎打滑角需限制在 ±69° 内，否则 tan(α) 过 90° 翻转符号导致自旋。
- 车轮视觉旋转方向 `+=`（前进正向滚动）。
- 相机角度回绕（见第 5 节）。
- 内嵌浏览器无法用 ES module 动态加载（见第 2 节）。
