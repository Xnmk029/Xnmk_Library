# 更深度提示词（需求汇总版）

> 本文件只汇总项目需求（做什么、验收什么）。不含实施步骤，不引用任何本地文档。

## 项目定位

参考开源项目 engine-sim（ange-yaghi/engine-sim）的引擎发声公开原理，制作一个
**计算开销低、强化混响与驾驶听感**的浏览器引擎声音驱动项目，并配一套用于验证
声音与驾驶的 Three.js 场景。首个音色目标：**前中置引擎、等长排气歧管
（equal-length headers）、十字曲轴 V8** 的美式现代肌肉车（6.4L 自然吸气、
真双出排气 + X-pipe）。

## 一、引擎声音与音频

1. 程序化合成前中置、等长芭蕉、十字曲轴 V8 音色。
2. 发火顺序、转速与主要发动机阶次必须有明确数学关系（V8 主阶 4 阶）。
3. 十字曲轴 V8 的煮水声（burble）必须由真实点火顺序 + 单侧排气歧管自然涌现，
   禁止任何“burble 强度”参数；半阶/4 阶幅度比约 0.09，平轴约 0.006（相差约 15 倍）。
4. 等长芭蕉退化为每侧一条延迟线：理论共振 164.6 Hz（c/4L），偶次模被抑制。
5. 混响为 8×8 FDN（Hadamard 正交反馈矩阵、互质延迟线、早期反射 + 预延迟 +
   立体声去相关）；提供 8 组空间预设，切换零点击。
6. 支持怠速、油门、负载、转速变化、断油/点火切断、回火、限速器火花切断、
   进气嘶吼、气门机械声。
7. 音频输出不得出现 NaN、无限值、持续削波或明显参数跳变爆音。
8. 低 CPU：lite 档约 4% 单核，high 档约 7–10% 单核（离线渲染测量）。
9. 浏览器与 Node 离线渲染共用同一份 DSP；提供 UDP(4001)+HTTP(8081) 桥供外部
   模拟器驱动。

## 二、车辆物理

1. 至少双轴双轨模型；每轮独立 Pacejka 魔术公式（复合滑移摩擦椭圆、
   载荷敏感性、侧向一阶松弛）。
2. Ackermann 内外轮转角、开式差速器（等扭矩）、每轮刹车、半隐式离合器、
   6 速 + 倒挡 + 终传、TC/ABS（默认开）。
3. 车身系积分必须保留科里奥利耦合项（vẋ = Fx/m + vy·r、vẏ = Fy/m − vx·r）。
4. 指标（测试锁定）：0-100 km/h ≈ 5.3 s（TC 开）、100→1 km/h 制动 ≈ 37.5 m、
   稳态弯道峰值 ≥ 0.85 g、直线 100 km/h 5 s 无横向漂移、限速器火花切断、
   30 s 随机滥用 0 NaN 且横摆率 ≤ 28°/s。
5. 转向辅助（默认开，可切换）：
   - 防推头限幅：R = v²/(μ·g) → 允许轮角 θ = atan(L/R)，限幅低通、
     前轮峰值滑移角在线自学习；
   - 自回正/漂移反打：前轴速度方向充当主销后倾，玩家主动打方向时不干预；
   - 电控横摆阻尼：松手时最强；
   - 状态融合：甩尾反打时限幅放宽；低速淡出；空中禁用。
6. 渲染姿态符号正确：加速翘头、刹车点头、转向时车身向弯道**外侧**倾。
7. 车轮旋转方向正确（前进时视觉向前滚动）。

## 三、Three.js 场景

1. 一条闭合样条赛道（柏油贴图 + 双色路肩/路缘 + 草地/砾石，不同 μ）。
2. 一辆可驾驶的低多边形现代美式肌肉车（搭载所模拟的引擎）；
   可使用现成模型（学习项目，需记录来源与许可）。
3. 精美程序化天空盒（多时段）、合适光照（环境 PMREM，金属/漆面不能发黑）、
   动态阴影、雾与天空同色、ACES 色调映射。
4. 相机至少包含追尾/引擎盖/座舱/轮毂/环绕五种；追尾镜头带转向预判、
   G 力姿态、速度 FOV、动态前瞻点、抖动反馈；**多圈累计航向角后相机角度必须
   连续，不得出现“莫名切到侧视”的跳变**（角度统一包装域，速度方向 =
   航向 + 侧滑角）。
5. HUD：转速表（换挡提示灯）、车速、挡位、圈速、TC/ABS/SLIP/OFF 指示灯、
   诊断面板（FPS/音频链路/混响/路面 μ/转向辅助状态）。

## 四、输入

1. 键盘：油门/刹车/转向/手刹/离合/换挡/倒挡/点火/视角/复位/暂停/帮助/全屏，
   以及曲轴类型、混响预设、天空时段、TC、ABS、转向辅助开关。
2. XInput/标准手柄：左摇杆转向、RT/LT 油门刹车、A 手刹、B 离合、RB/LB 换挡、
   Y 视角、X 倒挡、Back 复位、Start 暂停、十字键切换、打滑震动反馈。
3. 触屏自动显示虚拟按键。

## 五、工程约束与验收

1. 浏览器端零运行时依赖、零 ES module 机制：页面只使用经典脚本，
   应用打包为单文件经典脚本；AudioWorklet 优先、ScriptProcessor 兜底，
   保证页面可正常启动运行（无资源加载失败、无动态导入失败）。
2. 端口 8080 打开的是**驾驶场景**页面（而非音频实验室页面）。
3. 音频 DSP 与车辆动力学从渲染层解耦（纯函数、可离线测试）。
4. 自动化测试覆盖：DSP（发火间隔/主阶/半阶比/谐振奇次模/转速跟踪/输出边界/
   限幅/预设切换/回火/断油/CPU 预算）、车辆（怠速/加速/制动/弯道/直线/
   限速器/随机滥用/姿态符号/车轮方向/转向响应）、转向辅助（防推头/自回正/
   横摆阻尼/甩尾救车/低速淡出/空中禁用/反打判定）、渲染（相机角度连续性/
   视角切换/FOV/μ 查询/车轮方向约定）。
5. 说明参考项目与自主实现部分的边界；提供可运行工程与自动化测试。
6. 对工作区外文件、外部资源的引用必须显式披露（只读、获得同意、说明用途）。
