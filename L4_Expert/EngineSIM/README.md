# EngineSIM：V8 发动机声音与车辆动力学模拟

- **测试领域**: Python 工具与原生引擎
- **难度等级**: `L4`（专家级）
- **核心技术栈**: Web Audio API / DSP / Audio Spectrogram
- **核心考核点**: 程序化音频合成、燃烧脉冲建模、FFT 频谱图

## 任务定位

测试模型理解开源技术项目、重建程序化发动机声音，以及原项目的C++移植能力，并把音频、车辆动力学和 Three.js 场景整合为可运行产品的能力。

### 发动机与音频

- 第一阶段实现前中置、等长排气歧管、十字曲轴 V8 的程序化音色。

- 发火顺序、转速与主要发动机阶次应具有明确数学关系。

- 支持怠速、油门、负载、转速变化、断油/点火切断和混响。

- 音频输出不得出现 NaN、无限值、持续削波或明显参数跳变爆音。

### 驾驶场景

- 使用 Three.js 构建基础赛道。

- 创建可驾驶的低多边形现代美式肌肉车。

- 至少使用双轴单轨模型表达车辆平面动力学。

- 实现基础轮胎侧偏/纵向摩擦近似。

- 场景包含天空环境、合理光照、柏油路面和双色路肩。

- HUD 显示转速、车速、挡位、油门和关键性能状态。

## 输出要求

- 说明参考项目与自主实现部分的边界。

- 提供可运行工程和自动化测试。

- 将音频 DSP 与车辆动力学从渲染层解耦。

## 自动化验收建议

- Node 单测验证发火间隔、主阶次、转速跟踪、输出边界和实时预算。

- 车辆单测验证稳定怠速、加速、制动、转向与有限状态。

- 浏览器测试验证音频上下文、驾驶输入、HUD 和场景渲染。

- 录屏与客观音频采样分开；听感评分保持人工主观项。
