# V4f 操作指南

## 键盘

| 按键 | 功能 |
| --- | --- |
| W / S | 油门 / 刹车 |
| A / D | 转向 |
| Space | 手刹 |
| Shift | 离合 |
| Q / E | 降挡 / 升挡 |
| M | 自动 / 手动换挡 |
| G | 倒挡 |
| I | 点火（同时初始化音频） |
| V | 十字曲轴 / 平轴曲轴音色切换 |
| N / K | 混响预设切换（零延迟/小房间/车库/大厅/隧道/教堂/体育场/开阔地） |
| T / B | TC / ABS 开关 |
| Y | 转向辅助开关 |
| C | 相机视角（追尾/引擎盖/座舱/轮毂/环绕） |
| R | 复位 |
| P | 暂停 |
| H | 帮助 |
| F11 | 全屏 |

## 手柄（XInput / 标准）

- 左摇杆转向；RT/LT 油门/刹车（带死区与平滑）
- A 手刹、B 离合、RB/LB 换挡、Y 视角、X 倒挡
- Back 复位、Start 暂停
- 十字键上/下：混响 / 天空预设

## 触屏

首次触摸后屏幕底部出现虚拟按键：左右转向、油门、刹车、视角、复位、R 挡。

## HUD 说明

- 左侧诊断：FPS、音频路径（worklet/script）、混响预设、路面 μ、转向辅助限幅 %
- 右上：圈速（出赛道标 INV）
- 左下指示灯：TC / ABS / SLIP / OFF / ASST
- 底部仪表：转速表 + 红区换挡灯、车速、挡位、油门/刹车条

## 建议体验流程

1. `npm run serve` 打开 http://localhost:8080/ ；
2. 按 I 点火（浏览器会因用户手势创建音频上下文）；
3. W 起步（TC 默认开），M 自动换挡，C 切换视角；
4. 直线加速后 T 关 TC 感受烧胎；N/K 切混响；V 对比平轴音色；
5. 高速弯道留意 ASST 指示灯与辅助限幅百分比。
