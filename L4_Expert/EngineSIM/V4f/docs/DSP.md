# V4f 声学模型：数学、成本与实测

参考项目是 [ange-yaghi/engine-sim](https://github.com/ange-yaghi/engine-sim)：
它逐缸求解可压缩气体动力学，再把结果与实测脉冲响应卷积。那是"声音就是产品"
时的正确做法，但一个驾驶模拟器还要把 CPU 留给物理与渲染。

V4f 保留引擎**身份感**的来源，用封闭式等价物替换昂贵部分：

1. **点火顺序就是乐器**——十字曲轴 V8 的煮水声来自真实点火表，不是参数；
2. **等长芭蕉退化为每侧一根延迟线**——LTI 恒等变换，精确而非近似；
3. **混响是 8×8 反馈延迟网络（FDN）**——约 120 flops/采样、零延迟，
   换来卷积混响近 40 倍以上的成本优势；混响是 V4f 预算花得最多的地方。

---

## 1. 点火表即乐器

四冲程每缸每 720° 曲轴角点火一次。V8 八个曲柄销均匀分布，相邻点火间隔
`720/8 = 90°`。区别在于**每侧排气歧管看到什么**。

取 6.4L Hemi 顺序 `1-8-4-3-6-5-7-2`（奇数缸在左岸 A，偶数缸在右岸 B）：

| 曲轴角 | 0 | 90 | 180 | 270 | 360 | 450 | 540 | 630 |
|---|---|---|---|---|---|---|---|---|
| 气缸 | 1 | 8 | 4 | 3 | 6 | 5 | 7 | 2 |
| 排岸 | A | B | B | A | B | A | A | B |

单独收集每岸：

- **A 岸**点火于 0/270/450/540 → 间隔 **270/180/90/180°**
- **B 岸**点火于 90/180/360/630 → 间隔 **90/180/270/180°**

每岸收集器被"偏斜"的脉冲串轰击，这种不对称就是美式 V8 的煮水声。
模型里没有 burble 参数，只有一个点火顺序和一张岸映射表；
换成平轴曲轴（1-8-3-6-5-4-7-2）后，每岸变成均匀 180°，煮水声自动消失。

`test/dsp.test.mjs` 定量验证：2400 rpm 下，左声道半阶（1.5/2.5/3.5 阶）
与 4 阶的幅度比：

```
cross-plane   0.0929
flat-plane    0.0061   （约 15 倍差异）
```

## 2. 等长芭蕉：八根管子 → 每侧一根延迟线

八根一次管是八条声学波导。诚实的建模是 8 条双向延迟线，加 8 条反射线。

但规格是**等长芭蕉**：每根一次管完全一样。八个相同 LTI 滤波器各自输入不同
信号再求和，等于先求和再滤波一次：

```
Σ H(xᵢ) = H(Σ xᵢ)   当所有 H 相同
```

因此每岸一根四分之一波延迟线即可，**精确等价**——而且只有等长芭蕉成立，
这恰好就是等长芭蕉的声学意义（不等长会让共振互相抹平）。

每根一次管建模为四分之一波管：阀门端封闭、收集器端开放。负反馈梳状滤波器
的往返延迟 `2L/c`，共振位于 `c/4L` 的奇数倍。`L=0.82m, c=540m/s` 时：

```
基频 ≈ 165 Hz，后续模式 495 Hz、825 Hz……
```

实测（对 `Duct` 组件做脉冲响应）：

```
header resonance 164.6 Hz（期望 164.6）
3x/2x = 6.08e-6 / 4.87e-7   （奇数模共振、偶数模被抑制）
```

## 3. 真双出排气，否则煮水声会抵消

A 岸 0/270/450/540、B 岸 90/180/360/630，把两条脉冲串相加得到八次均匀脉冲
——纯 4 阶，煮水声完全消失。不对称只存在于**每岸内部**，求和即抵消。

所以模型保持真双出：每岸从排气门到尾管各自独立（port 低通 → 等长一次管 →
收集器 → 中管 → 消音腔 → 尾管），只有 X-pipe 做部分耦合
（`crossoverMix = 0.34`），两声道按 `0.7/0.3` 交叉馈送形成物理立体声。
两侧还带几个百分点的制造公差（中管/尾管长度、腔体频率），真实排气管
也不是克隆体——这部分公差对单声道下混时的煮水声保留很重要。

## 4. 每缸发射什么

每缸、每采样一次查表读取。排气门开启窗口（246°）内的压力脉冲被烘焙成
1024 点表：快速泄压尖峰（阀门刚开时缸内还有数巴压力、流动阻塞）→
活塞驱动的扫气鼓包 → 阀座关闭小台阶。表做过去直流处理，让管路网络
被"流量"而不是"压力偏移"驱动。

幅度由 EVO 时缸压决定，随油门、负载和容积效率（中段峰值）变化。湍流噪声
与瞬时流量成正比，随脉冲起伏而非恒定铺底。另有：

- 每缸 ±3.5% 幅度散布、±0.9° 点火角抖动（真实感的关键之一）；
- 断油缸仍泵气约 12% 并向下游释放未燃混合气——限速器听起来像机枪
  而不是淡出，回火噼啪声由此而来；
- 断油为旋转子集（8 取 5，逐循环旋转），模式永不落成单调；
- 进气侧有进气歧管 + 亥姆霍兹谐振腔、节气门嘶声；
- 机械侧有 210 Hz 轴系噪声与每 45° 一次的气门机构敲击。

## 5. 混响：8×8 FDN，不是卷积

"混响优化"是本项目硬性要求。房间用 **8 条互质延迟线 + Hadamard 8×8
正交反馈矩阵**：正交性保证再循环**构造性无损耗**，衰减只由环路增益与
每线阻尼低通决定——没有调环、没有爆音风险。

8×8 Hadamard 蝶形只需 **24 次加法 + 8 次乘法**（一般 8×8 矩阵要 64 乘 56 加）。
输入侧三级 Schroeder 全通扩散器，另有预延迟与早期反射抽头（最短两根线
的中间延迟读数），立体声输出由两套不相交的线组加权形成——不需要第二套
网络就得到去相关。

### 成本，逐采样点

| 阶段 | flops |
|---|---:|
| 8 条分数延迟读 | ~40 |
| 8 个一阶阻尼低通 | 24 |
| 输入低切/高切 + 3 全通 + 预延迟 | ~30 |
| Hadamard 蝶形 + 注入 | ~30 |
| 早期反射 + 立体声输出 | ~12 |
| **合计** | **~130** |

48 kHz 下约 **6.2 Mflop/s**，最大预设约 0.6 MB 延迟状态。

对比 1.2 s 立体声卷积混响（57,600 抽头/声道）：

- 直接卷积：约 115,000 flops/采样，**880 倍**于 FDN；
- 均匀分块 FFT 卷积（块 256）：约 2,900 flops/采样，**约 22 倍**于 FDN，
  还要 1.4 MB 冲激响应和至少一个块的延迟。

FDN **零延迟**——对驾驶模拟器很重要：发动机音符是驾驶员用来"听着换挡"的
控制信号，混响延迟等于油门与耳朵之间的延迟。

8 组预设（open/cabin/pitlane/garage/tunnel/canyon/hall/studio）只是
6 个数字（尺寸、衰减、阻尼、湿声、早期、预延迟），切换即时且零分配。

## 6. 参数平滑与安全

- RPM 在块内逐采样插值，曲轴角永不跳变（跳变就是咔哒声）；
- 油门/负载/主增益同样逐块平滑；
- 主限幅器（包络压到 0.92 附近）+ tanh 型软限幅兜底，杜绝 NaN/削波；
- 抗反常值（denormal）偏置遍布所有滤波器；
- 测试用 30 秒随机参数滥用（每 256 采样乱跳 RPM/油门/断油/回火）验证：
  `bad samples 0`、峰值 0.595、RMS 0.093。

## 7. 质量档位

| | lite（默认，精简） | high（完整管道） |
|---|---|---|
| 排气链 | portLP → 等长一次管 → 腔体峰 → 中低通 → 尾辐射 | + 收集器/中管/双消音腔/尾管 Duct、全通扩散、rasp/growl |
| X-pipe | 无 | 有（0.34 交叉耦合） |
| 进气 | 谐振腔 + 嘶声 | + 进气歧管波导 + 二次谐振 |
| 实测 CPU（Node，48 kHz，20 s，best of 3） | **约 4% 单核** | **约 7–10% 单核**（随机器负载波动） |

浏览器数值会不同（AudioWorklet 的 128 采样块调用开销、JIT、`renderCapacity`
是否可用）。Node 离线数字用于横向对比，趋势稳定：lite 足够跑在老机器上，
high 只留给想要完整管道质感的人。

## 8. 已知简化

- 不做逐缸气体动力学：脉冲形状固定，只缩放幅度/噪声，牺牲压力波-脉冲
  耦合的极端细节（engine-sim 的核心卖点）；
- 消音器是共振峰+低通，不是多腔体 TMM/二维 FEM；
- 无变速器啸叫、轮胎/风噪（属于驾驶模拟器的其他声音模块）；
- 单声道下混会损失一部分煮水声能量（物理上如此，真双出就该立体声听）。

下一步方向：更多引擎定义（直列六缸、水平对置、涡轮）、轮胎/风噪层、
doppler/多普勒监听视角。
