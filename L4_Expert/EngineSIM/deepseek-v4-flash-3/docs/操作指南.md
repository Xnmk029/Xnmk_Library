# EngineSIM deepseek-v4-flash-3 · 操作指南

> 前中置引擎 · 等长芭蕉 · 十字曲轴 V8 · 低性能要求 · 混响优化

## 启动

1. 确保已执行依赖安装与构建（或直接使用已构建产物）：
   ```
   node "C:\Program Files\nodejs\node_modules\npm\bin\npm-cli.js" install
   node "C:\Program Files\nodejs\node_modules\npm\bin\npm-cli.js" run build
   ```
   （本机 `npm` 命令包装损坏，请使用上述直调方式）
2. 启动服务器（端口 8080，根路径直达驾驶场景 sim.html）：
   ```
   node scripts/serve.mjs
   ```
   或开发模式：`node "…\npm-cli.js" run dev`（vite，同样 8080）
3. 浏览器打开 `http://localhost:8080/`
4. 点击 **「开始驾驶」**（该点击同时解锁音频；若浏览器拦截声音，点击后即可恢复）

## 键位

| 功能 | 键盘 | XInput 手柄 |
|---|---|---|
| 油门 | W / ↑ | RT（右扳机） |
| 刹车 | S / ↓ | LT（左扳机） |
| 转向 | A / D / ← / → | 左摇杆 |
| 倒车 | Shift（按住） | LB |
| 手刹 | 空格 | X |
| 复位（回起点） | R | A |
| 切换相机（追尾/外部/机舱） | C | B |

> 相机切换为显式键位操作，任何速度下都不会自动切换视角。

## HUD 说明

- 转速条（绿→黄→红，红线区 92% 起）+ 数字 RPM
- 车速（km/h）、当前挡位（N/1-6）
- 油门条
- 状态提示：`⛔ 断油`（收油高转点火切断）、`🟩 草地`（驶出赛道）、`📷 相机模式`、`🔄 辅助`（转向辅助介入）

## 驾驶特性

- **车辆**：1650kg 后驱肌肉车，6 挡自动变速，魔术公式四轮双轨物理（含载荷转移与 ABS）
- **手感辅助**（自动生效，无需设置）：
  - 防推头：按抓地力实时限制转向角（速度越高限幅越强）
  - 漂移救车：尾部侧滑时自动拓宽反打角度 + 自回正力矩
  - 横摆阻尼：松手后自动稳定车身
  - 低速（<1.8km/h）辅助完全淡出，倒车/移库无感
- **声音**：程序化十字曲轴 V8（发火顺序 1-8-4-3-6-5-7-2，0.5~8 阶次合成），支持怠速/油门/负载/断油，卷积混响可调
- **草地**：驶出赛道摩擦系数降低，易滑（可漂移）

## 已知限制

- 车辆无碰撞体（可穿越护栏/树木）
- 镜头无碰撞检测（可能穿模）
- 音频混响为程序化脉冲响应（非采样真实环境）
