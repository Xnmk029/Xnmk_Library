## 0. 一句话定义

一个**浏览器本地运行、断网可玩**的 MC 风格 3D 体素沙盒：玩法机制致敬经典体素沙盒，**材质与图案 100% 原创、程序化生成**，核心卖点是 **Voxy / Distant Horizons 式的立体远景 LOD**——8192 格视距下仍能流畅渲染一个"矮精度但立体"的无限世界。

---

## 1. 核心约束（不可妥协，验收硬门槛）

1. **原创性**：禁止使用任何官方/第三方素材。所有方块、物品贴图由 **SVG 程序化绘制**后导出为像素风贴图（Canvas 光栅化 → `THREE.Texture`，`NearestFilter` 保持像素硬边）。配色、图案、命名全部自创。
2. **离线即玩**：不依赖任何 CDN / 网络资源。Three.js 以本地文件随包分发。文件夹版通过一键 `启动.bat`（内置零配置本地静态服务器）双击即玩；另提供内联单文件 dist 版可直接 `file://` 双击。
3. **性能即特性**："更聪明的代码，不是更快的代码"——远景靠**减少需要生成的方块数量**而非加速计算。8192 视距下画面连续稳定、console 零 error。
4. **数据驱动**：方块不落单个 GameObject，全部 `TypedArray` 存储 + chunk 合并 Mesh（详见技术文档）。
5. **确定性**：同一种子（seed）永远生成同一世界，保证 LOD 各层级地形一致、远近景不冲突。

---

## 2. 玩法机制（致敬，非照搬）

### 2.1 模式
- **创造模式（本次交付主体）**：飞行 + 行走双形态，无限物品栏，瞬时破坏/放置，专注建造与探索。
- 预留生存模式接口（生命值、掉落、合成）但本期不实现，数据结构留位。

### 2.2 玩家能力
- 移动：WASD 行走，空格跳跃，Shift 下蹲/下降，飞行模式下双击空格切换悬浮。
- 视角：鼠标自由环视（Pointer Lock），滚轮切换手持物品。
- 交互：左键破坏方块（带 progressive 裂纹反馈），右键放置方块，中键拾取指向方块。
- 射线拾取：体素 DDA 射线步进（非三角面拾取），最大作用距离 8 格，高亮线框标示目标方块。

### 2.3 世界交互
- 放置/破坏实时改写 chunk 体素数据并**局部重建受影响 Mesh**（含相邻 chunk 边界面），不重建整个世界。
- 方块状态（玩家改动）以稀疏覆盖层（hash map）叠加在确定性生成之上，保证种子世界可复现、玩家改动可持久（内存级，本期不做存档落盘，预留接口）。

## 3. 世界与区块系统

- **立方体区块（3D chunk）**：世界在 X/Y/Z 三个维度均无限可探索，**无高度上限/下限**。这是高原台地拔升、深盆地、雪山耸立的前提。
- 区块为立方体（边长 16 体素），按三维坐标 `(cx, cy, cz)` 索引；逻辑上以"列"组织生成与流式加载，但存储与网格化以立方体区块为原子单位。
- 世界原点附近为玩家出生点；出生点由种子选定一处平坦草地。
- 坐标系：Y 向上，单位 = 1 体素 = 1 米。

## 4. 群系（7 种）

由 **海拔（高度噪声）+ 温度噪声 + 湿度噪声** 三场联合划分。划分逻辑见技术文档 §4。

| 群系 | 判定特征 | 地表主色 | 典型地物 | 远景识别点 |
|---|---|---|---|---|
| **平原** | 中海拔 + 中温 + 中湿，地势平缓 | 草绿 | 零星草、花、偶发圆冠树 | 低平绿毯 |
| **森林** | 中低海拔 + 中温 + 高湿 | 深草绿 | 密集针叶杉/樱花树、巨树地标 | **树冠凸起的"绒感"色块** |
| **沙漠** | 低中海拔 + 高温 + 极低湿 | 沙黄 | 沙丘、仙人掌、干棕榈 | 平滑黄沙 + 零星棕榈剪影 |
| **高原** | 高海拔 + 顶部平坦 | 草绿顶 + 裸岩壁 | **台地陡崖 + 平顶**、杉树 | **阶梯状崖壁轮廓** |
| **盆地** | 低海拔洼地（高度噪声低谷） | 湿土/泥 | 低洼聚水、芦苇、蘑菇 | 下凹地形 + 水色 |
| **湖泊** | 盆地/低地低于水面线 | 水蓝 | 成片水体、睡莲、沙滩边缘 | **水色走向** |
| **雪山** | 高海拔 + 低温（温度噪声低 + 海拔超雪线） | 雪白 + 岩灰 | 积雪坡、裸岩、针叶杉带雪 | **起伏轮廓 + 山顶白帽** |

**雪线规则**：温度噪声 < 阈值 且 海拔 > 雪线高度 → 地表覆雪；海拔越高雪越厚，形成山顶白帽。

**河流**：由一条低噪声蜿蜒路径切割地形，河床低于两侧，**至少贯穿 3 个以上群系**，在湖泊处汇水。河流作为独立噪声通道叠加到高度场上。

## 5. 地形生成（视觉目标）

- 多层 Perlin 噪声叠加（octaves），每层频率递增、振幅递减：底层定大势、高层加细节。
- **指数塑形**：`height = 2^(PerlinNoise)`。低噪声区 → 指数趋平 → 草甸/盆地；高噪声区 → 指数陡增 → 山脉/高原。自然形成"草甸与山脉交错"的远景天际线。
- **高原成台地**：对高度场做台阶量化（plateau quantization），顶部平坦、边缘陡崖。
- **盆地聚水**：高度场低谷区低于全局水面线 → 湖泊/湿地。
- **群系叠加**：温度/湿度噪声决定地表材质与植被密度；海拔决定基岩/裸岩/积雪分布。
- 地表之下按深度填充：表层（草/沙/雪）→ 泥土数格 → 石头 → 深板岩；矿物按深度概率散布。

## 6. 树木（3 + 1 种，轮廓必须截然不同）

| 树 | 轮廓 | 结构要点 | 出现群系 |
|---|---|---|---|
| **锥形针叶杉** | 自下而上逐层收缩的尖塔 | 直干 + 多层环形递减叶层，顶收尖 | 森林、雪山边缘、高原 |
| **弯干伞冠棕榈** | 弯曲树干 + 顶部伞状展开 | 弧形分段树干 + 顶端放射状下垂叶 | 沙漠、湖泊/海滩边缘 |
| **圆冠樱花树** | 短粗干 + 球形粉花冠 | 粗短干 + 球形粉色花叶团 | 平原、森林 |
| **巨型高树（地标）** | 2×2 粗树干、≥20 格高 | 超远景仍可辨认的剪影地标，顶部大冠 | 森林深处稀有生成 |

**严禁**使用橡木/白桦这类轮廓相近的组合。四种树在剪影层面必须一眼可分。

## 8. 材质（核心约束）

- **全部 SVG 程序化绘制**：每种方块/物品在 `src/data/textures.js` 中由一段 SVG 字符串（或 Canvas 绘图指令）定义，含 16×16 像素风的色块、噪点、图案。
- 渲染路径：SVG → `Image`/Canvas 光栅化 → `THREE.CanvasTexture`，`magFilter = NearestFilter` 保持硬像素边。
- **图集（atlas）**：所有方块面贴图合并进一张或数张图集纹理，配合贪婪 Mesh 的 UV 偏移，减少纹理切换/draw call。
- 方块可有**多面材质**（如草方块：顶绿、侧草边、底泥土）。
- 透明/镂空方块（玻璃、树叶、花、梯子、门）走 alpha-test 通道，不参与背面剔除优化但参与面剔除。
- 物品图标复用同一套程序化贴图（2D 展示）。

## 9. 远景 LOD（核心卖点 · 视觉目标）

**原则：远景是"矮精度的立体世界"，绝不是一张高度图平板贴色。**

- **LOD 分级**（详见技术文档 §5）：
  - 近景（视距内圈）：满精度体素 + 贪婪合并。
  - 中景：每 2³ 体素取 1 个代表方块。
  - 远景：逐级 4×/8×/16×… 降采样，最远层每 chunk 降至单代表方块，低细节 chunk 合批为超大 Mesh。
  - 环形 LOD 层始终包裹玩家，随移动动态回收/生成。
- **远景必须携带地物信息**（验收专项）：
  - 森林 → 远处有**树冠凸起的绒感色块**与树冠色；
  - 巨树 → 超远处仍是**可辨认地标剪影**；
  - 雪山 → 保留**起伏轮廓 + 山顶白帽**；
  - 台地 → 保留**阶梯崖壁**；
  - 河湖 → 显出**水色走向**。
- **无缝衔接**：近景与远景在雾中过渡，LOD 切换不跳变、不穿帮。
- **视距滑条**：设置中可调，最高 **8192 格**且流畅不崩。
- **合批**：每级 LOD draw call 压到个位数。

## 10. 画面效果

| 效果 | 目标 | 实现取向（详见技术文档 §7） |
|---|---|---|
| 环境光遮蔽 AO | 边缘/缝隙柔和阴影，消除拼凑感 | 顶点烘焙 AO（体素邻接采样），随贪婪 Mesh 写入顶点属性 |
| 体积光 God Rays | 阳光被遮挡的丁达尔光束 | 低成本近似：遮挡深度图 + 径向模糊合成，**非**步进射线追踪 |
| 水面着色器 | 浅水折射下方、深水反射上方 | 屏幕空间近似折射 + 立方/平面反射混合，按深度插值 |
| 天空 | 大气散射昼夜循环 | 数学函数（Preetham/Hosek 近似）程序化天空，参数由外部时间驱动 |
| 雾效 | 远处消散 + 掩盖 LOD 边界 | 指数雾，颜色随天空/昼夜联动 |
| 阴影 | 大范围多级分辨率 | 级联阴影 CSM（近高远低分辨率） |
| TAA | 抗锯齿，优于 MSAA | 抖动投影 + 历史帧混合 + 运动向量近似 |

## 11. UI / 交互（工业软件风格）

- **风格基调**：深色背景、等宽字体、无圆角、无阴影、无 emoji。HUD 信息以细边框面板呈现。
- **HUD**：左上 FPS + 坐标 + 群系 + 当前 LOD 统计；右下快捷栏（9 格）；中央十字准星。
- **调试面板（F3）**：各阶段计时器（生成/网格化/渲染耗时分布）、chunk 加载队列、draw call、三角面数、内存占用。
- **设置面板（Esc）**：视距滑条（256–8192）、渲染距离、FOV、鼠标灵敏度、昼夜时间、画质预设、God Rays/AO/TAA/阴影开关。
- **物品栏（E）**：见 §7.1。

## 12. 设置项一览

视距（256–8192，默认 1024）、FOV（60–110）、鼠标灵敏度、昼夜时间滑块（手动定格或自动循环）、画质预设（低/中/高/极致）、各效果独立开关（AO / God Rays / TAA / CSM 阴影 / 水面反射）、体素雾浓度、显示 FPS。

## 13. 验收标准（不达标不交付）

1. **性能**：内置 FPS 面板，8192 视距下画面连续稳定、console 零 error。
2. **群系自检**：无头浏览器截图确认 7 群系样貌可辨。
3. **树种区分度**：截图确认 4 种树剪影可分。
4. **远景立体感专项**：截图必须能认出远处**森林绒感、雪山轮廓、巨树地标**，认不出即不合格，迭代到通过。
5. **远近衔接**：LOD 切换无跳变穿帮。
6. **性能自检**：各阶段计时器输出耗时分布，定位瓶颈后优先"减少工作量"策略迭代。
7. **原创性**：零外部图片素材，全部程序化生成。
