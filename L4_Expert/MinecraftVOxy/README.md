# 我的世界VOxy：方块沙盒世界与超远视距渲染引擎

## 分类元数据

- **测试领域**: 3D 图形、物理仿真与 Shaders
- **难度等级**: `L4`（专家级）
- **核心技术栈**: 浏览器 Web 3D（WebGL2 / WebGPU / Three.js 自选）+ Web Worker 流式生成 + 原创程序化资产（材质/模型/UI）
- **核心考核点**: 完整可玩沙盒玩法闭环（采集/合成/熔炼/生存/战斗/生物/天气/存档）、主世界·地狱·末地三维度与传送门、60+ 方块与程序化结构探索体系、PBR 材质差异表现、电影级 GI/体积光/水体渲染、Voxy 级超远视距连续性

## 任务定位

测试模型在浏览器中构建"完整可玩 Minecraft 风格方块沙盒 + 三维度世界 + 电影级渲染 + 超远视距"的综合能力：既要玩法深度（生存、合成、战斗、生物、存档与探索目标梯度），又要渲染质量（PBR、全局光照、体积光、高质量水体），还要工程极限——数百米外仍保持近景方块密度与细节的 Voxy 级远景，杜绝巨型体素、粗大台阶与 LOD 断层。
