# Antigravity Benchmark

这是一个包含多个层级的基准测试仓库 (Benchmark Repository)，旨在测试、评估各类大模型在复杂任务下的代码编写与系统设计能力。

## 目录结构 (Directory Structure)

本仓库按难度/复杂度层级划分为多个子目录：

- **L1_Basic**：基础能力测试（如简单的脚本、单文件前端交互等）。
- **L2_Intermediate**：进阶能力测试（如涉及基础架构、Monorepo Workspace、带有一定复杂度的组件开发等）。
- **L3_Advanced**：高级能力测试（如手写底层物理引擎系统、无框架渲染、复杂算法实现等）。
- **L4_Expert**：专家级能力测试（具有极其复杂架构或前沿技术的应用）。

## 提示词说明 (Prompt Usage)

为了方便直接将提示词提供给大模型进行测试，本仓库内的所有测试任务都已在各自的子目录下提供了标准的 `PROJECT_PROMPT.md` 文件。

所有的 `PROJECT_PROMPT.md` 内容均已被包裹在 ` ```markdown ` 代码块中，您可以直接**一键复制**其内的全部内容（包含格式）并发送给被测大模型。

## 贡献与更新 (Contributing)

如果您要新增测试项目，请确保：
1. 在合适的难度层级下创建独立目录。
2. 创建 `PROJECT_PROMPT.md`，使用标准的 `# 任务背景`, `# 需求范围`, `# 交付与限制要求` 格式。
3. 请确保提示词不包含带有特定考核主观色彩的字眼（如“测试方向”、“考核权重”），使其读起来像一份专业的技术需求文档。
4. 将提示词内容使用 ` ```markdown ` 代码块包裹，以便快速复制。
